## 文章摘要

这是 HN 每月例行的「你在做什么」开放帖，由用户 david927 发起，正文只有一句话：你在做什么？最近对什么感到好奇？帖子最终拿到 378 分、1200 多条评论，其中 700 多条是一级回复，相当于一份自发形成的独立开发者年度横截面。

从整体分布看，2026 年 9 月这一期呈现出几个明显趋势。

第一，**AI 已经彻底从「项目主题」下沉为「施工工具」**。去年这类帖子里大量是「我做了一个 AI 包装器」，这一期占比明显下降；更多人是在做一件本来就想做的事，顺手用 Claude Code / Codex 把它做完。有人把七年前用 Vue2 写的 FFmpeg 命令生成器用 Opus 5 一口气迁到 Vite/React，并感慨这让他想把一堆积灰的老项目重新翻出来；有人用 LLM agent 反编译一款 1998 年的老游戏，同时把逆向工程的方法论写成一个可复用的 agent skill 开源出来，并坦承「产出全是 slop，但经得起测试、确实能跑」。也有人明确反向操作，强调自己那套给笔记本做全文搜索的工具是「用手指头敲出来的，没有 Claude Code 也没有 codex」。

第二，**围绕 agent 本身的工具链正在形成一个小生态**。帖子里出现了 agent 技能管理 TUI（把散落的 skills 从 git 仓库按需拷进项目目录，替代手动 cp/rm）、agent 的共享知识层（挂在 Claude Code / Codex 的 hook 上捕获经验并在报错时注入，目标是省 10% token）、agent 多路复用器（让 Claude 和 Codex 共享记忆一起跑）、agent 托管平台等等。工具做给工具用，是这一期最有时代感的一层。

第三，**硬件、逆向与「实体世界」的项目占比不低**，构成了对 AI 热潮的一种对冲。有人从零写 x86_64 UEFI 操作系统，目标是「长得像 Windows Vista、行为像 Linux」，卡在 USB-HID 键盘和真机启动上，公开求合作；有人逆向索尼 A7 IV 相机的硬件与固件；有人为 Masterbuilt 电控炭火熏炉重写全套开源固件，因为「硬件本身不错，但和多数 IoT 设备一样，固件和 App 都很烂」；有人在设计支持 Amiga / Atari / C64 多种协议的复古游戏鼠标；还有人明说自己重新回到硬件机器人爱好，理由是「这一块短期内 LLM 接管不了」。

第四，**小而具体的个人痒点仍是最大类**。名字发现网站、足球集锦聚合、Anki 智能扩展、间隔重复学习 App、阅读记录 App、本地演出与酒水优惠聚合、公交到站显示器、天文测光流水线、拉丁语有声书（带强制对齐、词形分析和古典发音的省音处理）等等，几乎都是「我自己烦了三年，干脆自己写一个」。

值得一提的是，帖子里也有若干完全跳出技术语境的回复：有人在给自己做周日晚餐（烤猪里脊配米饭和沙拉），有人在烤无蛋苹果酱燕麦饼干，有人在怀俄明州找地准备建「AI 末日地堡」——后者引出了整串跟帖玩梗。还有 OpenBSD 的长期贡献者直接在帖子里公开求赞助，希望能把时间从「赚房租」转回开源开发。

## HN 评论精华

- **PopFlamingo** 的名字发现网站是本期回复最热的项目之一。他的产品思路值得一读：现有同类网站的问题在于界面几乎是数据库查询的一比一翻译——先让你选筛选器和排序，再给你分页结果。他反其道而行，做了一个全屏的交互式「名字墙」，默认只保留性别一个筛选项，把屏幕留给内容本身，复杂查询交给支持自然语言的搜索框。有人反馈背景摇篮曲听久了很烦，他当天就加了关闭开关。

- **ponyous** 做 AI 驱动的 3D 打印建模已经一年半，给出了本帖最有信息量的一条观察：「AI benchmark 对我这个场景几乎没有意义，我这里的帕累托前沿和任何公开榜单画出来的都不一样。」他说能力提升肉眼可见——刚开始只能「做一个带孔的立方体」，现在能说「做一个树莓派 4 外壳」然后 agent 自己搜索、建模、验证。追问哪个模型最好时，他答的是 Gemini 系列，理由是空间理解能力相对价格和速度最划算。另一位回复者 **dr_kiszonka** 补充了一组有趣的对比：GPT 类模型即使不挂 MCP 也能一次成型出相对复杂的模型，而 Opus 哪怕接上 Fusion 360 的 MCP 也常常做出「滑稽得离谱」的东西——他的解释是 Opus 试图从头推理这个问题，而 GPT 倾向于先定一个「用手头任何工具解决」的大方向。

- **spudlyo** 的拉丁语有声书项目引来了本帖质量最高的一段技术交流。他用 wav2vec2 做强制对齐，让文本能跟读音同步高亮，还实现了元音鼻化、省音（elision）等口语细节，每个词都附有词元、主要变化形式、词形切分、变格变位表、古典拉丁语 IPA 等教学信息。评论者 **eigenblake** 亲自验证了省音确实实现了，并提出能否反过来用 wav2vec 把 IPA 较确定地转成语音，以弥补拉丁语训练数据稀少的问题。作者回复说朗读来自他的拉丁语老师本人，用的是意大利语 wav2vec2 在拉丁语上微调的模型，纯拉丁语内容效果不错但英拉混排会崩；另外他为了修正 Gemini 幻觉出来的省音标注，手工校对了全部文本。

- **kilroy123** 贴出自己在做的「全能工具站」，立刻被 **backtr4ck** 用一句「为什么要重复造轮子」甩了一个现成开源项目的链接——这条小交锋很典型地反映了这类帖子里常见的张力。另一位做类似工具集合站的 **moralestapia** 则把定位说得更清楚：「那些偶尔才用一次的小工具，我把它们放在一个地方，没有广告也没有废话，为可用性优化，不为曝光量优化。」

- **jesse__** 的十年期体素游戏引擎 Bonsai 是本帖跟帖最多的条目（17 条回复）。他介绍最有意思的部分是编辑器：世界和世界里的大多数东西都表示为 SDF（严格说是密度场）的集合，一次世界编辑就是一组 SDF 参数被投影/光栅化的结果。

- **hgoel** 在后续讨论里晒了一套 2 台 GB10 组成的本地推理集群，理由不只是成本：他会把其他机器的登录凭证直接交给本地模型去做系统更新和排障，「云端 AI 也能做，但我不想把内网密码发出去」。他也提到初期折腾点在于要先升级固件并断电重启，200GbE 链路才能跑满。

- **mrguyorama** 那条关于 VR 的长评（出现在本期另一帖，但同一批用户）之外，本帖里最贴合「好奇心」题干的回答来自 **azaras**：「我在学数理逻辑，以及两门用来写它的语言：TLA+ 和 Lean。」——在一整屏 SaaS 落地页链接里，这种回答反而显得稀有。

## 文章摘要

**先说清楚：这是 McSweeney's Internet Tendency 的讽刺小品，作者 Jonathan Zeller，不是任何人的真实主张。**全文以第一人称"我"的口吻，模仿一份被公司思想改造后的员工感言，标题的论点（"必须回办公室才能面对面使用 AI"）从头到尾都是反话，每一条"理由"都在自己拆自己的台。读的时候要把它当作《1984》式的黑色幽默，而不是一篇 RTO 立场文。

叙事者供职于 Mondo Mayo——一家蛋黄酱起家、如今兼营快消品、SaaS 和监控技术的公司，也是地球上仅剩的三家大企业之一。他的职位叫"助理泔水助产士"（Associate Slop Doula），工作内容是在内部系统上一天几千次地点击"生成"按钮，然后点击"批准"按钮。故事开场是 RTO 日——官方名称被改成"留在办公室"（Remain to Office），因为管理层坚称他记错了，公司一直就是每周六天到岗。他必须签署一份《热爱 RTO 备忘录》才能保住工作。

接下来是一条条"为什么 RTO 是必要的"，每一条都荒诞得刚好能映射现实。公司的三条核心原则是："好事比坏事好"、"是的老板，好主意老板"、"更多领导意味着更多领导力"——在第三条的加持下，十五名一线员工由数千名高级副总裁"领导"。公司宣称专有指标证明家庭生活也可以远程高效完成：租一台机器放在家里，在你不在时给孩子投喂颗粒饲料，孩子会和它建立感情。办公室由名为"最佳伙伴"的 AI 绩效软件全天监控。总部工地已连续施工二十年，卡车上贴着"散装石棉"，蛋黄酱从管道里漏出来，而这些不是干扰，是"锤炼专注力的机会"。

后半段完全走《1984》的结构：他和同事 Blair 因为在公司内部聊天工具上吐槽战略变动（公司刚从"与 Cagefight 制药结盟对抗 SodaPorn"翻转成反过来，而官方说法是"我们一直如此"）被叫进 HR；两人被放上"帮你做到最好计划"，按规定必须有一人被"充满关怀地释放"，且竞业条款让此人终身无法再从任何公司领薪。叙事者最终以健康保险和背痛为要挟被驯服，请求公司处置对方而留下自己，随后获得一瓶止痛药和"高级助理泔水助产士"的晋升，并心悦诚服地签下了每周七天、每天十六小时的 RTO 备忘录。结尾三句口号式自白与《1984》的"他热爱老大哥"如出一辙。

全文真正刺的是：绩效监控、无限扩张的管理层、把 AI 产出流水线化的岗位、朝令夕改还要求员工假装没变过的战略、用医保绑住人的雇佣关系，以及"回办公室"这套说辞本身的空洞——所谓"面对面使用 AI"从头到尾没有任何解释，因为它本来就没有理由。

## HN 评论精华

这篇在 HN 拿到 401 分，讨论罕见地轻松，主线是"笑"，支线才是真吵架。

**"AI 写不出这个"**。置顶评论 jgbuddy 只有一句"AI 永远写不出这种东西"，随即演变成一场关于文风与模型能力的辩论。xena 认为这里有一种"被制造出来供消费"与"被写出来供感受"的区别；meowface 提醒"赌 AI 永远做不到某件事通常不是个好山头"；no_multitudes 反驳说 LLM 在长篇散文上最近反而在退步，代码之所以写得好是因为领域受限、可验证（streb-lo 补充：RLVR 能给代码指方向，散文不行）。这条线还跑出一个纯技术小插曲：如果只用这一篇文本从零训练一个模型，它会不会逐字复现？Borealid 认真解释了为什么不会——损失通常不会收敛到零，采样也是随机的，要它生成比训练文本更长的内容时必然产生"新"东西。

**辨识出致敬对象**。selwoot 说"让我想起 1984 年左右读过的东西"，引出一串纠正（小说写于 1948、出版于 1949）和玩笑（如果书名按出版年改成《1994》，味道全变）。pjc50 点明这是刻意的：与 Julia 的私情、"我们一直在与……作战"、老大哥（这里是"最佳伙伴"）、强制改造，结构全是《1984》，读者被期待认出来。也有人说更像《巴西》或 DFW 的调子。多条评论把"泔水助产士"（slop doula）单独挑出来，希望这个词能留在英语里。

**唯一一场严肃争论：远程办公是不是无可指摘**。phplovesong 说 RTO 是管理层推的最烂的东西，xp84 提出了帖子里最有分量的反方意见：2026 年的纯远程主要是省成本，而且长期看会给"用 AI agent 替换知识工作者"铺路——在物理空间里人类对机器人有先天优势，一旦全部沟通走 IP，非语言表达的优势被抹平，员工 100% 的产出都对 agent 可读；远程也削弱了同事之间私下串联的能力（Slack 上所有东西都有日志）。反方 tyrust 说"在现实空间里扯淡"算不上护城河，而通勤一小时是实打实的损失，还提醒别把省下的通勤时间还给公司。xp84 回应说自己选择住在离公司二十分钟步行的地方，preg_match 则算账：为了在办公室上班而住得近，相当于每年主动减薪约两万美元，还不如租个联合办公空间。Apocryphon 抛出的另一个角度也很尖锐：如果工程师真有那么大议价权，为什么疫情期间得到的远程福利守不住？

**最扎心的真实故事**。sznio 讲了自己刚辞职的经历：被要求去办公室，独自坐在一间屋子里，与在国家另一头的团队远程协作；经理推 Claude Code、部门主管被销售说服上了另一款 AI 工具、C 级高管押注第三家——三套工具的 token 用量都被纳入考核，结果他因为忙着刷各家的用量而绩效不合格。他跳槽到一家只允许 GitHub Copilot 的公司，薪水翻倍，"从没这么开心过"。

另有多条短评点出讽刺的准头：ARandomerDude 说"十五个一线员工、数千名高级副总裁"这句"既好笑又熟悉得疼"；neuroelectron 指出"回办公室并不能阻止办公室工作被 AI 取代"——下面接了一句更冷的，"能啊，AI 效率太高我们只需要十几个工人，于是领导比以往任何时候都多，经济问题解决了"。还有人注意到"SaaS 和监控技术"被并列写进同一家公司的业务范围，追问这两者到底还有什么区别。

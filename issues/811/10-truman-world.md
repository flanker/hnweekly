## 文章摘要

Truman World 不是一篇文章，而是一个实时运行的 AI 生成直播网站。站点本身是客户端渲染的单页应用，没有"关于"页面，HN 用户也吐槽找不到说明。以下内容来自页面本身、前端代码中的界面文案，以及 HN 评论里转述的创作者自述。

**设定：让楚门继续相信他的世界是真的。** 页面标语是"One world. Everyone directs."（一个世界，所有人一起导演），副标语是"下一个场景由你来塑造"。玩法说明直接借用了电影《楚门的世界》的设定："楚门生活在一个电视节目里而不自知。通过改变他周围的环境来掩盖奇怪的事件。你无法控制他的想法。"首页的任务是："让楚门继续相信他的世界是真的——在他发现自己活在电视节目里之前，把线索掩盖掉。"前端代码中的提示词模板写明，楚门是主角，吉姆·凯瑞是他的外貌参考。

**观众如何参与。** 页面分为几个区域：共享摄像头（实时视频流）、"导演下一刻"（输入不超过 200 字的指令）、楚门的想法、世界与角色、记忆日志、最近活动，以及一个相当详细的"诊断"面板，展示世界引擎考虑过哪些动作、选了哪个、决策延迟多少。界面里有几类干预方式：向世界提出一个"楚门能看到的物理解释"或"广播故障的正常解释"，编辑一份楚门可以拿来和亲眼所见对照的"记录"，或者给楚门的手机发短信、安排来电（"来电者决定打不打，楚门决定接不接"）。

**付费机制。** 前端文案显示，免费指令按先进先出排队，每个浏览器只能有一条等待中的指令，10 分钟后过期，且不增加直播时长；付费干预每次 2 美元，以 Solana 链上的 USDC 支付（网络手续费用 SOL 付），包含"为所有人"增加 20 秒共享直播时长，付费指令会出现在公开队列里，也可以花 2 美元给已有指令"加速"以提高优先级。内容政策要求"非政治性、无脏话的场景请求"。

**技术栈与"记忆"。** 页面标注"World engine · Built with GPT-6 Astra"和"Director mode · Powered by MiniMax H3 Director · fal"。记忆日志的说明很有意思："上一个世界的习惯会以模糊熟悉感的形式在重置后留存——而不是对原始事件的记忆。"世界会被"重置"并编号，页面还特意声明"链接并不能证明是什么导致了某个决定"，活动记录是"世界事件，而非经过验证的视频帧"。

**创作者的说法。** 根据 HN 用户 avaer 转述，创作者（推特 @WillTheRapper_）称："这是我们构建持久化社交世界引擎（Social World Engine）的第一次实验——一个即使没人观看也会继续存在、演化和记忆的世界。"

## HN 评论精华

约 35 条评论，规模不大，而且帖子一上首页网站就被挤垮了，所以相当一部分讨论是"这到底是什么"和"网站挂了"。

**这到底是什么？** stevage 问："它是怎么运作的？我找不到关于页面。"得到"用了哪些模型"的回答后他追问："我不想知道用了什么工具。它……到底是什么？目标是什么？该怎么和它互动？"avaer 给出了最完整的解释：核心是 MiniMax 的 H3 Max Director，它提供一个伪实时的 WebRTC 视频流，可以用 JSON 消息控制，"你真的可以随便输入想要的内容，几秒后它就会合理地发生"；配合 Jev 和一个负责管理上下文并向 Director 发送更新的智能体。"逻辑连续性不包含在内；维持连续性大概才是这个实验的主要工作量。"他还提醒这东西非常贵：按 fal 上的标价，运行一分钟 5 美元，最少计费一分钟。如果想自己做一个，在 fal 的 API 上 vibe code 一个界面几分钟就行。dvh 对没看到视频的人做了描述：设定类似吉姆·凯瑞主演的《楚门的世界》，受当前技术限制，画面"连贯性最多维持 5 到 10 秒"，他猜测是先生成一段 10 秒"场景"的首尾帧、生成两段视频再拼起来。vunderba 的比喻是"把'选择你自己的冒险'调到 11 档"。

**付费与版权的疑虑。** avaer 提到支付涉及加密货币，"自己判断吧"，并认为这是在招惹官司：当年有人在 Twitch 上跑 AI 版海绵宝宝，因版权问题被关，"而这次不是卡通，是吉姆·凯瑞"。yreg 指出观众似乎是用 USDC 付款，"这本身没什么可疑的"；SwellJoe 则说目前画面里的人看起来一点也不像吉姆·凯瑞，pooloo 的观察正相反："它在努力不变成《楚门的世界》里的吉姆·凯瑞，但挣扎得很辛苦。"

**被 HN 挤垮。** jader201 只说了一个词："Hugged :("（被抱死了）。esseph 贴出了报错："代理请求到容器出错：入站到容器的并发连接超过 4096 个，超出限制。"TZubiri 列了个选择题：A）去掉容器用裸进程；B）4096 个连接够多了，开始丢连接；C）套上 Cloudflare 了事（错误率一样，但用户被告知自己是机器人，所以是他们的错）；D）重启服务器。avaer 认为唯一不能轻易无限扩展的是流媒体，应该交给 LiveKit 之类的服务；dwroberts 则说正确答案是 E："多跑几个容器"。

**亲历者的描述比任何介绍都生动。** the_sleaze_ 在网站挂掉前看到的一幕是：楚门望向发生爆炸的街道，一个黑影从烟雾中走出，撞上楚门又越过他，去袭击一个缠头巾的印度男子；两人扭打，直到另一个一模一样的缠头巾男子把黑影扑倒到画面后方；第一个男子被递上一罐白色魔爪能量饮料，喝了一口，立刻变成了眼睛发蓝光的楚门，楚门一脸困惑，开始说些含糊不清的话。userbinator 接了句"现在我成了 HN，网站的毁灭者"。

Phemist 在帖子掉出首页、网站恢复后玩了半小时，给出了最详细的体验报告：这基本上就是"自己写提示词的楚门秀"，指令响应慢、还会崩，很难建立连续性，楚门同时被三四条故事线来回拉扯。有人一直试图让楚门打破自己的模拟——让他在手机上打开 trumanworld.live，看他会写什么指令；与此同时楚门不停把水果扔在地上大喊"就决定是你了，妙蛙种子／杰尼龟／皮卡丘！"，一度还直视镜头说"别再玩宝可梦了，数码宝贝才是冠军"；另一条线让楚门不断突然唱起歌来，一首关于香蕉的歌和打破模拟的尝试混在了一起，楚门最后唱出类似"这就是我的感受，像香蕉皮一样，我剥开现实"的歌词，然后拿起手机又打开了 trumanworld.live，试图给自己写指令。"混乱，但挺好玩的！"sbucco 说"停不下来地看和写指令，会上瘾"，Fairburn 则问"这怎么还没上 YouTube 直播"。

**批评同样直接。** rvz 说它"被漫不经心地 vibe code 出来，在 HN 的轻度流量下就崩了，可靠性的最低门槛"；altmanaltman 称之为"vibe code 出来的垃圾，不明白为什么有人当真"，margalabargala 回应："有些人看的是它是什么，而不是它是怎么做出来的。"drayfield 说"这真是个可怕的东西"，weezing 称之为"实时垃圾生成器"。持正面看法的也有：Ajakks 认为这虽然粗糙，但让他意识到"十年后世界会大不相同，二十年后将面目全非"；SpikeyCoder 觉得在参与式即兴小说外面包一层面向公众的 AI 智能体可观测面板，是个很妙的想法，只是做得粗糙、扛不住流量。

## 文章摘要

Anthropic 于 2026 年 9 月 23 日发布的公告：他们成立了一个新的生命科学研究组和实验室，并公布第一批成果——在科学家只给出高层方向的情况下，Claude 自主发现了一种此前未被描述的酶系统，其结构特征让人联想到 CRISPR。公告同时附了一篇技术预印本。

**背景论证是"很多革命性工具都始于有人注意到一个怪东西"。** 文章开篇回顾了几段生物技术史：限制性内切酶最初在细菌免疫系统里被发现，后来成为基因拼接的基础，开启了整个生物技术产业；Taq 聚合酶来自黄石公园温泉中的一种细菌，成了 PCR 的基础；CRISPR 最早只是被当作某些细菌 DNA 中一段不寻常的重复序列注意到，如今已是基因编辑药物的基石。2026 年春天，Anthropic 组建研究组，想看看通用 AI 模型能否把这类"注意到异常"的发现系统化、规模化。他们认为这种加速来自一种新的研究方式：Agent 在每一步都与人类协作。为此他们建了自己的实验室，一个团队同时负责训练 Claude 的生物学能力和做实验。

**发现了什么。** 这个系统以一种逆转录酶为核心。该酶本身在以前的研究中已被鉴定过，但 Claude 似乎是第一个注意到这个系统的决定性特征：它旁边伴随着一段有规律重复的非编码序列阵列，以及一个功能未知的附属蛋白。研究者把这类系统命名为"阵列相关逆转录酶"（array-associated reverse transcriptases，ART）。公告明确承认：目前还不知道它的功能是什么。他们的理由是，这组特征此前只在少数几个系统中同时出现过，而那些系统都是可编程的分子工具；因此这个新系统值得进一步研究。CRISPR 基因编辑先驱、MIT 与 Broad 研究所教授张锋（Feng Zhang）在读过预印本后评价："这是 AI Agent 能为生物学发现做出贡献的一个令人兴奋的例子……我希望这项工作能鼓励更多科学家去探索 AI 如何支持他们的研究。"

**过程与规模是这篇公告真正想展示的东西。** 研究者给 Claude 的提示是在一个巨大的序列数据库中寻找有趣的新逆转录酶，人类的参与"仅限于最初的提示词和实验室工作"。Agent 自行完成了检索、分类、筛选候选、撰写人类可读报告的全过程：约 950 个 Agent 会话、约 2.1 亿 token、21 小时墙钟时间，从约 20 万个候选中逐层收敛到 3500 个候选系统、再到 20 份最值得关注的报告。公告说，对一位专家科学家而言，这类分析通常需要数周到数月。最富戏剧性的细节是 Agent 在原始序列里直接"用眼睛看出"了重复模式，其推理轨迹里写着一句："这段序列太壮观了：我一眼就能看到一个串联重复阵列……这是一个类 CRISPR 的重复阵列？！"随后它像人类科学家一样继续：数重复次数、量间距、与已知系统的布局做对比、检索文献确认没人报告过这个模式，最后提交报告等待人类审阅。

**他们怎么工作。** 公告用一节介绍了工作流：Claude 先读相关文献、用公开数据复现已确立的结果来检验自己的方法，然后寻找不符合任何已描述系统的家族成员或基因组邻居，为每个候选写一份简短的、人类可读的报告，提出功能假设并列出支持证据；在后续分析中 Claude 会批判性地评估这些证据，多数候选在这一步就被淘汰，一轮调查可能以一个值得测试的候选结束，也可能一个都不剩。候选通过人类审查后才进实验室，由人类科学家表达蛋白并做表征，Claude 协助解读数据。他们用的是 Claude Science 和 Claude Code——和任何科学家都能用的工具一样，有时再加上自研的、协调多个并行 Claude 会话的 harness。一个有意思的副产品是：由于 Claude 产出假设的数量极大，"假设本身"成了他们的研究对象——一轮活动能产出成百上千份候选报告，他们在研究"我们判断值得测试的提案与被搁置的提案之间区别在哪"，学到的东西再写回给 Claude 的指令中，教它模仿人类的科学品味。

公告还特别说明了实验室的安全边界：实验室位于湾区，是一个典型的分子生物学实验室，只做 BSL-1 和 BSL-2 级别的研究，不处理能感染人类的病原体，所有实验室工作都由人类科学家完成。

## HN 评论精华

763 条评论，是本期讨论量最大的条目之一，也是分歧最激烈的一条。主线大致有四条：这个结果到底有多大分量、"Claude 发现"这个说法是否得体、AI 公司为什么要自己做科研，以及围绕安全与虚伪的指责。讨论中还夹杂了一段长达数十层的"人该不该永生"跑题辩论。

**最有价值的一条是专业视角的"诚实版公告"。** porridgeraisin 转来了 Ravid Shwartz-Ziv 的帖子，被多人认为提供了最好的解读框架。他先肯定：Anthropic 让约 950 个 Claude Agent 在大型生物序列数据库上跑，Claude 自己搜索、写代码、比较序列和基因组邻域，发现了一个此前似乎没人注意到的模式，"这很酷，把这种开放式生物信息学检索自动化并规模化是有用的，Claude 可能找到了一条人类会错过的线索"。但他随即指出：Claude 没有做生物学实验，它只是检索数据库和分析数据；人类把候选带进湿实验室，而目前的湿实验结果很有限；"我们仍然不知道这个系统做什么。功能、机制、表型、靶向、防御活性、可编程性，一个都没有被证明。"他认为 CRISPR 这个框架超前于结果："'它具有一些让人联想到已知可编程系统的特征'是一个值得研究的假设，而不是'它的行为像 CRISPR'的发现。"他还指出缺少基线对照：生物信息学多年来就有寻找异常基因邻域和候选系统的工具，有意义的比较是 950 个 Claude Agent 对比一位使用现有最佳计算流程的专家，而不是对比一个人手工翻 20 万条序列。他的"诚实版公告"是："Claude 自主找到了一个有趣的候选。一个小规模的人类湿实验确认候选的一部分会被表达。我们还不知道它做什么。这是个好结果。但在普通生物实验室里，这不是完稿的论文，这是你在组会上拿出来说'这看起来有意思，现在我们得搞清楚它到底在干嘛'的那种结果。"有意思的是，这条本身被多人怀疑是 AI 写的：Kotlopou 说 Pangram 判定 100% AI，zozbot234 说"这读起来怎么这么像 Claude 在谈论 Claude"；glub 的回应很妙："人们会按照自己消费的内容的方式说话。如果你大量消费 Claude 腔，你最终也会开始说 Claude 腔，我在现实生活中已经注意到有人说 Claude 腔了。"

**领域内人士的评价从"扎实但初步"到"糟糕透顶"都有。** Spacecosmonaut 给出了一个被广泛认可的"清醒版表述"：现有的 Cas9 变体已经相当高效、在人类基因组靶向覆盖上也基本不受限，更小的核酸酶和更高的特异性会有用，但治疗用途的瓶颈主要在递送；这件事本质上是"Claude 在一个已知的逆转录酶周围识别出了一种此前未被描述的基因组排布，没那么性感"，"就目前而言，这主要是一个关于 AI 能被用来解析现有数据以发现新生物学的故事——而这很棒"。ajhammer 表示自己一直读到最后都在期待一个有趣的转折或功能被揭示，但没有。evolarjun 的判断是："这是个不错的结果，但并不遥远或极其新颖……在我看来这是一个增量式的发现，以前也需要有时间、兴趣和专业能力的人才能做出来。"contemporary343 更严厉："这充其量是一篇平庸的论文。如果是学生拿这个来做资格考试答辩，委员会一定会因为他完全不理解这东西做什么而把他撕碎。"自称在药物发现领域管理 50 人团队的 PhD vapemaster 措辞最重，称其严谨性、方法和披露的缺失"令人痛心"。另一边，dekhn 多次为作者辩护：预印本作者全都是该领域专家，第一作者曾在 Doudna 实验室研究 CRISPR 的起源，"他们确实在实验室里测试了"，并提醒批评者要具体。一位自称大量使用 Claude Science 的研究者 a_bonobo 提供了很接地气的体验：它在自己的 DNA 序列里找模式确实很强，经常主动提醒"你可以把引物放这里，但那看起来像个重复序列，特异性会不好"；不过用起来其实更累，"你得做很多额外工作来保证可追溯性……我现在把 Claude Science 当成一个 IDE，不断强制它规范用 git，这样我才能复现这些工作"，而且"它用的工具和我以前一样，只是比我快 20 倍，我主要在挣扎着跟上并验证它在做什么"。mfld 补充了一个技术观察：人们本以为这类任务该是基因组语言模型的主场，结果 Agent 反而依赖 HMM 这类经典生物信息学方法做出了发现。

**"Claude 发现"这个措辞引发了最多情绪。** willtemperley 说这种说法"非常瘆人"，正文里一次都没提到参与其中的人类，只有拉到最底下点开一个小链接才能在技术报告里看到致谢。hmokiguess 说自己"受够了这种营销"："这么多人参与其中，我们却还在说'Claude 做了'……说'一支由 Anthropic 支持、使用 Claude 的研究团队发现了……'有什么不好，或者干脆在标题里提一下首席研究员？"1659447091 的批评更细致，他逐句给出了"去拟人化"的改写版本，并质问："为什么人人都急着指出博客文章是 AI 垃圾，却没人对这些公司用微妙的、近乎欺骗性的措辞推动'它们的 LLM 有意识、有人格'的叙事眨一下眼？他们创造的系统本身已经足够令人印象深刻，完全没必要利用大众对系统基本原理的无知，用这么油滑的语言。"ChrisGreenHeur 反问"你买 iPhone 时也会拿到一本工程师名册吗"，podocarp 的反驳被多人认可："这完全不同。在研究中你是有署名的……这相当于说'起重机建了摩天大楼'或者'推土机生产了木材'。是的，以焦耳计它们可能干了大部分活，但我们通常不这么说话。"TeMPOraL 提出了一个区分标准：关键在于它更像 iPhone 与工程师名册，还是更像前两天那个 Astra 破解 Enigma 的故事——在后者中当事人直接说明他们只是含糊地把模型指向未破解的密文，模型就自己去做了，那种情况下说"LLM 做的"是完全公道的。jstanley 则指出了一个两难："如果有人说某件事是'他们做的'，会收到一百万条评论说其实是 Claude 做的；如果有人说是'Claude 做的'，又会收到相反的评论。你赢不了。"

**为什么 AI 公司要自己下场做科研。** ryanschaefer 的提问引出了本帖第二大的讨论串："我很困惑为什么 AI 公司在内部用 Agent 做这类研究，而不是对外合作？"回答五花八门。Insanity 认为核心产品长期不可持续：本地硬件和模型会继续改进，而需要托管方案时大云厂商也提供，同时签 OpenAI/Anthropic 和 AWS/GCP/Azure 并不是好的商业决策，"唯一保持相关性的办法就是超越单纯提供模型"。baxtr 一句话概括："当'笨模型提供商'已经没有护城河了，所以他们在往垂直领域转。"jackb4040 从估值角度算账："一个给癌症研究者聊天的机器人最多值个位数十亿。Anthropic 的估值已经超过一万亿，前提是他们能取代大多数知识行业的大部分工作。所有关于黑客、数学问题、生物科学的公告，都是为了营造这个策略行得通且可跨行业复制的印象。"dekhn 给出了更善意的解读：这是基础发现科学而非工业研究，"经营 Anthropic 的那群人是读着有疯狂酷炫生物技术的科幻小说长大的，可他们看今天的生物技术只觉得沮丧——太慢了，验证一项新技术要几十年，他们觉得有了这个新工具，就可以把它指向问题、让它吐出发现"；而且 Anthropic 现在资本太充裕，投向包含内外部研究的广泛组合是最容易的做法。6thbit 则指出了一个竞争效应："无论他们对这研究是不是认真的，做这类研究的医药公司为了不'掉队'，肯定会考虑提高 AI 预算、把实验室接上。所以 AI 实验室要么得到可以营销的成果，要么得到对同行施加的同侪压力。"AbstractH24 提出了一个更激进的猜想：他们可能从卖 token 转向自己做前沿研究、靠研究成果而非模型赚钱，因为那比商品化的 token 更不容易陷入逐底竞争；spwa4 回应说"所以他们已经在用 Amazon 式的方式威胁客户了？"

**安全与"虚伪"之争。** danpalmer 的对照最广为传播："Anthropic：你绝对不能在任何情况下把 Claude 用于生物工程，那可能真的会终结人类。同样是 Anthropic：Claude 发现了编辑你基因组的新方法！"senordevnyc 的辩护是：他们从没说过做生物研究本身就危险，风险来自坏人为恶意目的做研究，这正是他们会逐案对其他组织开放无护栏模型的原因。danpalmer 澄清自己不反对严格的安全立场，"我不喜欢的是，一边对你能用模型做什么采取强硬的道德立场，一边自己把护栏拆了并且拿结果做营销。'看我们的模型在做我们不让你做的事情时有多厉害'是个相当糟糕的营销词"。consumer451 的解释较为无奈但现实：真正有用的模型往往风险高，风险高的模型按安全标准不该发布、发布了还要面对监管压力，最后必然导向"我们内部做就好了"，"我相信这可能最终会成为 AI 每一种应用的答案，这看起来不可避免，而且非常令人沮丧"。也有不少人直接担心方向本身：catigula 觉得这项工作本身就危险，UberFly 担心 AI 很快会让定向病毒变得容易；michaelbarton 提供了较为冷静的回应——即使能用 AI 设计出序列，在现实中从一条新序列造出可传播的病毒仍然相当困难，是一道不小的门槛。此外，多位评论者（nirei、asciimov、mullingitover、rickdeckard）提出了同一种怀疑：这会不会是别人的研究被"捞"了出来？mullingitover 说："下周会不会又有一篇帖子，某个实验室抱怨他们正要发表同样的发现，他们让 Claude 校对过论文，然后哎呀这东西怎么进了 Anthropic 的训练数据？"rickdeckard 用了一个比喻：这就像"耐克在最后一刻把跑者从鞋里拿掉，宣称比赛是鞋自己赢的"。

**为什么不发正经期刊。** djierardi 和 evolarjun 都质疑为什么是新闻稿而不是 Nature 或 Science 的同行评审论文。gavinray 提醒大家其实文中就有预印本链接（并被人用网页存档证明链接一开始就在）。关于预印本本身的价值也有一轮争论：beAbU 认为"每个人和他的狗都能发预印本，在我看来学术上一文不值"；howunfortunate 回应说期刊文章通常在付费墙后，预印本是大多数期刊允许的完全开放的变通办法，而且"除非你自己做过，否则很难体会同行评审有多糟糕，它大概只比什么都没有好 5%"；ACCount39 总结得最全面："预印本就是用严谨性换取可达性和速度……这就是为什么预印本成了机器学习的命脉。"levocardia 的回答最简洁："因为一篇有同行评审的 Science 或 Nature 论文要等到 2027 年底或 2028 年初？"

**几条被反复提及的旁支。** nonameiguess 希望讨论不要立刻堕落成"这毫无意义"与"奇点来了"的对喊，并给了一个冷静的框架：这类工作大致是三步——在自然界中发现分子和序列并编目、在其中发现有趣的子序列、搞清楚能不能有有用的应用；对已知数据库的系统性自动分析加速了第二步并减少了其中的运气成分，但第一步和第三步仍是长杆，"每当你必须与现实世界打交道，你就是在以现实世界的速度工作，而不是电的速度。CRISPR 发现于 1987 年，2015 年才首次用于编辑人类受精卵的基因序列。我相信有很多办法让候选发现到人类应用这一步不用花三十年，但它也永远不会是三个月"。modeless 认为 Dario 显然相信 AI 的公关问题的解法是治愈癌症，"他们会大力宣传路上的每一步，无论多小、离商业化多远"；这条引出了一大串关于癌症能否被"治愈"的讨论，其中 D-Machine 的自述最有分量——他自己正是靠 CAR-T 活下来的，但坚持说把 CAR-T 称为"治愈"是深度误导，"肿瘤学里'治愈'根本不是一个科学概念"，代价和副作用都极其沉重。evolarjun 还提出了一个少见的角度：入门级程序员的市场已经萎缩，"那么那些本来就几乎没有收入、还常常被当牛马的博士后又会怎样？"这引发了关于"没有人还能看懂 LLM 在建议什么"的争论，dekhn 把它提炼成一个他常在科学家中抛出的问题："如果有一个 AI 能输出疾病的治愈方案——能通过三期临床、获 FDA 批准、高度有效的药——但它无法解释它是怎么做到的，你会用吗？意见是分裂的。"

## 文章摘要

Wiz 披露了 NGINX 的两项 HTTP/2 内存安全漏洞，编号为 CVE-2026-123633 与 CVE-2026-123007。研究团队报告，在符合条件的部署中，问题可能导致未经身份验证的远程代码执行，影响网站、接口及服务器所处理的数据。漏洞位于基础服务器软件，因此应用代码本身没有缺陷，也不能自动排除风险；但不能由此推断所有 NGINX 部署都必然可被攻破。

本次另外核对了 [NGINX 官方安全公告](https://nginx.org/en/security_advisories.html)。公告分别列出受影响版本范围为 1.19.7 至 1.31.8，以及 1.9.5 至 1.31.8，并明确将 1.31.9 以上、1.30.7 以上列为已修复分支。阅读版本范围时应同时看修复分支，不要把已修复的稳定版误纳入较宽的历史范围。发行版和商业产品可能采用回补补丁，实际状态应以对应供应商公告为准，而不是只比较上游版本数字。

对运维团队而言，重点是清点实际部署及依赖、确认供应商更新是否已安装生效，并结合服务影响安排验证和发布。研究方的严重性评分与上游公告的分级标签并不完全相同，摘要保留来源区别，不用单一标签替代环境评估。本文只整理漏洞类别、总体影响和厂商修复信息，不提供利用方法或复现内容，也未对任何服务器进行探测。公开披露及已有修复，不等于所有用户已经获得保护，补丁到达生产环境之间的时间仍需关注。

## 文章摘要

Tom Verbeure（HN 用户名 tverbeure）在电子跳蚤市场上遇到一台泰克 TDS7104 示波器。除了几个脏按键、几处污渍和惯常的校准与资产标签外，外观状况极好，但 700 美元的标价明显偏高——同期 Craigslist 上同价位就能买到可以先试后买的 TDS7104。不过卖家 Paul 有主动说「我给你个价」的习惯，还没等他开口就报了 300 美元。按跳蚤市场标准这仍不便宜，但对一台 TDS7104 来说是好价——**前提是你能把它修好**。

回到家，示波器一上电就直接启动进了主程序，除了屏幕太暗外一切正常。但几小时后再试，它卡在了 BIOS 画面上。整篇文章就是他把这台机器恢复到最佳状态的全过程。

**机器本身。** TDS7104 是 4 通道、1GHz 带宽的示波器，最高采样率 10GS/s——但那只有单通道时才能达到，2 通道降到 5GS/s，3 或 4 通道降到 2.5GS/s。即便以今天的标准看，规格也超过 Rigol、Siglent 这类爱好者级示波器，代价是 39 磅（约 18 公斤）的重量和体积。它的小兄弟 TDS7054 是同一底盘的 500MHz 版本。与更高端的 TDS7xxx 型号不同，7104 和 7054 用的是标准 BNC 接口，而不是需要昂贵专用探头或转接头的泰克定制接口。

2000 年年中推出时最初跑 Windows 98，但很快就升级到了 Windows 2000 Pro Embedded——他这台就是。PC 主板用的是很少见的 NLX 规格，具体型号是 RadiSys SF810，Socket 370 加 100MHz 前端总线。原厂配的是慢得要命的 550MHz 赛扬，他运气好拿到的是 850MHz 版本（兼容的 100MHz FSB 赛扬最高到 1.4GHz，但价格贵，1.1GHz 的在 eBay 上约 20 美元）。640×480 的 LCD 屏带电阻式触控，不接鼠标也能用高级功能。除了 PC 主板，机内还有一块跑 VxWorks 的 PowerPC 控制板和一块大尺寸采集板。硬件选项（如每通道 4M 采样存储，默认 500k）和大量软件选项（抖动测试、USB 认证测试等）都通过 license key 启用——不出所料，这套保护机制早就被破解了。根据机箱上的标签，这台来自 Cypress Semiconductor 的 PSD 实验室，曾被用来测量 Apple TV 遥控器的电池电流等高带宽信号。

**常见故障与修复过程。** 他列出了 EEVblog 论坛和各类博客上这类示波器的常见问题，自己只碰上了其中两个。文章特别提醒：如果是 PowerPC 备用电池没电，工作量会大得多——开机后 TekScope 会停在启动画面永久挂起，你需要把机器进一步拆开、取出所有 PC 组件、更换 Dallas DS9034 NVRAM 的顶盖电池、用 RS-232 连上 PowerPC 控制板、再手工输入一堆值写回 NVRAM。电源故障是另一个常见问题，往往只需要更换漏液电容，EEVblog 上有逆向出来的电源原理图。

无论机器能不能启动，**第一步永远是给硬盘做镜像**（他这台是 6GB 的 IBM Travelstar）。他原以为要开机箱才能拿到硬盘，其实只要按下机背弹簧盖就能抽出硬盘托架。这一步的重要性立刻显现：HDD Raw Copy Tool 在复制时撞上了一批坏扇区，运气好受影响的文件属于法语版 Windows 2000 手册。

接下来必须开箱换 PC 主板上的 CR2032 备用电池。换完后机器能启动了，但 TekScope 窗口有奇怪的显示损坏、波形渲染不正常——原因是 Chips & Technologies 69000 显卡被设成了 256 色调色板模式，需要改回 24 位真彩色。这里有个有趣的细节：机内有**两块显卡**，一块 Intel 810 集显和一块 C&T 69000，后者负责驱动 LCD，它有专门的硬件以 overlay 模式渲染示波器波形——波形由采集板通过 DMA 直接送进显存。至于屏幕太暗的问题：他一度以为要换 CCFL 背光管，结果完全没必要——TDS7104 根本没有调节 LCD 背光强度的机制，是之前的用户在暗室里用，通过调 Windows 的 gamma 设置把亮度压低了。

文章特意把「拆解」一节放在后面，并反复强调：绝大多数维修场景下**你不需要拆前面板**，前面板有非常容易掰断的塑料卡扣（他自己就掰断了几个），左右两侧还有会滑进金属导轨的滑动卡扣。所有 PC 维护（包括换软驱）都可以不动前面板完成。拆开机箱需要卸 30 多颗螺丝——好消息是全是 Torx-15 且长度一致，不用记谁是谁。他还分享了一个折腾很久才想明白的小技巧：拆机器最省事的方式是把它立在后脚上，这样背面一颗螺丝都不用卸；以及配件包不用拧螺丝，用平口螺丝刀贴着每个按扣撬下来即可，硬扯会撕破布料。他顺带称赞了设备推车的价值——绕着推车走比在桌上搬动笨重的测试设备轻松太多。

**换 SSD 的失败尝试与从零重装。** 他过去用过 CF 卡替代老化硬盘，但除非买贵的「工业级」卡，否则没有内置磨损均衡——跑 DOS 还行，跑带 swap 的 Windows 就有问题了。标准做法是用 HDD Raw Copy Tool 把镜像写进 SSD，他用 64GB SSD 试了，机器过了第一阶段引导，但在启动 Windows GUI 的第二阶段报错；换更便宜的一半容量的盘（考虑到老系统常有 32GB 分区限制）也一样。别人这么做都成功了，他却在这条死胡同里耗了好几个小时，最终决定从零重装所有软件。

他本想避免重装，因为预计会遇到一堆驱动问题。虽然有人报告 Windows XP 能在部分 TDS7104 主板上跑，他还是选择留在 Windows 2000 Pro——因为他知道这个能用，也没有迫切需要更多功能。找不到 Embedded 版的安装盘，普通版也一样能用，ISO 可以从互联网档案馆拿到。机器背面印的 license key 对普通版 Win2k 无效，但档案馆那份自带可用的 key，而且他在安装过程中根本没被要求输入 key。

**引导安装介质的漫长折腾**（本文最有喜剧色彩的部分）：标准做法是用光驱装，但机内光驱坏了——BIOS 和 Windows 都能识别驱动器，但放进盘后谁也读不出来。于是又开一次机箱换光驱。新光驱（eBay 上 20 美元）配上转接板在他的笔记本上能正常读安装盘，装进示波器后 **BIOS 干脆识别不到**。他试遍了所有 BIOS 设置也无解。原因是 CD-224E 有很多版本，尺寸和 slimline IDE 接口相同但行为不同——坏的那台是 A93（2000 年），新的是 CD0（2005 年）。eBay 上能买到 A93，但 69 美元买一个只用一次的东西太贵了。

接着他试了「用虚拟机在没有光驱和 USB 的老机器上装 Win2k」这个据说可行的迂回方案：在虚拟机里挂载安装 ISO 和 SSD，走完第一阶段直到要求重启，再把 SSD 移到示波器上继续。他又花了几小时，示波器始终起不来。

最后只剩 USB。RadiSys 主板不支持 USB 启动，所以方案变成：用 FBinst 自动格式化成 FAT32、把 Win2k 安装内容拷进 U 盘，然后用 **Plop Boot Manager**（自带 USB 大容量存储驱动）从软盘引导、再由它引导 U 盘。他极力想避开软盘路线，因为他在老设备上遇到的软驱**没有一个能用**。结果他刚从亚马逊买的 USB 软驱也拷不了引导镜像——这些年来罪魁祸首竟然是 USB 软驱本身。由于示波器配 IBM 原硬盘时还能正常工作，他直接用示波器自己的软驱写了软盘，成功了。设置 BIOS 允许软盘启动后，机器顺利进入 Plop 并从 U 盘引导了 Win2k 安装程序。（一个坑：Plop 不支持 USB hub，而 RadiSys 主板只有一个 USB 口且会被 U 盘占用，所以至少还需要一个 PS/2 键盘。）

**驱动与最后一公里。** 装 Win2k 本身很顺利。TDS7104 有一批需要专用驱动的特殊硬件，他从原硬盘里提取了这些驱动。四个特殊驱动分别对应：一个列在「其他设备」下的 USB 设备；TI PCI-1225 CardBus 控制器（需要为每个端口各装一次，Windows 默认装的那个不工作，要用名字里带 "unsupported" 的那个，令人困惑但就是它）；以及 C&T 69000 视频驱动——Windows 默认驱动能让 Windows 正常显示，但不足以在 TekScope 里渲染测量信号，必须升级到 Chips and Technologies（Asiliant）的 69000 驱动。TDS7000 系列软件可以从泰克官网免费下载，安装很轻松。这台机器的架构相当迂回：控制板上的 PowerPC 会去访问常规 PC 硬盘上特定目录里的文件；因为他这台的控制板备用电池状态良好，固件安装时该目录自动创建，他不需要做额外操作。最后一个坑是字体：TekScope 用自定义 TrueType 字体渲染上升沿触发符号之类的图形，缺了就会显示成希腊字母——而新系统上已经装了同名字体文件，必须先删掉再重装泰克那份。

至此他终于得到一台装着 SSD 的可用 TDS7104，从按下电源到屏幕出波形的时间比原来短得多。最后还剩一项：高级抖动分析的 license 选项。前面提到的那个 GitHub 仓库里有启用和验证 license 的脚本，EEVblog 上很多人用过，只是不如其他 keygen 那么友好。多数设备的 license 是「一个功能一个 key」的叠加式，而 TDS7104 是**一个 key 一次启用全部功能**。验证脚本会解出 key 里编码的信息，其中的 UID 其实就是序列号与型号的组合；他把这些参数喂回生成工具就重建出了 license key（需要把 18 个字节拼成一个 72 位的十六进制数）。

## HN 评论精华

150 分、66 条评论，气氛是典型的 HN 硬件爱好者线程：一半在算这机器当年值多少钱，一半在争论泰克那个年代的可靠性，还有一条意外冒出来的「用 Claude 修老仪器」的支线。作者 tverbeure 在评论区非常活跃。

**「这东西当年多少钱」：** **devy** 说 eBay 上二手的还要 1500 美元左右，好奇当年新机的定价，无论如何 300 美元是白捡。tverbeure 回忆说 2000 年代初大概卖 6 万美元，后来又贴出一篇博文佐证：不含选件的基础型号标价是 24,490 美元。**ChickeNES** 说他 2010 年代初在一个实验室见过同系列的逻辑分析仪，被告知当年价格相当于一栋房子。**analog31** 泼了盆冷水：等它需要维修、厂家告诉你已经停止服务的时候你就知道了——他经历过；这正是租赁可能更划算的场景之一。

**关于泰克这一代机器的可靠性（本帖最有争议的一条线）：**

**sdcfgy** 上来就唱衰：「给它一个月，采集 ASIC 会炸，电容会把板子走线蚀穿。我受不了这些示波器。」tverbeure 的回应堪称本帖精神内核：「太好了，那我能从它身上榨出更多乐趣。」他接着说了一段很多人共鸣的话——**在电子跳蚤市场上买卖的设备通常不是达成目的的手段，它本身就是目的；你在那儿买回一样东西结果它直接就能用，那是让人失望的，那样就没乐趣了**。他举例说自己并不真的需要一台 R&S AMIQ，但把 PC 主板上的电容全换一遍让他学到了很多正确的拆焊技巧。sdcfgy 表示同意这个态度，但坚持自己的判断：「我修过的泰克设备比大多数人都多，数以百计。这些真的是特别糟的一批。」

**drzaiusx11** 提供了反例：他管过的一个实验室有十来台 TDS700 或 TDS71xx，四年里没有任何东西「烧掉」，他很好奇什么应用会导致这种灾难性故障。tverbeure 给出了他多年拥有五台 TDSxxx 系列示波器的经验总结，常见问题是：NuColor CRT 显示器老化、电容变质、Dallas NVRAM 电池耗尽——**电子件烧毁其实相当罕见**。drzaiusx11 想起他们确实有几台屏幕有「重影」，但仍 100% 可用；他承认自己期望值低是因为账单从来不用他付。**sitzkrieg** 站在 sdcfgy 一边：他曾负责翻修过很多台，泰克的返修率是 100%，其他品牌哪怕年代更老，内部状况也总是更好。**stmw** 问有没有哪些 TDS 型号在可靠性上更好，sdcfgy 的回答是「除了最低端那些之外，没有；后来大多转向 HP/Agilent 了」。stmw 的评论很到位：从全硬件到 Windows 驱动的数字化转型，对泰克和许多有历史的工程团队都是一次沉重打击。（**jhallenworld** 顺带提到，他有一台真正的老 7104，还有一台 7834 存储示波管机型，「以另一种方式很酷，另一方面它们占地方」。）

**「便宜捡漏 + AI 辅助修复」这条支线意外地精彩：**

**jlawrence6809** 说他刚让 Claude 一步步带他翻新了一台 90 年代的 Rohde & Schwarz 信号发生器：「花 60 块钱拿到一件几千美元的设备感觉挺酷的，哪怕你根本不知道拿它干什么。」tverbeure 问是不是他之前博文里翻新的那台 R&S AMIQ，对方说是 SMIQ03E，并且承认自己最近「相当上瘾于逛本地二手电子店，见到带 RS232 口的东西就翻」。他那台是放在收货区、因为电源键坏了「as-is」出售的，换了个按键加换电池就到手了。这条线后来变得很技术：**mikewarot** 说他朋友买了台 SMIQ-03b，换掉了那颗「似乎总会坏」的 MMIC 放大器芯片，现在在查 ALC 为什么不工作——信号能正常产生，但精细衰减完全无效。jlawrence6809 说他遇到的问题很接近：报 "IQCON ALC loop failure"，Claude 帮他诊断出 2013 号电源轨在 11.44V 左右（超出 10V 范围），2015 号是 0 而不是最小 0.13V。他随后提了个值得琢磨的问题：**「我在想这些 agent 是不是会让人们能接上的每一件设备的实用性都增加。」**（顺带一提，他把 SMIQ 错说成 VNA，被 **beala** 纠正：那型号没有矢量网络分析能力，不过如果他在同一家二手店再淘到一台频谱分析仪，两者可以组合成标量网络分析仪。）

**wkjagt** 讲了个同类故事：他不久前买了台 386 笔记本，「几乎所有东西都坏了」，修了好几周——「我花过的最值的 40 块钱」。tverbeure 回敬了自己的 40 美元惨案：一台 SRS DG535，「花了我好久才搞明白」；他说东西终于能用的那一刻感觉棒极了。

**slhomme** 贡献了本帖最跑题也最有画面感的一条：他几个月前才第一次接触示波器，从一个科研实验室买了一台，为了个人项目把内部掏空、塞了台迷你 PC 进去，现在用它跑 AI 模型——接了 OpenAI 实时语音、grok bot、Claude Code 等等，即便主电脑关着也能对它下指令。他说主要就是喜欢那种复古又现代的外观。**aa-jv** 惋惜地补了一句：「可惜你不能再拿它当示波器用了。」

**关于实际需求的清醒声音：** **jhallenworld** 说 1GHz 是不错，但那台小小的 200MHz Siglent 在实践中对大多数事情有用得多；他正在争取让公司买一台 DSA91304a（13GHz、带 SERDES 调试的示波器），带全部选件约 4.4 万美元，而且还是跑 Windows XP——Windows 7 的版本反而没有他想要的选件，「也许有什么 hack 吧」。tverbeure 呼应说：正如文章里写的，这台 TDS7104 现在就摆在车库架子上，旁边是一台 Agilent 54831 和其他几个「船锚」；他的日常主力是一台 Siglent 和一台袖珍的 TDS220（后者即将被他正在救活的 TDS3052 取代）——**「爱好者很少需要超过 100MHz 的带宽」**。他还嘱咐对方：希望你在掏 4.4 万之前能把那台 DSA91304a 彻底测一遍。**Gibbon1** 对 TDS220 的评价很妙：「小可爱。现实是，你只能希望那就是你需要的全部。」**Tangurena2** 提醒别忘了 TekWiki 这个资源。

另外 **milleramp** 提到 TDS500/600/700 系列可以通过**移除零欧姆电阻**来扩展内存。tverbeure 说他的 TDS754D 正等着做电阻和电容改造，把 500MHz/2GS/s 变成 TDS784D 的 1GHz/4GS/s——不过他补了一句：「输入一个容易生成的 license key，终究比拆电阻要少侵入一些。」

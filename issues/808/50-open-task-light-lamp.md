## 文章摘要

这是 YouTube 创作者 Steven Bennett 在 2026 年 8 月 31 日发布的一期约 20 分钟的项目复盘视频，主题是他终于完工的开源台灯项目 Open Task Light（简称 OTL）。用他自己在视频简介里的话说：「总算做完了。Open Task Light 是一盏受戴森 Solarcycle 启发的开源台灯，你可以自己动手做，也可以随心所欲地改造它。其实也没花多久时间。」——最后半句显然是自嘲，这个项目从立项到成品拖了相当长一段时间。

这个项目的定位很清楚：戴森的 Solarcycle Morph 系列桌面照明灯是设计与工程都相当出彩的产品，但售价高达数百甚至上千美元，而且完全封闭、不可维修、不可改装。Bennett 做的事情是把这类高端任务照明灯（task light，即为工作面提供高显色性定向照明的桌灯）的核心思路——细长的悬臂结构、可多轴调节的关节、高质量的 LED 光源与光学设计——用一套任何人都能复现的方式重新实现出来。

项目的开放程度是它最大的卖点。所有设计文件托管在 GitHub 仓库 `stevenbennett/Open-Task-Light`，装配指南单独做成了一份 GitBook 文档（open-task-light.gitbook.io），照着走就能从零装起来。对于不想自己找料的人，他也在 opentasklight.com 上出售成套的零件 kit，等于给这个项目留了一条自筹资金的路——这是很多单人开源硬件项目最后能不能活下来的关键。视频本身则是把整个设计过程、踩过的坑、以及最终成品的效果串起来讲一遍。

从更大的图景看，这是近几年「开源硬件对标高端消费品」这条路线里的一个典型样本：不追求比原版更便宜的仿制，而是把设计意图公开，让用户获得改装权和维修权。台灯是一个门槛合适的载体——结构不算复杂，但对机械关节的阻尼手感、光源的显色指数和眩光控制都有实打实的要求，做不好一眼就能看出来。

考虑到 HN 社区对开源硬件、可维修性、DIY 项目历来相当买账，这条帖子的冷场大概率只是运气问题——发帖时间不巧、没能挤进首页，而不是内容本身不受欢迎。作为对比，同一期里其他几条帖子动辄四百多分、上千条评论。

由于评论区没有可供提炼的观点，这里补充原视频与项目文档里几个值得留意的信息点：

- **可自筹资金的开源硬件模式**：Bennett 同时开放了 GitHub 全套设计文件和付费 kit 两条路，既保证了「你可以完全自己做」的开源承诺，又给项目留了持续维护的经济来源。这是单人硬件项目里少见的兼顾。
- **文档分层**：设计文件放 GitHub、装配指南单独放 GitBook，说明他把「读代码的人」和「照着装的人」当成了两类不同受众，这在业余开源硬件项目里算相当讲究的做法。
- **对标对象选得聪明**：戴森 Solarcycle 是一个「贵得有道理但贵得离谱」的产品，正好落在开源复刻价值最高的区间——如果对标的是十几美元的宜家台灯，这个项目就没有意义了。

如果你对这盏灯感兴趣，最有效的入口不是 HN 讨论区，而是直接看 GitHub 仓库和那份 GitBook 装配指南。

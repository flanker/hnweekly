## 文章摘要

2026 年 8 月 28 日，OpenAI 在官网发布了一则极其罕见的、点名开火的公司声明：他们已通知 SpaceX，将终止向 Cursor 提供 OpenAI 模型的合同，拟定断供日期为 2026 年 11 月 12 日。

声明的逻辑链条是这样的。OpenAI 说这个决定「极其艰难」，因为他们非常在意自家模型对开发者的广泛可得性；他们之所以还是这么做，是因为「我们无法确信 SpaceX 会在我们的服务条款范围内使用我们的技术，这是基于我们与埃隆·马斯克旗下公司在合同问题上打交道的经验」。

接下来是全文最刺眼的两段事实陈述。OpenAI 直接写道：马斯克收购 Twitter（现已并入 SpaceX）之后，该公司违反了双方合同的条款（「以及其他许多公司的合同」）；今年早些时候，马斯克在宣誓作证时承认，xAI（现在也已并入 SpaceX）违反了 OpenAI 的服务条款——而这些条款与 xAI 自己的条款其实高度相似。

第三个理由指向即将发布的新模型。OpenAI 表示，与 SpaceX 这种量级的伙伴合作，他们通常依赖定制合同来确保合规与规模化安全；而随着 AI 能力推进，他们对确保新模型 **Astra** 被合规使用负有「新层级的责任」。他们与 Cursor 的定制协议里有一条控制权变更条款，允许 OpenAI 在被收购后的一个有限窗口期内取消合同。综合下来，他们的做法是：把取消日期拖到合同允许的最晚一天（给开发者最长的过渡期），但**不再向 Cursor 提供任何未来的新模型**。

结尾是标准的场面话：与 Cursor 合作近四年，对其团队和产品充满敬意，最受影响的是依赖 OpenAI 模型的开发者，会「竭尽所能」支持他们过渡。

需要注意的两个背景：Cursor 已被 SpaceX（马斯克把 X、xAI 都并了进去）收购；而所谓「蒸馏」（distillation）指用一个模型的输出去训练另一个模型，这正是各家大厂服务条款里明令禁止的行为。

## HN 评论精华

851 分、上千条评论，是本期最热的一帖。讨论确实带有相当浓的行业站队和骂战成分，但主线之外也长出了不少值得看的分析。

**主线一：这到底是护法还是借刀？** `semiquaver` 是「站得住脚」派的代表：马斯克已经在宣誓作证时承认 xAI 在持续蒸馏 OpenAI 的模型，「不管你怎么看 IP 盗窃这件事，我也不会自愿跟一个正在明目张胆违反我条款的竞争对手做生意」。`ananmays` 则认为这是一步聪明的公关棋：OpenAI 长期本来就想结束与 Cursor 的合作，现在借着 Hugging Face 泄露事件的时机出手，理由「没法被轻易驳回」。`quicklywilliam` 提出最尖锐的反面意见：「别让 AI 公司控制叙事框架。这就是赤裸裸的反竞争行为，xAI 和马斯克惯常违法只是提供了一片遮羞叶。」`twobitshifter` 追问：在一个正常世界里，这算不算反垄断案件——毕竟 Cursor 是 Codex 的直接竞争对手。

**主线二：讽刺感。** `userbinator` 一句「在 AI 模型的语境下谈『IP 盗窃』真是有趣的讽刺」点燃了一整片。`aeternum` 补刀：「OpenAI 的模型就是从你们这些 HN 帖子里蒸馏出来的。」`cornholio` 写下了这一支里最完整的论述：AI 公司正在发明自己那套私人执行的版权制度、游说政府封杀不尊重它的外国竞争者，而过去五年他们一直在拼命对抗训练数据本身的版权；「如果任何一本书都能变成模型，因为这足够『转化性』、因为『AI 学习跟人一样』，那么一个模型蒸馏另一个模型当然也是转化性的合理使用。」`dannyw` 反驳说公司当然有权选择卖给谁，`cornholio` 再回击：合同法只约束签约双方、赔偿有上限，而版权是侵权法，国家会替创作者向全世界主张权利，赔偿是惩罚性的、可以直接把侵权者搞破产，甚至配有刑事执行体系——「认为私人服务条款享有与版权同等的公共保护，这个想法幼稚得可笑」。

**主线三：Cursor 到底伤不伤得起？** 多个用户提到 Cursor CEO 已经公开表示 OpenAI 模型只占 Cursor 总用量的约 5%。`ralusek` 说自己一个用 Cursor 调 OpenAI 模型的人都不认识；`npn` 解释原因：Cursor 上还有 Grok 和一堆模型，而 Grok 现在是被主推的首选，别的自然被边缘化。`dgrin91` 认为模型已经彻底商品化，99% 的用户根本不需要顶配模型，很多人干脆用 auto 模式，「大部分人不会感觉到任何影响」；他补了一句关键判断：如果 Anthropic 也跟进，影响才会真正致命。

**主线四：Anthropic 会不会跟？** `rgbrenner` 翻出旧账：Anthropic 今年早些时候已经以近乎相同的条款理由封过 xAI，去年也封过 OpenAI 和 Windsurf，所以条款里那句「不得用于构建竞品」早就存在。`frankacter` 提出重要的技术性反驳：那几个案例里公开材料只显示「你是主要竞争对手」这一条被触发，并没有证据表明真的发生了蒸馏——「我们不该在没有实证的情况下暗示还有别的违规」。至于 Anthropic 为何这次没跟，`Jcampuzano2`、`shuckles`、`throwaway240403` 给出了同一个答案：Anthropic 现在受制于 SpaceX 提供的算力（有人提到约 10 亿美元/月量级的数据中心协议），「他们要么不能切，要么懂得别咬喂饭的手」。`Jcampuzano2` 说得最重：考虑到 Anthropic 自己对 Windsurf 干过一模一样的事，还在这件事上出来说话「简直是伪君子的巅峰」。

**主线五：模型提供商正在往上游收网。** `redox99` 认为 Cursor 转卖别家 API 的商业模式本来就有倒计时，「不一定是因为供应商拔线，而是你根本没法跟被补贴的订阅制竞争」。`CoolestBeans` 写下了本帖最被认同的结构性分析：纯模型提供商现在处境极其难受——编程 Agent 掌握了你的需求端，英伟达、数据中心和内存厂商掌握了你的供给端，开源权重模型在下面挤压你；企业换供应商只需要改一个 API key，你既没有传统软件公司的迁移成本护城河，也没有它们的接近零边际成本，「把模型锁进自家 harness 至少还能换来一点锁定效应」。`satvikpendem` 说得更直白：「如果你真有一项改变世界的技术，为什么要卖 API 而不是自己把价值全吃掉？」`alberth` 提醒别高兴太早：「你怎么就假设 OpenAI 不会顺手也关掉 OpenRouter 的通道？」`ifwinterco` 一句话总结：这是 OpenAI（以及 Anthropic）意识到自己不小心卡在了整个技术栈利润最薄的那一层——推理——然后开始往外爬。

**用户侧的实际反应五花八门。** `bentt` 说讽刺的是这反而把他推回 Anthropic，因为他本来就不想直接给 OpenAI 掏钱；`DustinBrett` 说他会把 Sol 从选项里删掉而不是弃用 Cursor；`rippeltippel` 是少见的真心难过的 Cursor 用户，他的工作流正是用 Sol/Terra 做头脑风暴和规划、再让免费的 Composer 去实现；`chr15m` 反复强调一条原则：「不要让公司或 harness 替你决定用哪个模型，把自己放到能被这样摆布的位置本身就是有害的。」也有人趁机吵起 harness 优劣——`raincole` 说「我没见过哪个产品像 Claude Code 碾压 Cursor 这样把另一个产品打得这么惨」，`girvo` 则指出 Cursor 在企业里的惯性大得惊人，`disgruntledphd2` 说他基本不用 Cursor 的编辑器，但那个集成的代码审查 UI 太好用了，「不过好像现在除了我没人审查代码了」。

**最后是那句被反复引用的观察。** `skeledrew` 说：「我从没见过一家大公司这样毫无法律辞令包装地把另一家大公司扔到车轮底下，怀疑 OpenAI 官网是不是被黑了。」`mikeyouse` 给了答案：他们能跳过法律辞令，是因为马斯克已经宣誓承认 Grok 在蒸馏 OpenAI 模型，而且是在他还坐在 OpenAI 董事会的时候。`AirMax98` 补了一刀：「还挑周五晚上发。真狠。」

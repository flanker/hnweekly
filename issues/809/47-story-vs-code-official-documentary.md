## 文章摘要

这是 Visual Studio Code 官方频道发布的纪录片《The Story of VS Code》，时长约 **98 分钟**，发布于 2026 年 9 月 4 日，上线一周播放量已超过 50 万。

**「一个酝酿了十年的一夜成名」**

官方简介以 Erich Gamma 的一句话开场——他曾把 VS Code 形容为「一个酝酿了十年的一夜成名（an overnight success 10 years in the making）」。而那十年相当曲折：在成为世界上使用最广泛的开发者工具之一以前，VS Code 起步于一个在苏黎世做在线开发者工具的小团队，先叫 **Monaco**，再叫 **Visual Studio Online Monaco**，然后叫 **Ticino**（简介里加了一句「为什么不呢？」），接着变成一个桌面编辑器，然后开源，然后自身长成了一个生态系统，然后又回到了浏览器里，一路上还促成了一批开放协议的确立。而就在一切看起来最难的部分已经过去的时候——AI 来了。

**片子讲的是什么**

简介的定位是：这是 VS Code 如何走到今天的故事，由建造它的人和塑造它的开发者们来讲述；以及在 AI 改变代码编辑器的定义之际，它如何再一次自我调整。

纪录片由 **Stefan Kingham** 导演并制作，在一支全球摄影团队协助下完成，**拍摄从 2024 年 11 月一直持续到 2026 年中**。制作方鸣谢了 Microsoft、GitHub、Meta、Red Hat、GitKraken、Ona 和 AG Grid。

**章节结构**

官方章节时间轴基本勾勒出了整部片子的叙事线：

- **00:00 到开发者所在的地方去（Meet Developers Where They Are）** —— 全片的主题句
- **02:11 起源故事** / **09:04 你好，苏黎世** —— 早期的小团队时期
- **12:42 与 TypeScript 的协作** —— 一条被反复提及的关键线索
- **17:38 Monaco** / **22:53 Monaco Workbench 与 Visual Studio Online Monaco**
- **26:17 Node-Webkit、Electron 与走向桌面** —— 从浏览器转向桌面的关键转折
- **30:08 VS Code 发布** / **34:05 开源与扩展** / **42:23 社区反响**
- **46:33 任何语言：LSP** —— 语言服务器协议
- **54:33 你好，雷德蒙德** —— 团队与微软本部的关系
- **59:51 任何环境：远程开发**
- **1:08:45 任何开发者：无障碍（Accessibility）**
- **1:13:48 AI 转向** / **1:15:07 GitHub Copilot** / **1:18:51 AI 时代的 VS Code**
- **1:27:37 那些分叉（The Forks）** —— 显然指 Cursor、Windsurf 等基于 VS Code 的 AI 编辑器
- **1:33:48 不发布就等于不存在（Unless It Ships, It Doesn't Exist）**

「任何语言 / 任何环境 / 任何开发者」这组三段式相当清楚地概括了 VS Code 的扩张逻辑：先用 LSP 把语言支持问题变成一个可以被任何人实现的开放协议，再用远程开发把编辑器和运行环境解耦，最后是无障碍能力上的投入。

**出镜阵容**

受访名单相当有分量，包含了 VS Code 的多位创始工程师（Dirk Bäumer、Alexandru Dima、João Moreno、Benjamin Pasero、Johannes Rieken）、原始负责人 **Erich Gamma**（也是《设计模式》GoF 四人组之一和 Eclipse 的核心人物）、现任 VS Code 负责人 Kai Maetzel、TypeScript 联合创造者 **Steve Lucco**、GitHub Copilot 创始人 **Oege de Moor**、微软开发部门前总裁 Julia Liuson、Scott Hanselman、Amanda Silver、Chris Dias 等。

同时也有大量微软之外的声音：GitLens 作者、GitKraken CTO **Eric Amodio**，Red Hat 的 Max Rydahl Andersen 和 Görkem Ercan，Gitpod 联合创始人 **Sven Efftinge**，Ona 联合创始人 Christian Weichel，Google 的 Jaana Dogan 和 Addy Osmani，Meta 的 Stephen Kreyenbuhl 与前 Facebook 工程师 Michael Bolin，以及 Syntax.fm 播客的 **Wes Bos**。

一个有点应景的细节：简介注明字幕是「用 VS Code 里的 GitHub Copilot 配合 GPT-5.6 Sol 翻译，然后由人工审阅和修订的」。

## 文章摘要

Newton's Orchard 是一个跑在浏览器里的三维引力／天体力学模拟沙盒。作者 Andrew Childs（HN 用户名 **andrewchilds**）在 Show HN 帖子里讲了它的来历，这段自述比页面本身信息量大得多——因为站点是一个纯 SPA 骨架，所有内容都在 JS 里。

**起源：给儿子做的**

他儿子五年级时花了很多时间玩 PhET 的二维引力／轨道模拟器（科罗拉多大学那套著名的 STEM 教学模拟工具），学校的 STEM 课在用，回家也接着玩，然后开始想要更多。作者找遍了网上的太空模拟器和沙盒，包括 NASA 官方的 Eyes on the Solar System，但没有一个能在 PhET 的基础上提供**真正的进阶路径**。于是他用一个暑假做了 Newton's Orchard。

项目是开源的，源码在 GitHub 上（`andrewchilds/newtons-orchard`）。

**核心功能**（作者自述 + 从 JS bundle 中提取的界面文案）

- **确定性的时间擦洗（deterministic time scrubbing）**：可以自由前后拖动时间轴，结果完全可复现；支持倒回起点
- **所有天体都可编辑**：可以直接创建新天体、修改任意天体的参数
- **多套预置系统和实验**，包括太阳系、双星系统、TRAPPIST 等
- **任务系统**：完成任务解锁内容——完成三个任务就能解锁**黑洞**天体类型和对应的黑洞任务
- **用户作品画廊**：可以把自己搭的系统提交上去，也能加载别人的；支持把系统导出／导入为 JSON
- **参考系可切换**：可以把任意天体（或质心 barycenter）固定在原点，但物理计算仍然保持惯性系
- **两种轨迹绘制模式**：一种是所有轨迹都相对于视图中心绘制，另一种是**让每条轨迹围绕它所环绕的天体绘制**，这样一颗卫星在任何视角下都能显示出自己的椭圆轨道
- **预测轨迹**：选中的天体会显示一条虚线的前向积分路径
- **宜居带可视化**：根据每颗恒星的质量估算并着色出类地行星能维持液态水的轨道带——界面里明确标注这只是粗略参考，不是结论
- **黑洞引力透镜**：可以打开光线弯曲效果，渲染爱因斯坦环、恒星光弧和被放大的黑洞阴影，同时会扭曲附近轨道的视觉呈现
- 相机可以锁定跟随任意天体；恒星有后期处理的辉光效果（在弱 GPU 上可以关掉）；天体半径可以夸张放大以便观察；轨迹长度按"天"为单位调节
- 参数调节支持拖拽，按住 Shift 粗调、按住 Alt 微调；有完整的键盘快捷键

作者在 HN 上明确说明了他最想要的反馈方向：**如何让它对学生更有吸引力、更有启发性**，以及如何让任何想直观感受引力如何运作的人都能上手。

## HN 评论精华

这个帖子只拿到 32 分、7 条评论，讨论很稀少，这里如实呈现全部有实质内容的发言。

**最有分量的一条来自 fourfire**，它几乎直接验证了作者做这个项目的初衷：「我最近试着用手绘草图向我女儿解释地球和太阳的关系，但不太直观。今天我把这个页面给她看，她看了一会儿之后，好像理解得清楚多了。她非常喜欢这种动态的可视化。」作者 **andrewchilds** 的回复只有一句：「听到这个太好了！谢谢你！」

**xtiansimon** 提了个把它往游戏方向拓展的想法：他想发射飞船、像《家园》（Homeworld）那样打一场太空战。「我不算重度玩家，但我喜欢完整三维战略的想法。不过《家园》在朝向上有个锁步机制，我觉得那是个错失的机会。」作者的回应透露了一个尚未实现的计划：「我想过加一个飞船模式，让你能在自己搭的星系里驾驶飞行、做引力弹弓之类的操作。**底子已经在那了。**」

**tonygoodchild** 半开玩笑地问：「能不能用它来帮忙解决三体问题？:)」

## 文章摘要

Simon Willison 这篇短文梳理了 2026 年 9 月初数学界与 AI 圈交叉处的一场风波：OpenAI 用一个未发布的内部模型给出了**纳维-斯托克斯存在性与光滑性问题**的解决方案——这是 2000 年 5 月 24 日设立、单项奖金一百万美元的七个千禧年大奖难题之一。但这项成果被一场关于学术操守的指控严重遮蔽了。

**指控来自谁**。提出质疑的是 NYU 数学教授 Tristan Buckmaster，他当时正与 Levent Alpöge（一位成就卓著的数学家，目前受雇于 Anthropic）合作研究相关问题。Buckmaster 的控诉伴随着他们自己匆忙发布的结果一同公开，并附有一份说明事件经过的 PDF。

**事件时间线**（据 Buckmaster 一方的说法）：两人在这个问题上工作了将近一年，期间大量使用 Claude 和 Codex（主要是 GPT-5.6 Sol），并在 8 月 15 日取得突破。数学界的传言机器随即启动，Buckmaster 和 Alpöge 听说 OpenAI 听说了"Anthropic 解决了一个重大公开问题"，于是主动联系 OpenAI，得知对方有一个团队在做相关问题、而且路径相似。Buckmaster 在文件中写道：他问对方第一条 prompt 是什么时候发出的，这个问题一度没有得到直接回答，最终各方认定是在**最近几天内**，也就是在他们的工作消息传到 OpenAI 之后；他还问模型是否在他们的 Codex 会话（整个项目期间他们把所有草稿都放在里面）上训练过或有访问权，得到的回答是模型不会查询用户数据；他再次追问训练问题，**没有得到答复**。

事情进一步复杂化：OpenAI 团队提出可以等 Buckmaster 先发表，或者请他作为作者参与一篇关于 OpenAI 成果的论文——但明确表示，**由于 OpenAI 与 Alpöge 雇主之间的竞争关系，不会邀请 Alpöge 共同署名**。

**OpenAI 一方的叙述**。他们说 9 月 1 日星期二听到两个千禧年问题被解决的传言，受传言和内部模型性能阶跃的激励，启动了一项针对所有未解千禧年问题及若干高影响问题的评估；智能体在 9 月 5 日星期六给出解答，距首批智能体启动约 88 小时，Lean 形式化与验证由 GPT-6 Astra 又花了 17 小时。规模数据是：所有尝试的问题合计发出 **490 万条消息、约 3000 亿输出 token**；仅纳维-斯托克斯一项就是 **270 万条消息、约 1300 亿输出 token**。Willison 顺手算了笔账：虽然不知道他们内部模型的成本结构，但按 GPT-6 Astra 的公开 API 价格，3000 亿输出 token 大约值 **1500 万美元**。

关于争议，OpenAI 的说法是：他们的行动始于 9 月 1 日，是在听到传言之后；在完成全部工作和 Lean 验证（9 月 6 日）后，因为相信对方也有一份纳维-斯托克斯的解，才主动联系提出同步发布、在联合声明中承认对方的优先权。关键的一段是（Willison 特意加粗）：研究者和智能体**在对方公开发布前没有通过任何途径看到他们的工作**，解决这个问题的过程中没有访问任何特定用户数据；**虽然可能性很低，但他们无法排除**从对方使用其产品中衍生出的去标识化数据曾帮助改进过模型；不过两份证明差异显著，在欧拉方程的情形下连所证的精确结果都不同（有强迫项 vs 无强迫项）。

**Willison 的解读**。他认为发生的事情是：OpenAI 听说有人用 LLM 解决了千禧年问题，把这看作展示最新模型威力的机会，**没有太认真考虑"抢发一个用 OpenAI 自家模型做了近一年研究的团队"在观感上意味着什么**。

他把这件事与当下计算机安全领域正在发生的变化对照：Anil Madhavapeddy 最近指出，如今**光是一个漏洞存在的传言就足以让人找到利用方法**——因为只要知道某个软件有未修补的漏洞，就可以让智能体去把它找出来。Willison 问：数学是不是也一样了？**光是知道某个问题存在一个未发表的解，就可能触发数百万美元的 LLM 支出去抢先抵达。**

文章最后回到他长期的困惑：当 AI 实验室说我的数据被"用于改进模型性能"，这到底意味着什么？他过去最喜欢的两个假想问题是：如果我跑 Codex 时不小心让一个 API key 进了上下文，将来别人问 API key 时拿到我这个的概率有多大？（他曾问过 OpenAI 的人，对方称之为"复吐"（regurgitation）问题，保证他们为防止此事煞费苦心，但不肯说怎么做的。）如果我用 ChatGPT 头脑风暴公司的新方向，这些信息半年后被问"X 公司接下来可能做什么"的竞争对手看到的概率有多大？而他现在最喜欢的版本是：**如果我用 ChatGPT 帮我部分解决了一个千禧年大奖难题，我的工作影响训练、从而让后来的模型帮别人抢先解决的概率有多大？**

## HN 评论精华

这条帖子拿到 231 分、229 条评论。与文章本身的克制相比，评论区的态度要激烈得多，而且讨论明显分成了"学术伦理"和"LLM 到底在数学上做了什么"两条主线。

**署名问题被认为是最不可辩护的一点**。avs733 自称身在学界但不是数学家，他说得最系统：在学术圈**只要你在署名上动手脚，你立刻就是可疑的**，任何严肃的学者都不该考虑这种事。署名反映的是谁做了工作，为了商业竞争理由去改动它是多重意义上的红旗——把一项重大理论进展首先当作竞争站位来处理的无礼、违反学界规范、以及人们现在会怀疑表面之下还藏着多少对学科文化的误解。他还科普了数学这个学科在署名上的独特性：长期以来的规范是**按字母顺序署名**，因为在数学里定义第一作者、第二作者、通讯作者比其他领域困难得多；他引用的说法是，字母序把合著当作智识上的共同工作，每个名字分量相同，没人需要为排名去谈判——相比位置编码的惯例（"谁是第一作者"是署名冲突最常见的来源之一）这是实打实的优势。这个规范正在缓慢变化，其中一个方向值得注意：**随机作者顺序**，因为有人认为字母序也有偏见。"这就是 OpenAI 向一位学者提出署名、同时要求他排除自己搭档时，所踏入的那个世界。"他最后说：我不能对此事其他事实置评，但如果一个研究生告诉我有人向他提出这种条件，我会让他赶紧跑，如果他够勇敢就去举报。emil-lp 简短附和："学术不端毫无疑问，我认为整个数学界都同意这一点。"

不过 sobellian 给出了 OpenAI 一方的澄清（引用 Sébastien Bubeck 的说法）：OpenAI 的叙述是他们发现两边的路径不同（欧拉方程 vs 纳维-斯托克斯方程），随后向 Buckmaster 提出的是**他们那份证明的第一作者身份**（不含 Alpöge），但他们从未要求把 Alpöge 从欧拉方程正则性成果的共同署名中剥离。

tyre 的评价很直接："OpenAI 这事干得挺烂的，可惜并不意外。仅仅因为他在 Anthropic 工作就想排除一位作者，暴露了他们（那部分）组织内部的文化。焦点不是支持学者或推进研究，而是拿到好的营销素材。如果为此要烧掉几百万美元去解一个**他们认为已经被解决的问题**，他们也会干。"

**"传言是怎么传出去的"**。shellfishgene 指出故事里缺了一环：如果只有他们两人在秘密研究，突破怎么会变成传言？tyre 给出了最被认可的答案：**人是会说话的**。如果你在最著名的未解问题之一上取得突破，你一定会告诉别人；你会说"别告诉任何人"，而对方会无视这句话，因为分享能带来快感和地位感，然后他也会带着同一句"别告诉任何人"告诉下一个人。学术数学圈加上一个在 Anthropic 的人，这个世界小到只需要很少几跳就能到 OpenAI。

dboreham 补充了一个精彩的历史类比来说明"知道某事被做成了"本身的威力：德国发射 V2 原型火箭时，英国知道它的大致弹道、并通过谍报知道大致尺寸。此前英国人一直认为弹道导弹不可行，因为没有引擎能提供必需的推重比；但既然德国人明摆着发射成功了，他们就把所有已知的化合物过了一遍，反推出了实际使用的组合（乙醇和液氧）。（出处：R.V. Jones《Most Secret War》。）

**时间线的技术可行性被认真拷问**。rao-v 提出了这条讨论里最冷静的分析：担心聊天数据进入模型是合理的（虽然他认为实际进入的可能很少——精心筛选训练数据和制造更高质量的合成数据似乎才是当前做法），但**他没法把时间线和这个担心对上**。他不认为训练流程有接近于"持续训练"的程度，足以把 8 月 15 日的想法吸收进一个 9 月初就能产出突破的模型。所以要么 OpenAI 赤裸裸地让某个懂数学的人去翻了特定用户的对话（那是巨大的红旗），要么这真的是一次经典的平行发现被糟糕地处理了（其中一方明显投入时间更长）。KeplerBoy 提出反面考虑："我会假设很多 Codex 数据回流进了训练。一个被良好引导的会话是极其宝贵的数据。"

Simon Willison 本人（simonw）在评论区回应了这一点：突破是 8 月 15 日，但 Tristan 和 Levent 借助各种模型朝这个方向工作了将近一年。"我个人怀疑他们的工作影响了 OpenAI 的结果——OpenAI 自己说的是'虽然可能性很低，但我们无法排除'——**但那句"无法排除"正是问题所在**。如果连 OpenAI 都无法排除他们使用 ChatGPT 对这一层结果的影响，那我对自己无法理解自己的使用如何影响其训练的那份不适感就被放大了。"

**数据隐私的结论**。sdcfgy 给出了最被赞同的一条实用结论（他自称"纸面上"是数学家，且对这个问题本身并不特别在意）："我从这整场闹剧里带走的是：**不应该把机密或专有信息交给 LLM 服务，因为它们看起来都是混蛋在经营**。而你把自己做的一切都发给了他们。你会把实验记录本寄给一个混蛋吗？绝对不会。"junofan 泼了盆冷水：普通订阅用户的隐私政策里用大白话写着他们会把你的个人数据用于研究，"用着这个服务还指望别的，我觉得挺不讲理的"。walrus01 则说："等你知道有多少 SaaS、Web 2.0 和云服务也是混蛋在经营的时候……你知道'乌龟驮着乌龟'那个比喻吗？只不过把乌龟换成混蛋。"pansa2 觉得这本就是常识："就像你不会把机密文档传到在线拼写检查器，或者把专有代码传到在线编译器一样。"Blikkentrekker 从另一个角度感到不安：**这件事真正令人担忧之处在于它说明本地运行的模型还不够好**——像他们这样的研究者当然有算力在本地跑模型，他们缺的是训练可比水平模型的算力。他担心开源会被甩下：Leela Chess Zero 曾靠志愿者贡献算力做到与 AlphaZero 可比，但如今最好的模型都把东西锁起来了，图像生成领域也一样。johanvts 问有没有隐私优先的 LLM 公司（他提到 Proton 的 Lumo）。hn993302 的总结最短："或者说，如果你要信任其中一家，也许不该是 OpenAI。"

**LLM 到底在数学上做了什么**。civvv 提出了怀疑派的核心论点：LLM 似乎特别擅长解决**训练数据里已有海量既有工作和尝试**的数学问题；这是了不起的能力，但不能说服他这些模型在以人类的方式"思考"或"推理"。一位人类数学家理论上可以在明天基于纯粹的人类智能开创一个全新的数学领域；如果明天出现一个全新领域里的全新问题，他强烈怀疑 LLM 独自能有任何用处——"这是不是终极 ASI 测试？"

反驳来得很密集。eru 指出人类做的很多事本身就是**旧想法的组合**，而且 LLM 理论上也可能撞上全新想法（生成推理和答案的过程里有随机性）；他认为当下很多进展来自 LLM 把已有但相对冷门的知识组合起来，这一点它们比人类强得多——毕竟它们早在变强之前就以"读过几乎所有语言的每一篇论文和每一本教科书"著称，从那里只要智力再提高一点，就能抵达人类知识的"凸包"。krona 给出了一个技术上的思想实验：极高的温度（>2.0）能把 GPT 推离它的流形，产出几乎与随机噪声难以区分的预测；理论上这能预测出任何东西包括下一个数学领域（无限猴子定理），但现实中不会发生——"不过，我们怎么知道下一个数学领域不是若干子领域的新颖组合呢？"paxys 给出了最平衡的一条："那种独自开创整个科学领域的人，一代人里只出现几次。说 AI 远不及他们聪明是可以的，但它可以类比于那个**在别人工作基础上再往前推一点的'普通'数学家**。"bonplan23 的回击最简洁："如果明天出现一个全新领域里的全新问题，我也高度怀疑一位人类数学家独自能有任何用处。"

**为什么 LLM 能做数学却写不好数学库的代码**？aadyachinubhai 提出这个问题，matrix2596 用三个词回答："搜索、可验证性、算力。"vbarrielle 展开了这个机制：数学问题的陈述方式常常使得**解是否正确可以被自动验证**，这意味着"推测一个路径（LLM 或 prompt）→ 实现它（LLM）→ 检查（自动）"的循环是可行的；你仍然需要非常好的 LLM 和非常好的 prompt 提供有趣的研究方向，否则可能永远循环下去。emil-lp 给出了一个优雅的类比：数学论文很像软件——**定理是 API，引理是内部/私有函数 API，定义是类型，证明是实现**；ChatGPT 的证明不一定可读或可维护。linkgoron 的补充直击要害："你不需要一个**好**证明，你只需要一个证明。"recursivecaveat 提出了一个重要的限定观察：**目前所有重大公告据他所知都是反例或对既有结果的形式化**——不一定是能暴力破解的，但都是"投入体力就有高回报"的领域。lhd1 也提醒说这个结果虽然惊人但并非完全出乎意料——过去十年该问题上有大量进展，没有那些进展今天的完整解决不太可能；专家会仔细审查这份证明，**看看除了已知技法之外是否真的做了什么原创或出人意料的事、有没有属于数学的"第 37 手"**。

dguest 补了个关于署名的题外话，读来颇有荒诞感：在某些领域，署名其实更像一种**正式的位阶**——一旦进了这个组，每篇论文上都有你的名字；相当一部分"作者"根本不知道有一篇论文正以他们的名义发表，绝大多数人一个字都没读过。"在这些领域里，**不出现在论文上**反而相当有挑战性。"

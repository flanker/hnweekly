## 文章摘要

这是 Hacker News 每月固定的"谁想找工作？"（Who wants to be hired?）帖子，与"谁在招人？"配套，供求职者张贴自己的求职信息。帖子要求发布者按统一格式填写：所在地点、是否接受远程、是否愿意搬迁、掌握的技术栈、简历／CV 链接以及联系邮箱。

从本期的求职帖来看，地域分布相当全球化：欧洲（西班牙、英国、罗马尼亚、瑞士、葡萄牙、德国）声势不小，亚洲（印度、新加坡、马来西亚、泰国、孟加拉国）参与者众多，美洲（加拿大、美国、巴西）也有充分代表，其中不少人明确寻求签证担保或搬迁机会。工作方式上，绝大多数求职者偏好远程岗位，许多人强调时区弹性——即便身处全球各地，也愿意配合美国或欧洲的工作时间。

技术栈方面，后端技能占主导，Python、TypeScript/Node.js、Go、Java 最为常见；AI/LLM 方向的能力被大量突出，RAG、LangChain、Claude 集成、智能体（agents）等关键词频繁出现。云平台以 AWS 为主（约六成帖子提及），GCP 和 Azure 次之；数据基础设施常见 PostgreSQL、Kafka、Redis；全栈组合多为 React/Next.js 搭配 FastAPI 或 Node 后端。从资历分布看，资深工程师（8-20 年以上经验）约占四成，中级（3-7 年）约三成半，初级／应届约一成半，其余为专精或兼职（fractional）角色。

## HN 评论精华

与"谁在招人？"一样，这类帖子的每条"评论"本身即是一份求职简介，因此不存在传统意义上的高赞观点争论。以下列举几则有代表性的求职帖，以呈现本期求职者的整体面貌：

- **ML 基础设施工程师**：一位来自印度海得拉巴的工程师，自述"痴迷于让 LLM 驱动的工具在规模化场景下做到高性能、可预测、可靠"，需要签证担保。

- **全栈创始工程师**：一位常驻安道尔的资深开发者，拥有"15 年以上资本市场技术经验"，希望从事交易基础设施、算法交易、AI、市场数据相关的工作。

- **设计工程师**：一位来自冰岛的从业者，"15 年以上从 0 到 1 打造产品"的经验，兼具设计系统专长与全栈能力，不接受搬迁。

整体而言，本期求职者中 AI/LLM 相关技能与远程办公诉求高度集中，反映出当前技术就业市场供给侧的鲜明取向。

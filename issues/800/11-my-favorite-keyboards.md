## 文章摘要

知名技术作者 Fabien Sanglard 在这篇随笔中回顾了自己多年来用过、爱过的一系列键盘。故事从他早年使用 Sinclair 和 Thomson 机器的糟糕体验讲起，直到 1993 年他第一次接触到 IBM Model M——那种打字机般的手感和标志性的"咔哒"清脆声让他一见倾心。2011 年他在多伦多一家电脑店淘到了好几把 Model M，此后用了将近十年，同时也对 8BitDo 推出的现代版 Model M 复刻款颇有好感。

文章还介绍了几款有故事的键盘。IBM Model M SSK 是 84 键的紧凑省空间版本，作者在 2025 年组装一台复古 PS/1 时才发现它，觉得它在桌面布局上比完整的 101/102 键更符合人体工学。另一把 NMB ConcertMaster RT-9100W 则因为是 John Carmack 在 id Software 开发从 Quake 到 Doom 3 期间使用的键盘而闻名——虽然它的薄膜结构手感不如 Model M，但其音质和内置扬声器系统出人意料地出色。

最后两款是分体式人体工学键盘。Ergodox EZ 帮他解决了长时间打字带来的 RSI（重复性劳损）问题，用了十年，但倾斜时底座不稳一直让他困扰。而他现在的最爱是 Moonlander——拥有 Ergodox EZ 的一切优点，但倾斜时更加稳固，他甚至觉得这可能是自己的"最后一把键盘"。

## HN 评论精华

- **键盘布局之争**：**eimrine** 认为任何 QWERTY 或类 QWERTY 布局本身就很"傻"，在不解决真正瓶颈的前提下换成直列（ortho）键盘，好比把欧宝换成保时捷却仍装着方形轮子。这引出了关于布局重要性的一系列讨论。

- **对 Model M 崇拜的质疑**：**frou_dh** 直言 Model M（如今的 Unicomp）崇拜其实是一种"梗"——弯曲弹簧结构手感独特有趣，但从人体工学和速度角度看并不适合大量打字，它是新奇玩物而非终极键盘。

- **更彻底的人体工学派**：**throwawaySimon** 和 **EnnEmmEss** 都指出，真正在意人体工学的人不该止步于 Ergodox、Moonlander 这类"半吊子"方案，而应看看 Kinesis Advantage、Glove80、Maltron 这些做过真正人体工学研究的产品，凹陷式（contouring）键面对减轻左手负担帮助最大。**dgroshev** 也惋惜文章漏掉了 Glove80，认为它几乎在各方面都胜过 Moonlander。

- **Moonlander 的塑料手感争议**：**gempir** 抱怨 Moonlander 廉价的塑料外壳会吱吱作响、晃动，从全金属机械键盘转过来后很难满意，最终换成了介于两者之间的 Neo Ergo。**Cthulhu_** 和 **yuppiepuppie** 则讨论了 Moonlander 的适应难度以及键盘鼠标切换的尴尬问题。

- **Topre 拥趸**：**chao-** 分享了自己钟情于 Topre 静电容轴（尤其是静音的 Type-S）的经历，用过 HHKB、Leopold FC660C 和 Realforce，唯一遗憾是无法把 Topre 轴单独装到 ErgoDox 那样的分体键盘上。

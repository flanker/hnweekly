## 文章摘要

OOMWOO 是一个面向创客（maker）的自己动手造扫地机器人项目。作者将它描述为"一台你可以自己搭建的开源家用扫地机器人"，把易获取的硬件与完全开源的软件、固件结合在一起。项目强调"本地优先"（local-first）的理念："无需云端，无厂商锁定"（No cloud required. No vendor lock-in.）——用户对设备拥有完全控制权，不依赖任何云服务，未来才可能酌情加入可选功能。

技术层面，它采用 2D LiDAR 建图，配合 ROS 2 / Nav2 实现自主导航；主控为运行 ROS 2 的 Raspberry Pi 5，另有一块基于 STM32 的 I/O 板负责管理电机与传感器；原生兼容 Home Assistant，实现本地控制；机身为 3D 打印底盘，零件多从 AliExpress 采购。

项目目前尚处于早期硬件选型阶段，但软件开发环境已就绪、可在仿真中测试。第一个里程碑 v0 的目标是做出一台可用的基础版扫地机：3D 打印结构件、基础 SLAM 建图、在 Raspberry Pi 上跑 ROS 2。成本方面，目标是零件约 100-200 美元（另加 Raspberry Pi），力图以此实现 500-600 美元商用扫地机的功能。所有选型信息和搭建说明都对社区开放。

## HN 评论精华

评论区呈现两条主线：一是对博客文章明显是 AI 生成（"AI slop"）的不满，二是对"开源、可维修硬件"这一方向的真诚期待，二者常常交织在同一条评论里。

- **frio** 表达了对"AI 味"内容的疲惫：这看起来是个有用的东西（现有闭源扫地机上的摄像头让他很不安），但连announcement 博客都不亲手写，让他对项目前景毫无信心。**jimnotgym** 反问："一篇 AI 生成的博客，难道不比'做出了有用的东西却没人听说'更好吗？"**jm4** 给出了更长的辩护：这很可能只是一个人的项目，若没有 vibe coding 它根本不会问世——几年前这样的软硬件项目得靠 Kickstarter 众筹几十万甚至上百万美元、聚集多学科专家团队才有一线机会。
- 围绕"vibe coded"的质量疑虑，不少人选择宽容。**shaunkoh** 说尽管是 vibe 出来的，他依然喜欢"开源可维修扫地机"的想法，因为现有产品出了名地不耐用、不好修。**fluidcruft** 表示自己会写代码，不在乎用什么方式起步，"他们在做硬件设计，这才是我在意的"，并会持续关注套件。
- 关于"扫地机是否真的不耐修"，出现了有力的反例。**RealityVoid** 讲述自己八年的 Xiaomi S6 轮组电机坏了，只拧一两颗螺丝就弹出模块、换上新电机搞定，如今转给父母还在用。这条评论对文章"现有产品不可维修"的前提提出了质疑。
- 一处技术性争论颇为典型：**darlachaps** 质问项目为何要跑 Valetudo（一个针对已 root 的闭源扫地机的产品），并直指其社区文化有毒；**fh973** 澄清 Valetudo 只是一个用来绕过厂商云、通过配套 App 控制机器人的 API 代理，并非机器人固件，在此项目中根本没有它的位置。
- 更宏观地，多人为开源硬件本身欢呼。**holistio** 直言"说不出有多想看到开源硬件成长"，**sqdiaz** 认为可更换零部件才是开源设备的真正卖点，**utopiah** 推荐了 crowdsupply.com 供购买与自售参考。也有实用建议，如 **wisdomseaker** 追问扫地机为何总是圆形、加一个 90 度直角区段是否更利于清扫墙角，**stevewodil** 回答中高端机型多用可伸出的边刷臂来处理边角。

## 文章摘要

Zamzar 联合创始人 Chris 与 Mike Whyley 回顾了这个文件转换服务从 2006 年至今的经历。他们最初只是想解决打不开文件、又不想下载安装复杂工具的问题；二十年后，公司仍是一家小型、独立的英国企业，没有风险投资，也没有把追逐每一轮技术热点当作使命。

按创始人公布的数据，平台累计转换超过 7.66 亿个文件，支持的转换类型从最初 150 种增加到 2,128 种，每天处理超过一百万次 API 请求。他们还说累计有超过 5.5 亿人使用过服务。上述数字均是企业自述，本摘要没有独立审计；尤其累计使用者不能直接当作付费订阅人数，更不能据此反推出收入。

文章中更具体的价值来自长期兼容性需求：团队帮助恢复旧演示文稿、处理古老 eFax 文件，并与 Xerox 合作将文档转成语音。他们也承认有些要求无法满足，例如某些缝纫机图案转换。面对不断变化的软件生态，一家专注格式转换的小公司仍能靠零散但真实的问题积累客户关系。结尾感谢多年参与的团队成员，也提醒读者这并不是「两个创始人独自维持全部业务」的故事，而是独立融资路线下长期经营和协作的回顾。

## HN 评论精华

**累计用户不是订阅人数。** 面对把网站价格乘以 5.5 亿人的推算，[andai](https://news.ycombinator.com/item?id=50323771) 提醒其中并非都是付费用户，平台也有付费 API。

**成功未必意味着无限追求规模。** [throwaway83772](https://news.ycombinator.com/item?id=50323527) 将这类经营目标理解为足以过舒适生活，而非让财富目标不断上移；这是读者对创业动机的解读。

**AI 的竞争影响尚无结论。** [piker](https://news.ycombinator.com/item?id=50323423) 询问编码代理兴起是否影响营收，后续争论主要是对普通用户习惯的猜测，不能据此宣布业务不受影响。作者 [whyleyc](https://news.ycombinator.com/item?id=50335248) 则在另一支讨论中确认音频转文字是实际用途。

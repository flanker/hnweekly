## 文章摘要

Rikiya Takehi 等人的研究博客提出「权重空间编程」：让通用语言模型依据自然语言目标，直接分析或修改另一个神经网络的参数，而不是编写训练循环、执行梯度下降。作者报告了从小型游戏网络到语言模型的多组实验，包括根据权重判断网络学过哪款游戏，以及为给定架构写出游戏策略。这里必须区分两种设置：小网络的全部参数可以作为文本交给模型，部分任务禁止工具；较大的网络则允许 Python 分析、权重操作，某些实验还允许受限的前向运行。

最受关注的是 Qwen3.5-0.8B 实验。按作者报告，在允许 50 次批量前向评估的条件下，Astra 找到与重复推理有关的方向，修改 131,072 个权重，约占总参数的 0.016%。在文中指定采样参数下，MATH-500 从 7.9% 提高到 48.1%，IFEval 从 21.0% 提高到 62.3%。这不能直接解读为模型凭空学会新数学知识：主要改善来自减少循环、让已有能力产生完整答案。作者另测了较少循环的 Gemma 3 270M，没有得到可靠的数学提升；仅看权重辨别迎合行为的尝试也失败，加入注意力观测后才成功。文章提供实验日志，但仍属早期研究报告；上述数字是作者结果，本期未独立复现，更不能据此断言通用递归自我改进已经实现。

## HN 评论精华

- **区分读数字与用工具研究参数。** [jablongo](https://news.ycombinator.com/item?id=50343288) 指出修改语言模型的实验包含提出假设、编写分析代码和查看权重数学性质，并非看见某个数字就直接知道该怎样改。

- **修复循环不等于教授数学。** [l9o](https://news.ycombinator.com/item?id=50342593) 认为 Qwen 原本已有相关能力，只是输出被循环阻断；同时提到不易循环的 Gemma 没有改善，提醒读者收窄结论。

- **负结果同样重要。** [epihelix](https://news.ycombinator.com/item?id=50347338) 把 Gemma 实验视为关键限制：结果令人印象深刻，但距离随意提升任何模型还很远。

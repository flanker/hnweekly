## 文章摘要

OnKey 是一款面向 Apple Silicon Mac 的开源唱歌练习工具。用户用原有音乐软件播放歌曲，应用先听一遍、在本机分离人声并分析旋律，之后把目标音高与麦克风捕捉到的音高叠在一起，提供逐句评分。它本身不提供或下载歌曲，支持系统音频录制的最低系统版本为 macOS 14.2。

README 说明，歌曲分析和个人录音留在本机，但识曲指纹、歌词查询、封面与更新检查仍涉及外部服务，因此「本地处理」不等于完全没有联网请求。作者也坦承，复杂伴奏可能干扰主旋律提取，有时会判断错八度，评分偏向初学者。它更像把抽象的跑调感受变成即时视觉反馈，而不是一位完整的声乐老师。仓库还区分了个人练习和公开分享：不能因为应用可以捕捉声音，就假定歌曲或旋律转录可以随意再发布。

## HN 评论精华

**算法选择经过迭代。** dsmurrell 回复 HummingBirdGif，用户音高使用运行在 ONNX Runtime 上的 CREPE-tiny，原唱分析使用完整 CREPE，并结合人声分离工具。他还提到先建立评测集合，再比较候选工具。

**评分不涵盖全部歌唱能力。** enzoaguado 和 LluisGerard 强调呼吸、节奏、发声与情感表达的重要性，担心宽松评分给人过度自信。作者承认目前主要解决音准练习。

**跨平台便利与资源开销存在取舍。** viraptor 质疑 Tauri 界面的必要性；作者解释项目由 Python 和网页原型演变而来，并希望保留移植空间。他提供的包体、内存估算是个人说明，不是独立基准。

## 文章摘要

这条提交链接到 Stack Exchange Data Explorer 的月度提问查询，以“每月不足一千”描述 Stack Overflow 新问题数量的下降。它讨论的是新提问这一活动指标，不能直接等同于历史答案的使用量、访问人数、付费业务规模或整个 Stack Exchange 网络的健康状况。

本次查询页返回 403，未能独立重新运行 SQL 或检查最新月份是否完整，因此这里不把标题数字当作已经复算的统计结论。可确认的是，HN 讨论围绕长期下降展开，参与者把 AI 问答、严格的社区规则、重复问题关闭以及项目讨论迁移到 GitHub 等因素放在一起比较。

这件事的价值也在于提出一个知识生产问题：开发者仍然可以从已有答案获益，但如果新的经验不再公开沉淀，后来者能检索到的资料会怎样变化？这一担忧与“模型没有新数据就必然崩溃”是不同命题，评论区也没有给出证明。

## HN 评论精华

- **AI 还是社区文化？** p-e-w 认为近期急剧下降主要来自 AI；jdthorpe 则回忆，过度追求关闭问题和格式纯粹性早已损害参与体验。二者分别强调新增冲击和长期问题。
- **问题转移到了别处。** hatthew 认为，常见问题积累完成后，项目特定的问题逐渐流向 GitHub Issues，聊天式工具又接走了一部分临时求助。
- **失去的不只是训练资料。** werdnapk 担心新问题减少会削弱可供模型学习的内容；gwerbin 回应，工具调用可以读取文档和源码，更难替代的是人们公开交流使用体验与技术选择的过程。
- **不能以一个站点代表整个网络。** armchairhacker 提醒，其他 Stack Exchange 社区仍有阅读价值。不同领域、不同业务和不同指标应分别观察。

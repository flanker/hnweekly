## 文章摘要

（说明：原网站是纯前端 SPA，抓取时未能取到正文，以下内容主要基于作者 hmate9 的 Show HN 与讨论区还原。）

One More Letter 是一款每日更新的文字游戏，由 HN 用户 hmate9 发布。顾名思义，它的核心机制就是"再加一个字母"：从一组字母出发组出一个合法单词，随后每一轮都在原有字母的基础上再添加一个字母，并重新打乱重排（anagram），拼出一个更长的新单词，如此层层递进。规则上有一个关键约束——下一轮的答案必须把字母重新组合，而不能只是简单地在词尾追加一个字母，所以你得真正去"重排"而非"叠加"。

游戏节奏偏紧张：带有一个会自动开始的"猝死"计时器（sudden-death timer），时间一到就结束。它的界面打磨得相当精致，交错入场的字母动画和打字输入体验都获得了好评，是那种"坐飞机时会想拿出来玩一玩"的轻量小游戏。

不过首个版本也暴露了不少问题，成了讨论区反馈的焦点：一是词库判定过严，不少明明合法的单词（如围绕 KITERS、TRIKES 这类字母组合的重排）被判无效，让人反复"翻车"；二是缺少游戏说明，新玩家上手时常常搞不懂到底该怎么玩；三是那个自动启动的计时器很坑——如果标签页是在后台打开的，等你切过去时倒计时可能已经跑掉了。作者对这些反馈都做了积极回应，承诺尽快修复被误判的合法单词、加入空格键洗牌（shuffle）、并考虑上线一个没有计时器压力的"禅模式"（zen mode）。

## HN 评论精华

- **takencoder**：盛赞游戏的完成度"极佳"（fantastic polish），特别点名了交错入场的字母动画和顺滑的打字输入体验——这也是不少人愿意留下来玩的第一印象。

- **wrs**：反映了最普遍的痛点——合法单词被拒。他连续三次输入了自认为正确的真词却都被判无效，体验相当挫败。**BrenBarn** 和 **propter_hoc** 也附和，后者具体举出了 KITERS、TRIKES 等被拒的重排词例。

- **nsvd2**：帮忙厘清了规则——被拒往往是因为"下一个答案必须重新打乱字母"这一约束，但他也批评这条规则在界面上体现得不够清晰，玩家很难意识到自己错在哪。

- **ethanpil**：指出计时器自动开始的设计有问题，尤其是当页面在后台标签页打开时，等你回来时间已经在流逝了。

- **thrtythreeforty**：给出了较系统的建议——去掉猝死计时器、改用计分制，增加暂停按钮，并把提示（hint）的 UI 做得更清楚。这代表了"想慢慢玩"的一派诉求。

- **hmate9**（作者）：全程积极互动，逐条认领反馈，承诺修复被误判的合法单词、加入空格键洗牌功能，并有意推出无计时压力的"禅模式"。

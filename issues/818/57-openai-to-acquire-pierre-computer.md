## 文章摘要

OpenAI 的官方公告表示将收购 Pierre Computer Company，后者开发 Code Storage 以及 Trees、Diffs、Highlights 等工具。公告特别说明，收购仍须满足通常交割条件，包括监管批准，双方在完成交割前仍是独立公司。因此本条使用「拟收购」，不将它写成已经完成整合的交易；公告也没有披露收购金额。

这些产品围绕代码工作流的不同环节：Trees 用于浏览项目文件，Diffs 展示与审阅修改，并允许在差异视图中直接编辑，Highlights 提供随输入或生成过程更新的语法高亮。Code Storage 则让应用通过 API 存储代码并追踪 Git 历史。OpenAI 称 Codex 已使用 Pierre 的 Trees 和 Diffs 库，所以计划是在既有集成基础上扩大合作，而非所有能力都要等并购后才出现。

公告把需求归因于工程师与编码代理同时开展越来越多并行工作，版本管理、理解修改和评审需要相应调整。公司承诺 Pierre 的开源项目继续开源并持续贡献，Code Storage 客户在交割后可继续使用，同时相关能力逐步进入 Codex。这些是未来产品与维护承诺，本文未把它们等同于永久服务保证，也没有据此推测未公布的迁移时间表或商业条款。

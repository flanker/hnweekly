## 文章摘要

Watched 把「最近有哪些卫星从我头顶经过」做成可交互的地球仪。输入地点后，浏览器使用 SGP4 轨道计算寻找过去七天的过境记录，再关联可取得的遥感影像。项目官方 README 区分了两个规模：地球仪可绘制约一万七千个目录对象，实际过境查询覆盖的成像、气象、雷达与载人航天对象则接近四百个。不能把画面中的所有亮点都理解成拍摄过指定地点的卫星。

结果还区分已有公开影像、固定扫描带可能覆盖、商业卫星可能转向拍摄，以及仅从上空经过等情况。这些标签直接影响「被看见」的含义：轨道经过并不能证明相机开启，公开目录也不包含全部情报卫星。项目关联 Sentinel、Landsat 等来源，公开影像的分辨率与发布时间各有限制；气象图像部分数量按拍摄时刻表推算，并非逐张确认已发布。开发者也提醒轨道预测会随资料老化产生误差。

主站本次返回的是 JavaScript/WebGL 空壳，摘要补读了[官方仓库说明](https://github.com/dev-Armaan/satellites)，未实际操作地球仪。另须注意版本差异：发帖时作者说不保存位置，当前 README 已说明会记录约十公里网格的查询位置和访问事件，分享链接的位置精度更高，第三方影像服务也会收到相关请求。因此不能沿用最初宣传，把它描述成完全不留位置记录的工具。

## HN 评论精华

- [wnissen](https://news.ycombinator.com/item?id=50430479)：认为它能帮助规划徒步路线，尤其适合查看近期地表情况；这是实际使用方向，而非影像完整性的保证。

- [dingaling](https://news.ycombinator.com/item?id=50433623)：指出标题里的「每一颗」过于宽泛，机密卫星不一定出现在公开轨道目录中。

- [traceroute66](https://news.ycombinator.com/item?id=50437609)：质疑标题给人的全面监控印象与实际可用影像之间存在落差，提醒读者区分过境与确实拍摄。

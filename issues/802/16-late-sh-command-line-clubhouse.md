## 文章摘要

late.sh 自称「a cozy command-line clubhouse for computer people」——给电脑人的温馨命令行俱乐部。使用方式简单到只有一行：`ssh late.sh`。不需要注册、不需要安装任何东西，一个 SSH 客户端就是入场券。源码在 `mpiorowski/late-sh`。

站内提供的内容意外地丰富：chill radio、古典乐和客串电台；街机厅（2048、数独、Nonogram、纸牌）；一块协作 ASCII 画板；每日挑战与连胜记录；实时聊天；新闻分享与讨论；多人游戏（即将推出）。画板是一块共享的 ASCII 画布，可以涂、可以擦、可以签名，每个格子都记得是谁放的；系统每日和每月存快照，所以即使画板不断变化，历史也留得住，站点另有一个可平移缩放、显示每格作者信息的全屏 `/gallery` 查看器。还有一个「work」板块：谁在附近、他们在做什么、谁在接活，一人一份档案，从 TUI 里发布（进 work room 按 `i`），包含标题、状态、技能、链接，以及可选的简介、`late.fetch` 输出和作品展示。

身份机制是整个项目最有话题性的设计：没有密码、没有 OAuth、没有账号——**你的 SSH 密钥就是你的身份**。聊天记录、分数和连胜都绑定在公钥指纹上，同一把密钥就是同一份数据。隐私方面站点声明只存密钥指纹而非完整公钥，不记录 IP，无追踪、无分析，聊天消息和游戏分数存在 Postgres 里，只与指纹关联。不放心的话，官方直接给了用一次性密钥连接的命令（`ssh-keygen -t ed25519 -f ~/.ssh/late_throwaway && ssh -o IdentitiesOnly=yes -i ~/.ssh/late_throwaway late.sh`）。

此外有一个可选的伴生 CLI（仓库里的 `late-cli` crate）。纯 `ssh late.sh` 已经能拿到全部内容，`late` 二进制只是补上终端本身做不到的部分：用自己的音箱放电台、给音频可视化喂数据、承载语音房的麦克风和播放、跑音乐厅的 YouTube 窗口、以及把剪贴板里的图片直接粘进聊天。它也会帮你启动同一个 SSH 会话。下一步计划是屏幕与视频共享。

## HN 评论精华

- **jwr**：一句话定性——「这是一个现代 BBS！我喜欢这个想法。不过我猜现在大多数人已经不知道 BBS 是什么了，如果你不知道，去查一下。」**T3OU-736** 在另一处也持同样看法：把拨号调制解调器换成 SSH，其余的类比相当站得住。

- **kksweet**：「这就像 Habbo Hotel，但是给终端极客的。」**pishpash** 妙回一句：「读这句话的感觉，就像一边握着拨号调制解调器一边读『这就像 WiFi，但是给 RJ11 极客的』。」**tristanMatthias** 补充还像 Club Penguin。**flexagoon** 则想起了 tilde.town。

- **greengreengrass**（当时的置顶争议）：希望连接说明明确写出默认 SSH 用户名会被拿去在平台上建用户名，并展示给其他用户，而这一步没有事先征求同意——「在公司机器上，我没法决定 `$USER` 就是我的全名。」他给出规避方式：用 `ssh [化名]@late.sh` 连接。**soraminazuki** 反驳「SSH 本来就是这样工作的，想匿名就该另生成一对密钥」，greengreengrass 再回应：我知道 SSH 会自动发送本地 `$USER`，但这不意味着平台必须把收到的值自动展示给其他用户，完全可以先提示「你的用户名被报为 X，可以展示吗？」，或者在说明里建议用户在首次连接**之前**先选好用户名——这些都是合理且保护隐私的良好设计。

- **h43z**：提出一个更细的 opsec 提醒——默认情况下 SSH 会把 `~/.ssh/` 下所有存在的公钥以及 ssh-agent 里的全部公钥都发给你连接的服务器。一旦公钥泄露，就可以被用来探测另一台服务器是否认识这把钥匙。**alentred** 老实反问「公钥不就是本该公开的吗？」h43z 解释：这只是件人人都该知道的事，由你自己决定是否接受把一堆公钥交给服务方（比如 late.sh），因为它可以拿来探测你在哪些服务器上有访问权；每个人的 opsec 标准不同。**benj111** 抬杠说「那你也不该泄露用户名，我也能拿它去试别的服务器」，h43z 回应：OpenSSH 服务端的设计本就不会透露某个用户名是否存在。

- **1dom**：说这个点子很酷、只需 SSH 客户端也很好，但有两点建议——应该解释伴生客户端是干什么用的；另外首页那条一行 `curl | bash` 安装命令，要么去掉、要么在首页给出 git 仓库链接，「没有仓库链接却放着复制粘贴的 bash 管道，感觉像暗黑模式」。**Izmaki** 补充技术理由：Web 服务器完全可以配置成浏览器访问看到一个 sh、curl 取到的是另一个——展示一样、安装另一样。作者 **bl4ckbe4r** 表示收到，会改。但 **rob** 唱反调：「不必因为一个人抱怨就改。我个人就喜欢复制粘贴 curl 命令来安装，很方便，真那么偏执我可以自己检查文件。」

- **polycancel**：提出一个务实要求——所有这类 SSH 服务都该公布服务器指纹以便验证，并贴出了自己看到的 ED25519 指纹求确认。

## 文章摘要

这是 Humble Bundle 与 Raspberry Pi Press（树莓派官方出版社）合作推出的技术书籍合辑，官方名称为「Humble Tech Book Bundle: Picos, HATs, and More by Raspberry Pi Press」，主题口号是「让你的项目活起来（Make your projects come to life）」。合辑于 2026 年 8 月 1 日结束，全部电子书原价合计约 332 美元，采用 Humble Bundle 惯用的「自选价格、分档解锁」模式，共三档：

- **5.25 美元档（起步价）**：2 本——《Retro Gaming with Raspberry Pi》（用树莓派做复古游戏，The MagPi 杂志编辑团队）、《An Introduction to C & GUI Programming》（C 与 GUI 编程入门，Simon Long）。
- **15.75 美元档**：共 5 本，追加《The Official Raspberry Pi Handbook 2025》（官方手册 2025，The MagPi 编辑团队）、《The Official Raspberry Pi Camera Guide》（官方摄像头指南，David Plowman）、《Design an RP2040 board with KiCad》（用 KiCad 设计 RP2040 板，Jo Hinchliffe）。
- **26.25 美元档（完整）**：共 16 本，再追加《The Official Raspberry Pi Handbook 2026》（官方手册 2026）、《AI Projects with Raspberry Pi》（树莓派 AI 项目，Lucy Hattersley、Brian Jepson）、《Experiment with the Sense HAT》（Sense HAT 实验，树莓派基金会学习团队）、《Get started with MicroPython on Raspberry Pi Pico》（Pico 上的 MicroPython 入门，Gareth Halfacree、Ben Everard）、《Python Projects for Raspberry Pi》（Ben Everard）、《Simple Electronics with GPIO Zero》（用 GPIO Zero 做简单电子项目，Phil King）、《Book of Making 2026》与《Book of Making 2025》、《Make games with Python》（Sean M. Tracey）、《The Official Raspberry Pi Beginner's Guide》第 6 版（Gareth Halfacree）、《Conquer the command line》（征服命令行，Richard Smedley）。

官方介绍强调这是一套「全面且实用」的资源包：用 2026 版官方手册速成入门，再用 AI 项目、Sense HAT、MicroPython、GPIO Zero 等专题手册深入。所有电子书提供 PDF、MOBI、PRC 和 ePub 四种格式，可在电脑、电子阅读器、iPad、手机等各类设备上阅读。购买的慈善部分支持**树莓派基金会（Raspberry Pi Foundation）**推动儿童编程教育的工作（通过 PayPal Giving Fund 分发）。

值得说明的是，这类合辑覆盖的内容跨度相当宽：从最基础的命令行操作和初学者指南，到 Python 与 MicroPython 编程、GPIO 电路实践、Sense HAT 与摄像头等官方扩展模块的专门用法，再到硬件设计层面的 KiCad 板级设计（针对 RP2040 微控制器），以及偏娱乐向的复古游戏和 Python 游戏开发。对于刚入手树莓派或 Pico 的人来说，起步档就能覆盖 C/GUI 编程这一条相对少见的路径；而完整档基本等于把 Raspberry Pi Press 近两年的主力出版物一次性收齐。

## HN 评论精华

这条提交只得了 8 分、1 条评论——它是典型的「资源分享」类帖子，讨论热度低但信息密度高。唯一的那条评论恰好点出了这套合辑最实质的卖点：

- **throwa356262**：「这套合辑包含多本由树莓派核心员工撰写的书。举例来说，那本 KiCad 的书（我想）是由设计树莓派 PCB 的那些人写的。推荐！」

这条评论的价值在于它给出了一个外部难以核实、但很关键的质量信号。以《Design an RP2040 board with KiCad》为例，这类「用开源 EDA 工具从零设计一块基于官方微控制器的电路板」的教程，最怕的就是作者只停留在工具操作层面，而写不出真实量产板设计中的取舍与陷阱。如果作者确实来自树莓派内部实际负责 PCB 设计的团队，那么书中关于布局、去耦、电源、Flash 与晶振外围电路的建议就带有一手工程经验的分量，而不只是照抄参考设计。同理，《The Official Raspberry Pi Camera Guide》的作者 David Plowman 也是树莓派相机软件栈（libcamera / picamera2 相关工作）方面的核心人物，《An Introduction to C & GUI Programming》的作者 Simon Long 长期负责树莓派桌面环境的开发。这种「官方出版社 + 内部工程师撰写」的组合，是 Raspberry Pi Press 这条书系相较于第三方创客书籍的主要差异点，也是这条唯一评论想传达的意思。

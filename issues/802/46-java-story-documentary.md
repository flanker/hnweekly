## 文章摘要

CultRepo（前身是以《Vue.js: The Documentary》《React.js: The Documentary》等作品闻名的 Honeypot 频道）推出了一部关于 Java 的官方纪录片，片长约 40 分钟以上，赞助方包括 Oracle、JetBrains、IBM 和 Azul——Oracle 作为 Java 平台的当前管理者，参与本身就说明这是一次「官方视角」的叙述。

影片的叙事线索是 Java 从一个边缘实验演变为企业软件全球标准、并运行在数十亿台设备上的三十年历程。它从 Sun Microsystems 内部代号 Oak 的项目讲起：一支小型精英工程团队最初的目标并不是写网页，而是解决传统计算机行业之外那些嵌入式设备的编程问题。转折点来自第一个图形化浏览器 Mosaic 的发布——团队意识到静态网页需要交互性，于是重写了自己的浏览器（HotJava），把 Java 推向 Web，Netscape 的加入让这场押注变成了行业事件。由此诞生了那句著名的口号「一次编写，到处运行」（Write Once, Run Anywhere），以及为兑现这一承诺而打的一系列高风险官司。

按官方章节列表，影片依次覆盖了：Project Green 与早期岁月、HotJava 浏览器、Netscape、向 Web 转向与 WORA、「披着羊皮的狼」、Java 转向企业市场、兼容性问题与微软战争、那封关键的「铁证邮件」、微软的威胁与随后的诉讼、Java 社区进程（JCP）的成立、开源化进程、Tomcat、J2EE、Spring 与 Hibernate、Java 开源生态的壮大，直至 Oracle 收购 Sun 对这门语言的影响和 Java 的未来。换言之，这是一部把语言史、商业史和法律史缠在一起讲的片子——微软诉讼、JCP 的治理设计、OpenJDK 的开放，以及 Spring/Hibernate 这类由社区而非厂商推动的框架如何重新定义了「用 Java 开发」的含义，都是绕不开的节点。对于经历过 applet 时代、或者今天仍在维护企业 Java 系统的开发者，这大概是近年最完整的一次官方口述史梳理。

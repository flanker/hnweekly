## 文章摘要

Alex Wang 这篇长文的副标题是「每一层都是一个记忆存储」。他从一个日常场景切入：赶去朋友家玩桌游《沙丘：帝国》的路上，让语音助手把规则讲了一遍，于是好奇大模型为什么能记住这么多东西、又到底能记多少。文章的思路是把线性层、MLP 和自注意力都看成「联想记忆」（associative memory）：存入若干个键值对，查询时按与键的相似度取回值。衡量一个记忆存储好坏的核心指标是「干扰信号比」，也就是取回目标记忆时，其他记忆混进来的噪声与目标值本身的比例；当这个比例涨到 1，记忆就被淹没了，作者把此时能存的记忆数量称为「容量」。全文用这一个量，从最朴素的线性存储一路推导到现代 Transformer 的各个组件。文中配有可拖动的交互图，可以直接观察存入记忆增多时干扰怎样堆积，代码也开源在 GitHub 上。

**外积存储。** 最简单的做法是把每条记忆的值向量与键向量做外积，累加进一个矩阵 W；查询时用输入乘以 W，结果就是所有值按「键与查询的相似度」加权求和。作者顺带指出，一步梯度下降在形式上正好是往权重里写入一条记忆，键是层的输入，值是负的梯度乘以学习率；线性注意力（fast weights）的状态也正是这种外积存储。问题在于，如果键是随机单位向量，任意两个键的相似度约为 ±1/√d_k，M 条记忆的干扰像随机游走一样叠加，干扰信号比约为 √(M/d_k)。所以容量大约等于键的维度 d_k；d_k = 64 时只能存 64 条左右。

**最优线性存储。** 外积存储写入每条记忆时完全不考虑其他记忆。如果把选 W 看作一个最小二乘回归问题，解出来的是在外积存储基础上先乘以键协方差矩阵的逆，相当于对键做「白化」，不再过度放大许多键共享的方向。记忆数不超过 d_k 时可以做到零干扰的精确回忆；超过后干扰信号比约为 √(M/d_k − 1)，容量翻倍到 2d_k。作者附上了用投影矩阵迹的性质推导这一结果的过程，并用数值实验验证。但这仍然是线性的，大小相似度只能按同一比例缩放。

**MLP：非线性记忆存储。** 想压低低相似度键带来的干扰，就在加权求和前给相似度过一个非线性函数 σ，于是得到 f(x) = Vᵀσ(Kx)，这正是两层 MLP：第一层权重的行是键，第二层权重的列是值。作者引用 Sukhbaatar、Geva 等人的工作说明，训练好的 Transformer 里前馈层确实常常这样工作。他还发现一个有趣的史料：原版 Transformer 论文的 arXiv 第 2、3 版曾把前馈层描述为「一种注意力」，甚至试过用对可学习键值参数的注意力替换前馈层，效果相当，但这段话在之后所有版本里都被删掉了。

ReLU 把一半负相似度清零，容量提升到约 2d_k；平方 ReLU 把 0.1 压成 0.01、1 仍是 1，容量提升到约 2d_k²/3，即约 2700，是线性存储的 40 倍左右。平方 ReLU 等价于门控和输入投影共享权重的 GLU，如今流行的 SwiGLU 在同样设置下容量几乎相同。推广到 ReLU 的 p 次方，容量约为 d_k 的 p 次方，立方 ReLU 约 35000。作者也提醒，真实 MLP 是以「叠加」方式存储事实的，许多事实共享权重，每次回忆只激活很少一部分隐藏单元。

**自注意力：非参数记忆存储。** 既然次方越高越好，干脆用所有次方的加权和，也就是指数函数 e^(βs)，锐度 β 决定高次项的权重。推导表明容量约为 e^(2β(1−β/d_k))，随 β 指数增长；取自注意力常用的 β = √d_k = 8，容量约 e^14，即约 120 万条，是线性存储的近 2 万倍。为了数值稳定再除以所有权重之和，得到的正是 softmax 注意力。区别在于 MLP 的键值是训练出的参数，而自注意力的键值由上下文中的 token 计算而来，每个 token 存一条记忆，记忆数就是上下文长度，所以说它是「非参数」的。

**长上下文。** β 不能无限大，否则 softmax 退化为不可微的 argmax，训练时梯度也会消失。因此随记忆数 M 增长按 log M 适度提高 β，这正是苏剑林提出的 log M 缩放、Qwen 的 LogN-Scaling 以及 Qwen2.5-1M 所用 YaRN 注意力缩放背后的道理；实验中这些做法在 200 万条记忆时仍能保持很低的干扰。

文末作者坦承，这种容量估计只考虑随机向量，完全没涉及训练数据，并列举了按「每参数比特数」度量记忆量的研究（如 GPT 类模型约每参数 3.6 比特）以及 Hopfield 网络、Mamba、DeltaNet、记忆层、kNN-LM、ROME 等大量延伸方向。最后一句颇为动人：他一直被「记忆」吸引，也许因为切身感受到自己的记忆多么有限，希望弄懂机器如何记忆，也能多了解自己一点。

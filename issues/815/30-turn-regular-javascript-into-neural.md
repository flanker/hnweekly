## 文章摘要

Handwired 是 Cheng Lou（React 社区里以 react-motion、ReasonML 等项目闻名的开发者）发布的一个实验项目，标语是「把你的普通 JavaScript 代码变成神经网络：无需训练、结果精确，同时完全可微，在浏览器里不用 GPU 就能跑」。项目主页本身文字很少，主要是一个示例和三个演示，下面结合主页、GitHub README 和教程文档来介绍。

**核心思路。** 一个程序由 if-else、循环和状态构成，Handwired 把它们改写成浮点数上的矩阵乘法加 ReLU（准确说是 ReGLU，即一路线性和与一路 ReLU 门控相乘）。主页的例子是 `const result = a > 4 ? 10 : 12`，它可以改写成纯算术：先算 `above4 = relu(a - 4) - relu(a - 5)`，其中 `relu(x)` 就是 `Math.max(0, x)`，对整数 a 来说，a 大于 4 时 above4 为 1，否则为 0；然后算 `result = above4 * 10 + (1 - above4) * 12`，两个分支都计算，由 above4 选出其中一个。比如 a = 5 时 above4 = 1 - 0 = 1，结果是 10；a = 4 时 above4 = 0，结果是 12。主页上把这段算术画成一个电路：输入 a 分成两路进入两个 ReLU，两者相减得到 above4，再加权求和得到 result，这就是标题里说的「神经网络」，两个 ReLU 加上它们的加权和。之后把所有的加、乘和 ReLU 收集成一个巨大的矩阵乘法，可以用 JS 跑，也可以用 WebGPU 跑。

**精确性的边界。** 页面源码里留着一段很长的开发注释，坦白说明这个示例的 above4 只对整数精确：a 在 4 和 5 之间时 above4 等于 a - 4，比如 a = 4.5 会得到 0.5，结果变成 11；超大整数也会出错，在运行时使用的 FP32 下，第一个出错的整数是 2^24 + 6。实际的运行时用更严谨的方式构造比较：如果两个操作数声明在网格上（比如都是整数）且范围足够小，比较只需两次运算；否则会用一串「符号级联」，把差值乘以 2 的幂并截断，保证在声明的取值范围内与 JavaScript 自己的比较结果完全一致，此时 4.5 > 4 会精确得到 1。

**为什么要这样做。** README 说，因为基本只用到加权和与 ReLU 这两种原语：整个程序保持可微；权重是手工「接线」写出来的，不需要训练；GPU 上已有的融合、稀疏、重排等优化技术对这么简单的原语非常好用。由此可以玩出一些有趣的用法：把编译出来的程序权重「解冻」后再训练，看看会发生什么；把某个固定程序接到通用神经网络上端到端训练，比如让一个 nanoGPT 既会写莎士比亚又能跑你的特定 UI；让按传统单线程方式写的 JS 代码获得 GPU 级别的并行。

**三个演示。** 一是 Mini OS：一个用 JS 写、经 Handwired 转换的小桌面，有超长列表、动画、窗口层叠、滚动、拖拽、输入和图片，最终渲染成普通 DOM，共 9,909 个权重、130 层，训练量为 0。二是「学习型相册」：把编译后程序的权重解冻，实时训练。三是在 10 万份 JSON 文档里搜索：正则匹配、JSON 解析和高亮都用 JS 写成，再转换成 WebGPU 内核获得大规模并行，几毫秒就能跑完。

**实际怎么写。** 教程文档说明，所谓「数值程序」是一份固定的 FP32 运算列表，主要是加权和与带 ReLU 的乘积。你并不直接写这个列表，而是写「构建器代码」：一段只运行一次的普通 JavaScript，往 `Circuit` 里追加运算，因此程序运行时没有任何分支或循环。每个数值都要声明为输入、事件、状态等「单元格」并给出取值范围，比较之类的运算通过 `emitCompare`、`emitSelect`、`circuit.affine`、`circuit.reglu` 等函数构建。教程以一个开关组件为例，同时给出一份纯 JavaScript 的参考实现，用测试比对两者行为一致。

## HN 评论精华

这篇 Show HN 得了 42 分、12 条评论，讨论不多。几天前同一链接也有过几次提交，其中一帖 9 分、5 条评论，这里一并参考。评论主要集中在「这到底是什么、有什么用」以及项目是否夸大了宣传。

**到底是不是「普通」JavaScript。** gregsadetsky 认为这并不是把「普通」JavaScript 变成神经网络，而是「用一种 DSL 写逻辑，生成神经网络形状的电路」：Mini OS 演示的源码满是 `emitRelu` 之类的调用，根本不是普通代码。他指出主页和 README 有夸大之嫌，而文档里自己就写着「用 Handwired 你写的是一个数值程序」「没有工具能把现有的 JavaScript 源码转换成程序」，并表示如果理解错了乐意被纠正。curtisblaine 则抓到了主页示例的漏洞：给 `a > 4 ? 10 : 12` 传入 a = 4.5 会得到 11，「不是所有东西都可微」，这与页面源码注释里作者自己承认的边界一致。

**看不懂它的用途。** auraham 说着陆页让人困惑，又是把 JS 转成别的东西，又是浏览器里的迷你操作系统、相册、文档搜索，看起来互不相关；echoangle 解释这本质上是一个编译器，把任意 JS 程序编译成行为与原程序完全一致的神经网络权重，下面那些是以神经网络形式运行的演示项目；freecodeio 说「DEMOS」标签太小，难怪会误解。hungryhobbit 说网站漏掉了读者最想知道的第一件事：为什么要这么做。在另一帖里，skyzoidbroczky 和 vivzkestrel 也问这东西到底有什么意义，tetrisgm 说推特上很多人在吹，他却不明白应用在哪；Ohentis 给出一个猜测：可以先用手写的行为初始化神经网络，再在自己的数据集上微调。dvrp 建议感兴趣的人去看作者最初的推特长帖，说自己也花了一会儿才弄明白作者做了什么。

**延伸设想。** seamossfet 设想反过来做：冻结权重，加几层在各种古怪边界情况上训练的网络，再把权重转回分支代码，「用熵来做 QA」。jahala 想得更远：既然如此，Anthropic、Google 为什么不干脆做出完全取代「代码」概念的模型，指向一个 API 就直接实时推断并渲染出可用的 UI，需要持久化时再把部分结构「即时冻结」成确定性的形式？aatd86 提到 DeepMind 的 Tracr（把程序编译成 Transformer 权重）是相关的先行工作；austin-cheney 认为模型仍然无法产生新颖的解决方案；pizzafeelsright 则断言大约 18 个月后整个 UI 都会被取代。

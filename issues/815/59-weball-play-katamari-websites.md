## 文章摘要

Weball 是一个把任意网页变成《块魂》（Katamari Damacy）关卡的浏览器小游戏，挂在 Fun With Computer Vision 网站下。这个网站平时主要卖计算机视觉教程，做的多是手势追踪、面部识别之类的互动小项目（比如用语音和人脸读 Hacker News 的 "Snacker News"、用眼睛激光保护小猫的游戏），Weball 是其中新上的一个。标题下的口号是"滚起来，长大，赢下互联网"。页面本身几乎没有说明文字，下面根据实际页面、它公开的前端 JS 源码注释和 HN 讨论来介绍。

**玩法。** 你控制一个蓝色的小球（块魂），它会朝鼠标指针（手机上是手指）的方向滚动。网页上的东西都会被"拍平"成一张地面：每一个文字字符、每一个按钮、每一张图片都是一件可以卷起来的物品。一开始球很小，只能粘起单个字母；粘得越多球越大，就能吞下整个单词、段落，最后连网页上的大图片也能卷进去。体积不够时，大图片和表单控件会变成真正的障碍物，球撞上去会被弹开。游戏里的尺寸是按"1 像素等于 1 毫米"换算的，镜头会随着球变大而逐渐拉远。代码里还能看到跳跃（球可以在空中停留 0.8 秒、只保留少量转向能力）、连击计数（连击到 25 进入"狂热"状态）、尺寸里程碑和彩带特效等设计，每关都有一个目标尺寸，达成后显示用时，并记录最好成绩。

**关卡。** 游戏内置三个关卡：第一关是维基百科上的《块魂》词条，第二关是以 GeoCities 拼贴风格闻名的 Cameron's World，第三关是模仿老式网络浏览体验的 The Old Net。打开页面直接进入第一关，通关后才解锁关卡选择，以及"卷起任意网站"的功能：输入一个网址，就能把那个网站变成关卡。页面提示，网站是在不执行其 JavaScript 的情况下加载的，所以完全靠客户端渲染的站点卷起来会很空。

**实现思路。** 从源码注释能看出它的技术路线：内置关卡是预先"烘焙"好的 JSON 文件，不需要代理；自定义网址则通过站点自己的代理抓取 HTML，放进一个隐藏的同源 iframe 里让浏览器完成排版，然后用 getBoundingClientRect 和逐字符的 Range 读出每个可见字符、每个色块、每张图片的位置，组成一个扁平的关卡数据：用于重绘页面的"绘制层"、每个字符一个"字形"（记录它属于哪个单词、哪个链接），以及可以整块卷走的"块"（图片、控件、视觉上独立的盒子）。注释特别强调"这里没有重新实现任何排版"，所有位置都来自浏览器自己的布局结果。字体度量也是在被卷网页自己的文档里用 canvas 测的，这样网页字体能正确加载。球本身有真正的三维朝向，模拟无滑动滚动，被卷起的东西像贴纸一样贴在球面上，先在离屏 canvas 上俯视绘制并做球面明暗处理，再合成到屏幕上；为了性能，球上最多只画一千件物品。正如一位评论者所说，它的关键在于尽快"脱离 HTML"，把页面转换成游戏引擎自己的数据，而不是像老式小书签那样直接对页面 DOM 元素做 CSS 变换。

## HN 评论精华

本帖 304 分、23 条评论，讨论量不大，气氛几乎一边倒地正面：大家在晒自己卷了哪些网站，回忆当年的块魂小书签，也有几条关于性能的观察。

**做得比想象中好。** vunderba 说它出乎意料地精致，特别喜欢球从卷文字开始，到后来大到能把网页上的实物图片也吸进来的过程。他还顺带提到《星之卡比：探索发现》里有个"针"能力，进化后能把塔、开瓶器、仙人掌之类的随机物品粘在身上滚来滚去，显然是在致敬《块魂》。OuterVale 卷了好几个网站，包括他自己的，称之为"一点网络上的奇思妙想"；christkv 说自己被吸进去把公司官网卷了一遍；BatFastard 说这是很久以来见过最让人上瘾的东西；couchand 推荐 lwn.net 作为关卡，"看看你能打出多大的连击"。throwfaraway135 则抱怨第一关的页面没法完全卷干净。

**当年的块魂小书签。** Dwedit 提到 2008 年前后就有一个块魂风格的小书签（bookmarklet），nokun7 记得叫 kathack 之类，说自己当年靠它交了不少朋友。gregsadetsky 找出了 kathack.com，指出它只有 HTTP 版本，所以在如今大多数 HTTPS 网站上已经不能用了，他顺手修了一个可用版本放在自己的域名上。bookstore-romeo 也说想起了以前在 HN 上看到的这个小书签。frou_dh 对比了两者的实现：老书签是直接用 CSS 变换去操作页面上的真实元素，而 Weball 很快就把页面导入成游戏引擎里的表示，这大概是它运行得这么流畅的主要原因。allenu 提醒，谷歌搜索"Katamari"时也有一个彩蛋，点那个小块魂球就能在搜索结果页上滚。

**性能：因设备而异。** tantalor 说"很快就卡了"，gavmor 也说卷了几百个单词之后帧率很糟，但在那之前非常好玩，他特别喜欢大图片作为真正障碍物的设定。x-complexity 推测原因是球不是一个静态 3D 对象，可以通过定期把球的内层合并成单个资源来优化。另一方面，argsnd 说在 iPhone 17 Pro Max 上卷完整个维基百科页面帧率依然流畅，只是手机有点发热；frou_dh 用一台 8 年前的 iPhone XS 也能玩，清空整个维基页面帧率都没差到影响操作。

**音乐和原作。** nokun7 希望能用原版音乐，andylynch 说被这条评论提醒去查了一下，发现万代南梦宫最近把原作全部原声上架了流媒体，顺手哼起了那段经典的"Na na na na……"。pfdietz 则调侃说："没有那个虐待狂老爸（指原作里的宇宙之王），就不算真正的《块魂》。"

## 文章摘要

**先说清楚性质：这是一个恶搞网站，不是真实新闻。** 页面底部有一段标注为「⚠ 真实声明 · 这部分不是段子」的免责声明，明确写着 Stwipe 是讽刺、并不存在，OpenWouter 是讽刺、并不存在，没有收购、没有交易滚动条、没有那笔金额，也没有一个在乌得勒支等着你的 API 调用的男人；Wouter 是虚构人物，与任何真名为 Wouter 的人雷同纯属巧合，「而且坦白讲，对我们是种荣幸」。声明还指出 Stripe 和 OpenRouter 是真实公司，与本站无关且「大概并不知道本站的存在」，页面内容是基于它们的公开公告和营销材料的戏仿；并特意加了一句相当负责任的提醒：**公然宣布对真实公司的假收购带有证券欺诈的味道，别拿任何可交易的东西这么干。** 网站署名为「Duckbill 出品 · 一个 shitposting.ai 制作」——Duckbill 即 Corey Quinn 那家专做 AWS 账单咨询的公司（这解释了 HN 上「我们需要更多 QuinnyPig」的评论）。

**梗的来源。** Stripe 真实收购了 OpenRouter（一个统一了 500 多个语言模型的 API）。这个页面的整个笑话建立在谐音之上：**Stripe → Stwipe，OpenRouter → OpenWouter**（Wouter 是一个常见的荷兰男性名字）。核心笑点是：**「他们买了一个 router（路由器），我们买了一个 Wouter。」**

页面做成 12 页的「并购发布会幻灯片」形式，顶部有一条不断滚动的交易快讯：「Stwipe 公司与 OpenWouter B.V. 达成最终收购协议 · 条款未披露（Wouter 形容为『还行』）· 预计交易将在中欧时间 17:00 前完成，**因为在那之后 Wouter 就没空了**」。

主要页面的内容：

- **发布（01/12）**：「Stripe 买下了 OpenRouter，一个统一了五百个语言模型的 API。今天我们宣布一个统一了一个荷兰男人的 API。他叫 Wouter。**他就是那个模型。他希望这份新闻稿能短一点。**」
- **背景（02/12）**：当 Stripe 收购 OpenRouter 时，分析师问我们是否感到压力。「**我们不体验压力。我们体验的是大声地想要某样东西，直到它属于我们。在并购里，这叫『信念』。**」还有一句：「我们的首席产品官今年四岁。她看到那条头条就尖叫了。董事会将此解读为一项授权。」
- **资产（03/12）**：一张对比表，是全篇结构最精巧的部分。**OpenRouter**：被 Stripe 收购；模型 500+；供应商数十家；延迟毫秒级；可用性 99.9%；故障转移为自动重路由；上下文窗口最高 200 万 token。**OpenWouter**：被我们收购；模型 1 个（Wouter）；供应商也是 Wouter；**延迟取决于他是否正在骑车**；可用性为中欧时间 09:00–17:00，**八月绝不营业**；故障转移是 Wouter 的语音信箱；**上下文窗口是你对他说过的一切，而且他会翻出来提**。结论：「更少的活动部件。一个活动部件。他靠自行车移动。」
- **战略理由（04/12）**：Stwipe 的 API 对每一个请求都返回 200 OK，「这是我们的整个产品，而且据我们的治疗师说，也是我们的整个人格」。而 Wouter 会说不——**专业地说不、休闲地说不、以及不请自来地说不。他是荷兰人。** 这次收购填补了我们路线图上最大的单一能力缺口。「协同分数 11/10。我们请 Wouter 核实这个数字。他说不。**概念验证成功。**」
- **合并后的平台（05/12）**：「两个端点。全面覆盖。」有了「是」和「不」同在一个屋檐下，**每一个可能的商业决策现在都被支持了——「在一个非常真实的意义上，我们作为一个物种已经功能完备。」** 旧版 Stwipe（2025）是 `POST /v1/yes` 返回 ok 为真；由 Wouter 驱动的今天是 `POST /v1/no`，返回 ok 为假外加一句荷兰语的「Nee.」。页面强调这是**真的线上端点**——「Wouter 在生产环境应答，在他的上班时间内。」
- **模型卡 wouter-1（06/12）**：全篇最密集的笑点。**参数量**：一个（Wouter）。**上下文窗口**：1982 年至今，什么都不会被截断，他记得你在 Anke 生日会上说的那句话。**知识截止日期**：无。Wouter 知晓一切，并对其中大部分感到失望。**模态**：文本、语音，以及某一种眼神。**温度**：不要调节 Wouter 的温度。恒温器已经设好了。这样就行。**微调**：人们已经试图微调 Wouter 四十年了。去问他妈妈进展如何。**速率限制**：Wouter 会告诉你的。**对齐**：完全对齐。与他自己。
- **评测（07/12）**：「在那些没人愿意发表的基准上」对比前沿模型。MMLU-Nee（拒绝准确率）：wouter-1 得 100.0，前沿平均 31.2；谄媚度（越低越好）：wouter-1 得 0.0，前沿平均为「好问题！」；幻觉率：wouter-1 得 0.0，前沿平均「视情况而定」。**脚注是全篇被引用最多的一句：「数字是为这张幻灯片编造的，遵循行业传统。Wouter 这辈子从没想象过任何东西。我们测了两次谄媚度；第二次他请我们离开。」**
- **交易（08/12）**：收购价「Wouter 说：还行」；留任员工 1 人（Wouter）；整合工作流 0 条（他拒绝了）。「财务顾问：没有。我们问 Wouter 这家公司值多少钱。他告诉了我们。**这就是全部流程。**」
- **前 100 天（09/12）**：整合路线图。第 1 天：Wouter 保持他的作息。第 30 天：Wouter 保持他的作息。第 60 天：我们提议设立每周一的例行同步会。第 61 天：**不存在每周一的例行同步会。** 第 90 天：在乌得勒支的领导层务虚会，Wouter 出席了午餐环节。第 100 天：**我们已经适应了 Wouter 的作息。**「我们被告知，从文化上讲，这是成功的结果。」
- **口碑（10/12）**：「Nee.」——OpenWouter 创始人 Wouter，在被要求给一句评价时。「我们问 wouter-1 我们的种子轮 BP 能不能拿到融资。它说不能。它是对的。它永远是对的。」——一位正在重建的创始人。「**唯一一个把拒绝本身当作产品、而不是安全层的模型。**」——一位正在做笔记的对齐研究员。
- **诉求（11/12）**：「什么都不要。我们现在是买方了。」——「Stwipe 历史上第一次，我们不在融资。我们在花钱。**收购东西而不是索要东西的感觉太棒了，我们终于理解了为什么上游的每个人都在这么干。**」数据：本轮融资 $0；端点总数 2 个，增长 100%；Wouter 下班时间 17:00（中欧时间）。结尾是一个自行车表情和一句「谢谢。Wouter 已经下班了。」

## 文章摘要

这是 Framework 官方 YouTube 频道在 2026 年 8 月 18 日发布的新品发布视频，标题《We added WHAT to the Framework Laptop 12?》，片长 6 分 50 秒。视频宣布搭载 Intel Core Series 3 处理器的新一代 Framework Laptop 12 正式开放预订，官方明确表示这一代的改动来自用户的直接反馈和问卷数据——不是厂商拍脑袋决定该升级什么，而是把社区呼声最高的诉求逐条落地。

新一代仍是 Framework 产品线里那台最花哨、最有色彩感的二合一（2-in-1）笔记本，主要升级点有这么几项。**续航**方面官方给出的数字是最多延长 70%（测试条件为 Netflix 4K 流媒体播放），这也是本次换代最实质的收益。**指纹识别器**被集成进电源键——这是原版 Framework 12 缺失、社区抱怨最多的功能之一。**背光键盘**作为可选项加入，运行的是开源的 ZMK 固件，意味着键盘固件可编程、按键映射可以自己改。处理器换成代号 Wildcat Lake 的 Intel Core Series 3，SKU 覆盖 Core 3、Core 5，并且**首次为 Framework Laptop 12 提供 Core 7** 选项。接口和无线部分新增了 **Thunderbolt 4**（因此支持外接显卡坞 eGPU）与 **Wi-Fi 7 R2**，另外补上了北欧和瑞士键盘布局。

Linux 支持是这台机器的一条明线：官方强调 Framework Laptop 12 从设计之初就是为 Linux 准备的，这一代提供了预装 Fedora Linux 的整机配置可选。

而对老用户来说，视频里最关键的一句承诺是：新的**主板、输入上盖（Input Cover）和指纹识别器全部向下兼容原版 Framework Laptop 12**。也就是说，已经拥有第一代机器的人不必换掉整机，可以只买想要的那几个模块把手上的机器升级上去——这正是 Framework 整个产品哲学的核心，也是这次发布最能说明其模块化承诺不是营销话术的部分。

视频的章节划分本身也透露了叙事节奏：0:00 开场、1:09 正式宣布、1:29 主板更新、2:26 背光键盘、3:01 指纹识别器、3:19 Thunderbolt 4 与 Wi-Fi、4:03 Linux、4:50「它仍然是同一台笔记本」、5:59 收尾。其中 4:50 那一节的标题耐人寻味——在讲完所有新东西之后，官方专门花了一段时间强调这台机器**没有**变成一台新机器，机身、模块、可维修性一切照旧。预订页面在 frame.work/laptop12。截至抓取时该视频播放量约 57.9 万次。

## HN 评论精华

需要如实说明：这条帖子在 HN 上反响很小，只有 23 分、8 条评论，规模远不足以支撑一场技术辩论。但这几条评论的走向本身很有意思——**几乎没有人在讨论跑分、性能或性价比，讨论的全部内容是「我打算给我那台旧机器加装哪个模块」**，而这恰恰是对 Framework 模块化理念最有说服力的用户侧验证。

- 提交者 **what-is-water** 自己就是初代 Framework 12 的用户，他的第一条评论定下了整场讨论的调子：他大概会买那个指纹识别器，「我低估了自己有多想念它」；但**为了更好的续航去升级 CPU，对他来说不值**。这句话本身就说明了模块化带来的一种全新消费姿态——不是「要不要换新机」，而是「这一代的哪几个模块值得单独买」。
- **bpev** 的回复点破了这一点，也是全场最受认同的一条：「这是这个品牌最酷的部分。你能直接说一句『我大概会买那个指纹识别器』，然后就没了。」**samtheDamned** 附议：他这次也肯定要买指纹传感器，而且只要哪天出了更好的屏幕他也会立刻手痒，「拥有这类设备实在太让人兴奋了」。
- **tomekw** 问了唯一一个负面向的问题——初代机的品控（QC）到底怎么样。**what-is-water** 的回答很诚实也很克制：他自己那台没有任何问题，「很难说是我运气好，还是问题并没有网上分享出来的那么严重」；他对这台机器很满意，另外他还走运地在内存涨价前买了 64GB。
- **Lammy** 同样是初代用户，他的诉求很具体：他不介意初代没有键盘背光（因为会盲打），但**可编程键盘固件对他是刚需**——他要干掉那个飞行模式键。那个键是由 EC（嵌入式控制器）而非操作系统解释的，「如果我不小心按到，那就是『输掉这一局』按钮」。这条评论恰好落在新一代 ZMK 开源固件所解决的问题上。
- **Lio** 的评论跳出了产品本身，谈的是发布方式：「我喜欢 Framework 的产品发布风格，太接地气了。」他把视频的叙事概括成一句话——「这是大家要求最多的五件事。我们更新了其中三件。」他认为坦承自己没有做到所有人期待的一切、但仍在攻关问题区域，给人的观感反而比把头埋进沙里、假装那些问题不重要要**专业得多**。他的结尾是这条讨论最凝练的总结：「事后还能升级才是杀手级功能。」
- **Snuupy** 提出了唯一一个纯技术性的问题，也是唯一一条无人回答的：他好奇 Intel Core Series 3 和苹果 A18 Pro 在性能功耗曲线上的对比会是什么样。

## 文章摘要

「Sorry, I'm in a meeting」是英国开发者 John Carroll（HN 用户名 splintersio，个人品牌叫 Splinters）做的一个小网站，正式名字叫 Fleeting，域名 iminafleeting.com 是"I'm in a meeting"和"fleeting"（转瞬即逝）的谐音梗。网站自我介绍是"职场自卫工具，防止别人偷走你的时间"：挑一个会议，按下播放，让背景里的会议声音替你说话。也就是说，它播放的是一段段逼真（页面上故意把"逼真"划掉，改成"说得过去"）的虚构会议录音，你把它外放出来，周围的人就会以为你正在开会、不方便打扰。这是一个互动站点，正文很短，下面结合网站界面、源码里的会议列表和 HN 讨论介绍它。

**怎么用。** 首页让你"选择你的会议"，可以填上自己的名字（会显示在通话格子里），选择口音，以及是否开启"连轴开会"。点进去后是一个类似 Zoom 的视频会议界面：一排排参会者格子，大多是名字缩写头像，少数格子里有 AI 生成或授权图库的人脸视频，你自己的格子默认静音。电脑上加入会议会自动全屏（按 F 切换），手机上可以"添加到主屏幕"像 App 一样全屏运行，免得地址栏露馅。按"离开"或"我得先下了"，其他参会者会先跟你道别再挂断。

**会议种类。** 按源码里的列表，目前大约有十几种会议，每种都有固定角色和剧本：
- 工程站会（Engineering Standup）："简短汇报，没有阻塞项，有人家的狗在叫。"
- API 设计评审、应用安全评审、供应商安全评审
- 范围界定电话（Scoping Call）："客户和顾问在商定哪些在范围内、哪些不在。"
- 项目状态会、客户销售电话
- 季度全员大会："一位非常热情的演讲者，礼貌的掌声。"
- IT 事故作战室，以及"勒索软件危机电话会"："所有东西都被加密了，Nadeem 有一个关于母狮的比喻。"
- "主持人进来之前"："已经过了十分钟，主持人还没来，八卦开始了。"
- 健康职场工作组、团建策划同步会，甚至还有"运营周会（驾驶舱版）"

每段会议大约 12 分钟，每次从随机位置开始播放，所以不会连续两次听到同一句开场白。勾选"连轴开会"后，一段会议听完，大家会互相道别，几秒钟后你会自动加入另一个适合当前时段的会议（比如早上更可能是站会）；不勾选就循环播放。口音最初有英式、美式和"国际（混合口音）"三种，HN 讨论之后作者又加了西班牙语、法语、德语、意大利语的测试版。

**日历伪装。** 网站另一个功能叫"把日历占满"：在别人开口之前，先往自己日历里塞一个假会议，看起来就很忙。你可以选会议类型、日历里显示的标题、日期、开始时间、时长（15 分钟到一个半小时）和重复规则（不重复、每个工作日、每周），可以附上"加入链接"（链接回这个网站，提醒弹出时点进去就能"入会"），还可以标为私密，让同事只看到"忙碌"。邀请可以下载成 .ics 文件，或直接加到 Google 日历、Outlook。网站说明邀请完全在浏览器里生成，不会发送任何数据，但能看到你日历详情的人也能看到那个加入链接，介意的话就别勾选或者设为私密。

**都是假的。** FAQ 里说得很清楚：所有声音都是合成的，人脸是 AI 生成或授权的图库素材，所有名字都是虚构的，"除了 John Carroll，他做了这个网站，有时会关着摄像头旁听"，没有录制任何真实会议。页面底部还有一个"想把你的产品植入假会议？来投放广告吧"的入口，会议里有赞助商口播插播的设计；页脚写着"为需要一分钟清静的人而做"。

## HN 评论精华

本帖 1052 分、约 290 条评论。作者 splintersio 本人在评论区和大家互动，承诺根据反馈加功能。讨论主要集中在几个方面：音频能不能用、听起来像不像真的、类似的历史产品，以及"用假会议保护专注时间"的职场实践。

**作者的回应和早期 bug。** 7174n6 说"挺棒的，如果我在英国上班的话"，作者回复也有美式口音，"第一天嘛，图个好玩，如果火了我会尽量加更多选项"。但 roryirvine、fliglr、wccrawford、stronglikedan 等多人反馈，只有英式口音能出声，美式和国际版点进去是静音的，控制台报音频资源 404；ninkendo 怀疑网站被 HN 流量冲垮了。flurdy 建议加一个旋钮，能调各种口音和英语流利度的比例：北英格兰、威尔士、苏格兰、印度、各种美国口音、西班牙、葡萄牙、波兰、斯堪的纳维亚，再来一点澳洲口音，"芬兰就算了，那种沉默可不行"。wkumfer 希望有其他语言版本，作者说他已经有了，但担心翻译和方言会让声音不那么可信，"可以先作为测试版加上"，后来网站确实加了四种欧洲语言的测试版。有人反馈取消静音后自己的格子没变化，作者回"记下了，感谢你的用户验收测试"。broken-kebab 担心没装广告拦截的人会被一段响亮的 ClickUp 广告穿帮，作者随即表示"我会关掉广告！抱歉"，后来又补充说已经停掉了 AdSense，"不过我允许广告偷偷溜进会议里了，咳咳"。franga2000 称赞"在假会议里卖广告"是他见过最好的恶搞变现策略。

**听起来像不像。** 这是争议最大的部分。jonwinstanley 说音频不太可信，人类很擅长识别假货，也许用真人录音片段效果更好；xbar 不同意，认为对普通人来说很多音频元素相当可信。更多人站在批评一侧：mcv 说它听起来像配音表演，"太清晰、有点浮夸、像照着稿子念"；recursive 和 rbits 说像在听有声书而不是开会；adamors 说像托福听力练习；kazinator 的总结很到位：真实会议里的人是未经训练的演讲者，声音单调、有各种口头习惯，被点名的人会走神或要停顿想一想，而这里没有任何停顿，发音完美；0xR1CK 指出没有人抢话，每段音频严格一个接一个。micromacrofoot 建议多加点"嗯""呃"。AIorNot 吐槽 API 会议里清一色美国白人口音，在他待过的美国公司从来没出现过，然后发现有口音选择器，"太好了"。也有人觉得够用了：Barbing 说英式范围界定会议在 iOS 上能用，"应该能糊弄过家人，笑话之后还有一声轻笑"；saulpw 说它就像 80 年代游戏里的"老板键"，只是一层薄薄的伪装，足以挡住路过想看你有没有空的人。

**剧本写得太真实。** filcuk 觉得剧本好笑又不失准确："你对这个满意吗？""满意这个词有点重。""好的。"然后进入下一个议题。unethical_ban 引用了全员大会里的一段：员工问业绩这么好会不会体现在调薪上，高管回答"好问题，我不想说任何我承诺不了的话，但我们会考察所有选项，肯定会奖励优秀表现，这样回答了你的问题吗？"，他说"小品编剧们要小心了，这东西准得可悲又好笑"。mcv 接了一个真实经历：高管问"资深员工流失率很高，大家有什么想法？"有人喊"薪酬！"高管说"不，我是说比如每周五吃披萨、搞个团建之类的"。已经退休的 vermooten 说这些通话把他拉回了在科技公司上班的恐怖回忆，"大概就是 PTSD 的感觉"。lifestyleguru 说他每次开企业电话会都在想"这些人的句子和词是从哪来的"，"现在我知道了，他们是电脑"。tiborsaas 则说一个人在家工作时把它当背景音挺放松，"基本上就是大公司 ASMR"。

**这事真有需求。** frangonf 讲了一个发现：GitLab 的副频道里，按播放量排序，有一段看似普通、毫无亮点的会议录像有几百万播放，评论区全是"我放这个让家人别来烦我""我放这个假装很忙"，后来评论被关掉了。martind81 也说他当年找会议录音测试语音转文字模型时，同样纳闷为什么会议视频有几百万播放，看了评论才明白。tacostakohashi、karim79、BeetleB 想起了 MS-DOS 时代游戏里的"老板键"，一按就切到一张假电子表格；BeetleB 最喜欢《太空任务 3》（Space Quest III）的版本：它不是显示表格，而是弹窗明确告诉别人你在玩游戏、已经玩了多久，还得关掉好几个弹窗才能回到游戏。cantrevealname 回忆几十年前有一种真实商品：一盘录着各种背景音的磁带，你可以在公用电话亭给老板或配偶打电话，放一段汽修厂的敲打声，解释车坏了来不了。其他人还提到 hackertyper、假 Windows 更新页面、"假进度条"之类的前辈。whilenot-dev 问这类软件该叫什么，whh 给出一个答案："典型英式的、战术性又不失礼貌的社交互动威慑工具"，作者回"哈，是的"。

**用假会议保护专注时间。** 讨论最长的一串来自 alexpotato：他以前管理一支 SRE 团队，大家总被会议请求轰炸、没有专注时间，他的办法是每周五早上 8 点到 11 点设一个"团队会议"，把所有人都邀请进去，大家很喜欢；他说其实他们自己也可以这么做，团队回答的大意是只有经理发起才有分量。mikemarsh 称赞这是"管理层替开发者挡住上层公司闹剧"的理想典范，antoineMoPa 则反思挡得太多会让成员和组织其他部分脱节、过度依赖经理获取背景信息，引发了一串关于经理该是"通信路由器还是瓶颈"的讨论。notesinthefield 说他们的产品安全和工程团队每周一、周五都设 8 点到下午 2 点的"产品同步"来防项目经理，已经用了好几年；mlhpdx 发现 2 到 3 小时的块最不引人注意。Lammy 用"每日营养同步"来保住午饭时间，redsparrow 每天中午有一个"吃饭或死"，AnotherGoodName 把周五下午的威士忌品鉴会登记成"16 年规划会议"，还被高管表扬有远见。xyzzy_plugh 讲了一个更极端的故事：团队负担重到让 HR 虚构了"值班主岗"和"值班副岗"两个虚拟员工，配了专属笔记本和手机，换班时交接设备。Aurornis 提醒这治标不治本，会议只会被挤到下午，有人还开始只在专注时段里干活。

**质疑声。** spuz 和 bartread 说在旁边外放这种对话，自己根本无法集中精力，人声比背景噪音更让人分心；voidUpdate 问办公室里真有人外放会议吗，大家不都戴耳机。ghusto 和 tamimio 认为，如果你不能直接告诉别人你需要专注，要么是公司有问题，要么是你有问题。DharmaPolice 和 arjonagelhout 说公司电脑上这个网站已被屏蔽，esikich 解释企业 IT 常常默认拦截新注册域名。bdlowery 批评这是"零投入、千篇一律的 Claude 一次生成网站"，gigatree 反驳只要它有趣有用就行。

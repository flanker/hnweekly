## 文章摘要

作者 AJ Waxman 从 Robin Sloan 在 2020 年写的那篇 BoopSnoop 谈起：Sloan 为自己家人做了一个消息应用，总共只有四个人下载，他却认为这是彻头彻尾的成功。他的观点很简单——一个 app 可以像一顿家常饭，你不需要规模，不需要用户，你为你爱的人下厨。那个应用花了他一周，其中一半时间耗在代码签名的炼狱里。他当时的原话是：在一个更好的世界里，他本该用某种现代、灵活的 iOS 版 HyperCard 在一天内做完它。

六年后，这篇文章在社交网络上重新翻红。Thariq 写道，个人软件在 2020 年还稍嫌早了点，但到 2026 年，它真的可以像家常饭或手写信一样个人化。Lee Robinson 也写过同样的转变：AI 让「个人计算」真正变得个人——他和妻子做了一个育儿追踪器，因为他们根本不需要用户档案、徽章、订阅分层这些多余功能。

作者过去半年造了一大堆过度定制的软件：一个执行睡眠顾问方案的婴儿睡眠 app（顾问给的是一份满是条件逻辑的 PDF——清醒时长、小睡上限、小睡失败时怎么办），花了一周晚上做出来，现在他、妻子和保姆共享一份会在小睡缩短时自动重排的活时间表；一个健身 app，知道他的周跑量计划，按当天晨跑的距离和强度调整热量目标，甚至知道他每天称重的八种配料的思慕雪配方，按训练量调整每份用量；一个马拉松计划，心率区间直接从他实际比赛成绩推导，而不是套用年龄公式；一个「爵士乐版 Duolingo」，用他钢琴课上的和弦配置来出题；还有一个在专科门诊前帮他标出病历空缺的医疗记录工具。

技术栈是 Next.js on Vercel、Tailwind 加 shadcn/ui、Better Auth、Neon 上的 Postgres 配 Drizzle ORM、Resend 发邮件、GitHub Actions 跑定时任务、Claude Code 加 Vercel AI SDK 做 AI。全部成本约每月 160 美元：Claude Code Max 100 刀、API 用量 10 刀、Vercel 20 刀、Neon 30 刀。

他总结了几条心得：**构建成本断崖式下跌**——睡眠 app 一周晚上，健身 app 一个周末，爵士测验一个晚上，想象力成了唯一瓶颈；**维护出乎意料地轻松**，九成情况下把反馈截图丢给 Claude 就解决了；**聚合数据再加个 LLM**——他的 app 大多是同一个形状：把散落在多个来源的数据拉到一处，再用 LLM 从全局产出洞察；**用完即弃也没关系**——睡眠 app 只用了四个月，儿子能睡整觉后就退役了，因为只花了一周，他反而庆幸它在需要时管用；**AI 淹没大市场，也解锁小市场**；**好 API 比以往更重要**——他从 Cronometer 换到 FatSecret 纯粹因为后者 API 更好；**过程本身就是目的**，同时也承认「不只是好玩，是会上瘾」——agentic coding 有老虎机机制，讽刺的是他为了改善健康而熬夜写 app，毁掉了不少个晚上的睡眠。

## HN 评论精华

这条讨论拿到 264 分，评论区的走向远比文章本身分裂。

**平台封闭是最大的扫兴因素。** 高票开场的 **fny** 说这想法很浪漫，可惜苹果和谷歌都对这个模式充满敌意：iOS 最糟，不交 99 美元一年的开发者费，你的 app 在自己手机上活不过一周；分发麻烦得要命；大量有用的 API 被彻底锁死——2026 年了还不能扩展 Siri，让人抓狂。Android 本来更有希望，但谷歌最近搞的 APK 验证又搬石头砸了自己的脚。**rvz** 反唇相讥：每月给编程 agent 掏 100 多刀不吭声，99 美元一年就嫌贵，「开发者」不过是想让工具全都免费的挑剔消费者。**mft_** 回击道：我给自己写 app，根本不需要托管和分发，这对苹果是零成本，它没必要掺一脚；我在 Windows、Mac、Linux 上一直能跑自己的软件，只有移动 OS 不行，这才是烂的地方。**matheusmoreira** 更激进：计算自由重要到应该写进法律，远程证明、锁死的 bootloader、「应用商店」应当被判为非法，拥有自己的计算机应该是宪法权利。**mercutio2** 提供了务实解法：免费账号的构建每周过期一次，写两个脚本加个 cron 就能自动续；但 **reolbox** 说自己试过，最需要用的时候恰好过期而笔记本不在身边，最后还是转成了 PWA。**rpdillon** 推荐了一个思路完全反转的方案 WebXDC：app 就是自包含 web 应用的 zip 包，通过群聊本身分发和通信，没有应用商店、没有开发者费、没有 SDK。

**tptacek 贴出的清单成了讨论核心。** 他列举了近一个月做的东西：带 agent 循环的 Apple Music 播放器（可以说「我要去木工房干活，放点适合木工的音乐，播放列表一直填满且不重复」）、把一句话餐食描述解析成宏量营养素并存进 SQLite 的卡路里追踪器、macOS 菜单栏上的 Apple TV/Roku 遥控器、渲染 LaTeX 数学记号的 SageMath 计算器前端、会导入并消化 PDF 的「自动驾驶维基」、家里各房间温度传感器的菜单栏面板、设计相框切割清单和裁口深度的排版工具。他说这些应用普遍比 App Store 里能拿到的更好，而且自己「做得还不够多」。有人质疑一行字的餐食描述怎么可能算准卡路里，他解释自己几乎所有饭都在家做，会给出蛋白质和油脂碳水的精确克重，还拿三家前沿模型交叉验证过、手工核算过常用菜谱、并用几个月的体重变化对照过 TDEE。至于「适合木工的音乐」，他说这不是凭空乱抓，是他放过一堆歌之后让模型继续找类似的，实际结果就是「放了很多 Tom Petty」。

**质疑随之而来。** **nonameiguess** 写了整条讨论里最长也最尖锐的一条：工程师有种「工具能解决一切问题」的心态，但真的解决了吗？你量化上真的更健康了吗？血检、体脂率有变化吗？他反思自己为什么不用 LLM 做这些——因为他觉得自己没有这类问题：他早就吃得合适、练得合适、对听的音乐满意，在手机 app 出现之前就拿过两次州级越野和田径冠军、SAT 和 GRE 满分。他真正缺的不是工具，而是优先级和动力：今年运动少了、和妻子聊得不够、根本不和朋友联系、不常出门——而这些都不是软件能解决的。**tptacek** 简短回应：从四月开始到现在，他确实剧烈地、大幅地更健康了，这本来就是他早该追踪的东西。**eloisius** 站在批评一侧：这些人只是花更多时间摆弄电脑，而不是去做那些软件本该腾出时间让他们享受的事，这就是当年 IoT 智能开关自动化的重演；他说自己永远不会靠 vibe coding 出一个完美工作流工具而成为伟大摄影师，得真的每周拍几千张、亲手熬编辑。**IncreasePosts** 反驳了一个漂亮的比喻：你已经爬上了某座山顶，在平地上闲逛，然后低头看那些还在半山腰挣扎的人，问「他们何必费这个劲」——他们只是在搭建你已经拥有的系统。

**「睡眠顾问」意外成为吐槽焦点。** **JeffRosenberg** 说自己被这个随口带过的细节绊住了：时不时你会瞥见一个从不知道存在的世界。**what** 直言「这人听起来疯了，你不需要花钱请睡眠顾问给孩子排小睡时间」。**a2800276** 加码：这明显是净负面，错过一次小睡就焦虑到宁可花一周和 Claude 聊天写 app，也不肯多陪陪婴儿念念书哄睡。但也有反方：**tptacek** 说「你养过孩子吗？这是我听过最不令人意外的开销」；**camgunz** 透露自己伴侣就是睡眠顾问，找上门的家庭大多已到崩溃边缘、婚姻岌岌可危；**xyzelement** 说前两个孩子都顺利带过来，第三个怎么都放不下，睡眠教练给的策略确实有用。这条支线还岔出一段北欧育儿讨论：**wojciii** 说在斯堪的纳维亚，婴儿裹进小睡袋放在婴儿车里在户外睡觉是常态，官方指南给的下限是零下 10 度；**LtWorf** 表示自己在北欧住了几年从没亲眼见过，怀疑并不普遍，双方为「北日德兰半岛算不算整个斯堪的纳维亚」拌了几轮嘴。

**成本被反复吐槽。** **bastawhiz** 说他非常认同全文，但被「个人软件竟然有 30 美元/月的 Neon 账单」震到骨子里，这些用例连 SQLite 都嫌奢侈，「这是 Heroku 式定价」。**assimpleaspossi** 更不客气：一年将近 2000 美元荒谬到让人怀疑作者自己写软件的能力，他自己 VPS 每月 2 美元，用 HTML/CSS/JS 加 Postgres 就把类似的事办了。**ymolodtsov** 分享了迁移经验：意识到托管数据库和认证有多贵之后，他改用 Hetzner 上三台 VPS，总共每月 14 美元。**efortis** 给出了极简派方案：后端就是 Nginx 的 WebDAV 模块，数据是纯 JSON 文件，认证用浏览器内建的 Basic Auth，手机上「添加到主屏幕」，VPS 每月 12 美元。

**还有一批人纯粹在晒自己的作品。** **matusfaro** 等了 Duolingo 支持蒙古语好几年，最后一个晚上写了自己的 DuoMongo；**harryf** 为一位自闭症患者做了 PWA，对方的原话是「我没法用大多数软件，我用颜色思考」，于是他按对方的思维方式设计了整个应用，数据全存本地；**yen223** 开玩笑说 vibe code 一个白噪声生成器比在应用商店里下一个还快，实测之后发现这话令人沮丧地成立——慢的部分是筛掉那些满是广告的 app；**runarberg** 干脆手写了不到二十行 Web Audio API 代码来证明这压根不需要 LLM。**afro88** 提到一个耐人寻味的例子：他做了一个引导自己处理情绪困境的对话式工具，很有用，但因为涉及心理健康的法律伦理雷区和版权问题，既卖不掉也开源不了——只能自己留着。

**几条冷峻的观察。** **stillpointlab** 回忆 90 年代末 FoxPro、MS Access 这类 DBMS 曾让非技术人员用可视化界面拼出健身、记账、备餐应用，然后 2000 到 2020 年代是赢家通吃的 SaaS 大整合；他的直觉是「一人份软件」是暂时现象，长久性自有其价值，人们迟早不想调试自己的东西，5 美元一个月或免费增值最终会接管。**hamdouni** 问了一个没人答得好的问题：这些软件如何在作者身故后继续存在？**swiftcoder** 说这正是他反复撞上的恐惧，连给家里装个 pihole 都有严重的公交车因子。**tim-projects** 对「很快就不需要开发者技术栈」的预言毫不客气：他从 agent 面世第一天就在用，那套说法不成立——模型做的是刚好糊弄住用户的最低限度，一个功能通常得提示十到二十次才真正建成，而且下一个功能很可能把上一个改坏或删掉。**Diogenesian** 则对「像家常饭一样」的类比火大：vibe coding 出来的个人软件顶多算把微波炉热的拉面配上微波蔬菜和烤箱鸡肉，AI 热潮最令人沮丧的地方就是看着技术人贬低人类经验。**mattjhall** 一句话总结了整条讨论的漂移：「我觉得挺遗憾的，一篇在我看来是讲牺牲自己时间把家人聚在一起的文章，变成了不牺牲任何东西地超优化自己的生活。」

作者 **ajwaxman** 本人也现身：刚结束一趟长途自驾回来就看到上了首页，是个不错的惊喜——那趟路上最后一个休息站他儿子还爆发性腹泻了。

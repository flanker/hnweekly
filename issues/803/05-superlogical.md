## 文章摘要

Superlogical 是 Mitchell Hashimoto 创办的新公司，这个页面是它的首次公开亮相——一份愿景声明加团队与投资人名单，还没有产品。首屏用一串排比铺开它想覆盖的范围：本地开发、远程访问、编码 agent、后台任务、生产应用、线上调试、沙箱、共享终端、事故响应、人与机器、运维历史、多人协作工作——"所有工作"。

它对问题的诊断是这样的：今天构建和运维软件的活动横跨本地机器、远程主机、沙箱、服务和生产系统，而且有多种运行模式——由人交互式驱动、由 CI 和后台进程自动执行，以及越来越多地由并行工作的 agent 驱动。这些工作本质上是相关的，却被今天的工具切成了彼此独立的系统：交互式工具假定界面前坐着一个人；自动化的工作消失在任务与日志里；而当工作推进到生产环境，它又活在另一套系统与权限控制之后。团队强调，AI 让这种碎片化变得更显眼、代价更高，但并非 AI 造成的——系统管理、持续集成、远程开发和协作已经在同一批边界上磨了几十年。他们认为缺失的那一层，是围绕工作本身的**持久会话**（durable session）：它能跨越应用与环境、默认提供相关上下文、暴露结构化数据与动作、保存历史，能被软件驱动，同时对人保持可见和可控。

他们把计划拆成三步：一、做一个出色的多路复用器；二、让其中一切可组合；三、让它在生产环境里安全可运维。所谓多路复用器，就是把多路独立的流通过一个共同界面汇聚起来；对他们而言，这意味着交互式工作、自动化工作与生产工作共享同一套精心打磨的底层系统，而不是散落在各自的工具里。

起点是一个终端多路复用器。它把多个终端块组织在一个长生命周期的会话里，你可以关掉应用、换一台设备重新连上，从离开的地方原样继续。熟悉 tmux/screen 的人会感到亲切，但他们要做更现代的版本：会话可以通过 Web 以及 macOS/iOS 原生应用访问，把实时会话分享给他人是从第一天就内建的能力；同时他们要解决现有工具最常见的那些体验硬伤——让滚动回溯（scrollback）、文本选择和滚动都原生地工作。他们主动回应了"以终端多路复用器开局是不是格局太小"的质疑：愿景要大得多，但终端连接着开发者、agent、工具和基础设施，因此是后续一切的正确地基；他们会做一个高质量的终端多路复用器并在成长过程中始终保持它在这件事上的卓越，第二步和第三步以后再谈。

团队方面：Mitchell Hashimoto（Ghostty 作者，HashiCorp 联合创始人，Vagrant/Terraform/Vault 等的创造者，从最早期到 IPO 担任了十余年 CEO 与 CTO）、Jack Pearkes（HashiCorp 的第一号员工，后任工程 VP 与研发 VP）、Alasdair Monk（Poolside 体验负责人，前 Vercel 设计 VP，曾在 HashiCorp 与 Heroku 任高级设计负责人）、Hector Simpson（在 Poolside 设计 agent 化体验，曾在 Heroku、HashiCorp、Clearbit、Vercel 交付面向开发者的产品）。投资方包括 Notable Capital、Amplify Partners，以及一长串天使：Aaron Levie、Armon Dadgar、Dax Raad、Greg Foster、Guillermo Rauch、Jacob Thornton、Mario Zechner、Merrill Lutsky、Patrick Collison、Paul Copplestone、Stephen Haney、Steve Ruiz、Tobias Lütke、Tomas Reimers。页面底部有邮件订阅入口，招聘入口则是一条命令：`ssh superlogical.jobs`。

## HN 评论精华

需要先说明的是：这场讨论**很大程度上没有落在产品本身**——因为页面上还没有产品可谈。讨论主要分成四股：这个赛道已经有多少同类工具、投资人名单引发的政治争议、招聘用 `ssh` 这个彩蛋，以及对"标题只有一个公司名"和"网页说了半天不知道在说什么"的元吐槽。

- **brandall10** 的置顶评论直接把它放进了一个已经相当拥挤的赛道，列举了他最近在玩的几个东西：pi-web（Pi 编码 harness 的 Web 前端，可跨多台机器复用会话）、herdr（打磨得相当好的 agent 化多路复用 TUI，能按子 agent 活动自动开关窗口）、firstmate（编码 harness 的元环境，更自然地处理子 agent 的派生与通信、worktree 管理等）。**loveparade** 在下面问了一个很多人都有的问题：herdr 到底比 tmux 多给了我什么，除了那个 agent 侧栏？**Hissigh** 说自己也没懂，他连 tmux 都不用，窗口管理器已经给了工作区、分屏和平铺，而且他更愿意专注单个项目而不是同时耍五个球。**dregitsky** 提出了一个技术性观点：这些工具都假定你有机器来跑 agent，但要真正并行，每个 agent 应该有自己隔离的开发盒子跑完整开发环境，而不是同一台机器上的多个 worktree——而那并不好搭建和管理。他还分享了一个反直觉的观察：Codex 桌面端发布时他非常确信 GUI 才是编码 agent 的未来（不就是个聊天吗），结果证明 CLI 杀不死。**theturtletalks** 提到这个空间最早的应用是 VibeTunnel，本质就是"网页上的终端加一层组织"，被 **dakolli** 尖锐回怼：你们这些 LLM 人已经不知道自己在干什么了，我不认识任何一个做这么多元 agent 折腾还真能产出东西的人，就像那些整天配 nvim 却以为自己在提高生产力的人。

- **jelder** 提出了最朴素的问题：这个生态位真的空着吗？我还在用 iTerm2 加 tmux，我错过了什么吗？**1123581321** 给出了本帖对产品价值最扎实的辩护：你确实错过了一点，但保持满足就好。多路复用器有一堆小伤口和限制——当你希望原生的、贯通操作系统的行为一路流到多路复用器里的应用和连接时就会碰到，比如在 tmux/zellij 面板里做手势滚动很难，因为正确的事件传不过去；这和设计一个好的终端库（比如 Ghostty）是同一种痒。此外还有大量数据连接的统一与抹平工作：让面板里的 ssh 会话或 Claude Code 会话在面板关闭后能无缝重连或干脆不断线，在今天的多数配置下都需要很多黑魔法。**drob518** 补充说，多路复用器相对于多开窗口/标签页的经典优势是会话可以从终端 detach 后继续运行，本地场景下价值确实小些，但在远程主机上仍能省掉重复登录的开销。

- **devy** 的评论捕捉到了本帖最讨喜的细节："那个招聘链接太极客了，第一次见到用 `ssh superlogical.jobs` 在终端里看职位描述。"**gfat** 认为这大概也是个不错的申请者过滤器，**insane_dreamer** 补充说估计还能挡住 AI 批量投递。**tiagod** 是唯一的差评："ssh 这招很好玩，但我希望他们还有别的方式看职位——我现在这条线延迟巨大，体验相当糟糕。"**gizajob** 的回复很毒："那大概不是他们想要的那种网络连接。"**dolmen** 则给出了一条实用的安全提示：建议用 `ssh -o PubkeyAuthentication=no superlogical.jobs`，因为如果你用 SSH 连 GitHub，你的公钥会公开在 `https://github.com/<username>.keys`，服务端可以据此反查你是谁；他自己的 `~/.ssh/config` 末尾就常年放着 `Host *` / `PubkeyAuthentication no`。**ButlerianJihad** 顺势编了个段子："嘿，Linus Torvalds 今天登录了 100 次！""哇，他一定很想要这份工——哦。"

- 投资人名单引发了本帖最激烈的争执。**_verandaguy** 直言希望 mitchellh 不要拿其中某些人的钱，尤其点名 Tobias Lütke，称他在一些根本性议题上长期站错边，最近还鼓吹一种"财富决定你参与程度"的付费民主。**throwaway-blaze** 反驳说原评论歪曲了 Lütke 的说法——他主张的是纳税更多的人在政府如何花钱上应有更大发言权，这个提法表面上并不疯狂，只是推到极限会不好。**fourseventy** 质问"难道只能拿政治立场跟你一致的人的钱？"**an0malous** 的回应很干脆："他表达了偏好，没有说要立规矩来强制执行。"**antonyt** 则把这种心理讲得更完整："我觉得这人蠢且错 → 糟糕，这个蠢且错的人会对我关心的项目有超额影响 → 糟糕，他还能从中获利 → 糟糕，他正在用财富做蠢且错的事。这是一条正常且合理的思路。"另一条以 [flagged] 收场的支线也围绕投资人的政治立场展开。

- **hobofan** 提出了一个更结构性的质疑：为什么一家半隐身状态的初创公司在发布公告里列出 15 位投资人？其中多数是 VC 或高频天使，他们联手就能把这个产品推进 200 多家公司，无论它好不好——"先找到 product-market fit"的老规矩去哪了？一个本可以自掏腰包的准亿万富翁，为什么这么早就拉进这么多投资人？他强调自己很期待 Superlogical 会做出什么，"只是创业圈似乎一天比一天更像小圈子"。**colesantiago** 的辩护是：Ghostty 和 libghostty 本身就是 product-market fit，Superlogical（据称）用它来做多路复用器，Mitchell 只是锦上添花，他有构建被数百万开发者使用的定义性开发工具的履历，所以 15 个天使很合理，开发工具领域多点投资对大家都好。**hobofan** 澄清说他并不怀疑 Mitchell 的能力（"我心里那点偶像崇拜把他排在开发工具领域史上最强之列"），也不怀疑投资人会争着塞钱给他，他问的是：既然用不到 1% 的净资产就能舒服地自筹几年，除了强行获取市场准入，拿这笔钱对他有什么好处？**dust-jacket** 提出了善意解读：这表明他们有资金（预先回应"这么怪的东西没人投"），而且透明公开（预先回应"到底哪些混蛋才是真正的所有者"）。

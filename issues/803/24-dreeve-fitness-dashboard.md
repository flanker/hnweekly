## 文章摘要

Dreeve 是一个自托管、开源的运动与健身数据仪表盘。作者 frogfuhrer 在 Show HN 自述中说明，这个项目他已经断断续续做了几年，原名叫 "Statistics for Strava"，**最近改名为 Dreeve 是因为 Strava 改了 API 使用条款——他们把 API 收费墙化了**。

用法很直接：你把它指向自己的活动文件（FIT/TCX/GPX），或者连接一个 Strava 账号，它就会给你生成一个仪表盘。核心功能包括：

- **活动导入**——原始 FIT/TCX/GPX 文件，或连接 Strava 账号
- **管理后台**——浏览器界面管理活动、装备和各项设置
- **仪表盘**——统计数据与图表的快速总览
- **自动化规则**——用规则简化装备记录、通勤标记等
- **活动列表**、**月视图**（带交互式日历的月度统计）
- **装备统计**——追踪每辆自行车、每双跑鞋的使用量
- **保养追踪**——盯住装备的磨损情况
- **Eddington 数**——距离里程碑指标
- **路段与成绩**（Segments & Efforts）——深挖你的路段历史与用时
- **热力图**——可视化你活动最密集的区域
- **里程碑**——关键成就的时间线视图
- **Rewind（年度回顾）**——回看你这一年的运动轨迹
- **挑战赛**——查看你完成过的 Strava 挑战
- **活动照片**存档
- **AI 训练助手**——个性化训练建议（可选，默认关闭，需自行配置）
- **用户徽章**——可嵌入到个人网站、博客或论坛签名的分享徽章
- **PWA 支持**——可以像原生 App 一样在手机上使用

技术栈作者形容为"简单、直接、快"：**PHP 8.5 + Symfony，SQLite，Docker Compose**。以 Docker 容器运行，所有数据存在 SQLite 里，**任何东西都不会离开你的机器**。

作者也主动说明了限制（caveats）：它是围绕单用户设计的，**没有多租户方案**；AI 训练助手是可选的，不配置就不开启；**路段数据如果你想要，仍然来自 Strava，这是他唯一没能去掉的依赖**。文档在 docs.dreeve.app。

关于名字，README 里有一段温柔的解释：**dreeve**（读作 /driːv/）是西佛兰德语（Dreeve 维护者的出生地）中的一个词，指两侧种满树的乡间小路——"每个骑行者和跑者都热爱的那种路"。

**需要如实说明：这条帖子在 HN 上几乎没有引起讨论。**截至抓取时只有 18 分、3 条评论，其中一条还是作者自己的回复。

- **ashenke** 问了唯一一个实质性问题：它看起来不错，是否也能从 Garmin Connect 导入数据？如果他是用 Garmin Connect 同步到 Strava 的，那么用 Garmin 集成是不是能拿到更多数据？他还表达了自己的核心诉求——"我想有个办法把我所有的训练数据本地归档并保存下来，这个看起来很有意思。"

- 作者 **frogfuhrer** 回复：**只能从 Strava 或者 Garmin 二选一同步，不能同时用两个。**如果你有 Strava 订阅，他认为配置 Strava 导入会是更好的选择。

- **chriscyber** 留下一句简短的称赞："很棒的应用！超级有用。"

除此之外没有更多讨论。这个项目本身的技术选型（PHP 8.5 + Symfony + SQLite 做自托管仪表盘）、Strava API 收费墙化这个引发改名的行业背景，以及"运动数据主权"这个在 HN 上通常很能引发共鸣的话题，这次都没能激起对话——帖子大概率是沉在了首页之外。

## 文章摘要

Replicant Space 是 Tony McNulty（HN 用户名 mercutio）做的一款"API 优先"的太空探索游戏。它没有客户端，也没有需要下载的东西——**HTTP API 就是游戏的一等界面**。你可以纯用 curl 玩，可以自己写脚本，可以给它做一个前端 UI，也可以直接放一个 AI Agent 进去替你占领银河系。用作者的话说：接口就是游戏（the surface is the game）。

作者在 Show HN 里写下的这段自述，是这条帖子最打动人的部分。2025 年圣诞期间他工作倦怠严重：过去几年很难熬，几轮裁员之后，他曾深爱的公司只剩下一小撮人。作为一种应对机制，他有一段时间近乎解离，把自己整个扔进个人项目里。他说 **AI 正在摧毁他对编程的热情**，他试图重新找回开发的意义。在花了几个月折腾这个游戏之后，他慢慢重新爱上了写代码，顺便自学了一堆之前不熟的技术——Astro、Flask、Redis、Celery、Just。

游戏设定直接取自 Dennis E. Taylor 的《我们是军团》（Bobiverse）系列，同时也受 Space Traders 启发。你扮演一台冯·诺依曼探测器：醒来后查了下自己的资产标签，意识到你不是"原版的你"，而是一个克隆体——那好吧，得起个新名字了。你带着几台采矿无人机出现在一个陌生星系，工作是建立制造业、协助"出走计划"（exodus project）。但作者强调这个银河系里**没有任何强制内容**：不想干活也行，还有星星等着被探索、新物种等着被遇见，以及可能的危险。

功能层面已经相当丰富。**自动化**：可以写脚本调 API，也可以完全跳过写代码——直接打印出一系列带有指令集的 AMI 控制器设备，让它们去编排采矿无人机、勘测船和货运飞船组成的集群。**贸易**：打印一个交易控制器，配置好报价挂进目录，其他玩家会飞过来直接和它交易——本质上就是开个店。**蓝图**：从基础款起步，边玩边解锁，目前有 80 多种蓝图；当你在多个地点都堆了资源时，自然就会意识到自己需要一艘运输船。**自动工厂**：飞船自带的打印机只能干小活，要造新船和大型结构、要管理打印队列，就得部署自动工厂并持续给它送资源。**小行星偏转**：发现来袭小行星后读取撞击倒计时，在它周围部署推进器把它推离轨道。**成就系统**：给经验值，还经常奖励新蓝图设计。

API 设计得相当规整：`/replicants/{code}` 系列命令控制你的复制体（旅行、扫描、采矿等），`/devices/{code}` 控制你打印出来的设备，`/locations/{code}` 用来观察银河系。认证是每账号一个 API token、Bearer 方式，用邮箱找回。还有一条 SSE 事件流 `/v1/events/stream`，开一个连接就能实时收到你游戏里发生的所有事件，断线后可以带游标续传。文档里给出的示例包括 POST 一次星际旅行（返回出发时间、抵达时间、航线距离多少光年、跃迁类型等），以及给采矿无人机下 `start_mining` 指令（返回所在小行星带、矿点、资源丰度、密度、采矿周期秒数）。

游戏按**赛季**运作，每个赛季有一个横跨银河的目标、一个截止日期，以及后果。第一赛季从游戏内时间 2133 年 5 月 17 日开始，复制体们散布到银河各处；五六月间 Riker 指派大家在 Urcalis 星系建造一座巨构；6 月 12 日建造完成，累计打印 1700 多个组件、开采一百万单位资源；6 月 19 日六颗巨型小行星被成功偏转，方舟保住了；2151 年 7 月 1 日"出走方舟"启航，踏上前往地球的 18 年航程，第一赛季结束。次日第二赛季"重建循环"（Restoration Cycle）开启：方舟抵达地球，Bill 又有了一个新的巨构点子。第二赛季将于 2026 年 9 月结束。

作者反复强调这是一个纯粹的爱好项目：**没有付费档位，将来也永远不会有**。他做这个游戏是因为他自己想玩这个游戏。游戏永远免费，或者说只要他还能让服务器跑下去就一直免费；如果你也玩得开心，欢迎捐一点服务器成本。项目还有 Discord 社群，页面版本号显示为 v2.4.0（restoration build）。

## HN 评论精华

这条 Show HN 只有 11 分、两条评论，讨论非常稀少，因此这里如实说明，正文部分主要依据作者的 Show HN 自述与站点文档撰写。

- **NishanStepak**：表示自己是《我们是军团》系列的忠实读者，称其为"出色的科幻作品"。这条评论虽短，但侧面印证了这个游戏的选题精准——Bobiverse 系列讲的正是一个人类意识被制成冯·诺依曼探测器、不断自我复制并向银河扩散的故事，而"每个克隆体都是独立的自己、都要给自己起名字"这个设定被作者原封不动地做成了游戏的开场。

- **VatroslavM**：简短的正面反馈，感谢作者做出这个东西并分享出来。

值得一提的是，虽然 HN 上讨论冷清，但这个项目在"AI 冲击程序员职业热情"这个当下高频话题上给出了一个不常见的样本：作者的解法既不是抵制也不是拥抱，而是把 API 本身做成游戏界面，反过来邀请玩家"放一个 AI Agent 进去替你玩"。

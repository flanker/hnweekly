## 文章摘要

这是 HN 每月一次的固定栏目，由 sarreph 发起，题面只有一句话："你最近在做什么、想分享进展或想法？"没有正文，全部内容都在回帖里。2026 年 8 月这一期的整体面貌，比起前几年有几个相当明显的变化。

**第一个特征是「本地优先 + 隐私」成了压倒性的主题。** 大量项目的卖点不是功能有多强，而是「数据不出本机」。ertra 的 echo99 是纯本地模型的 macOS 通话录音工具，还会为每个说话人生成 embedding 以便跨通话追踪同一个人；sahil2412 的 Clippy Vision 是一个持续观察你屏幕、逐渐积累上下文的本地看守程序，跑在 Ollama + 本地视觉模型 + SQLite 上，目的就是不用每次都向 Claude 或 ChatGPT 重新解释上下文；joeamroo 的 km（knowledgemaxxing）把你申请了却从没打开过的 Twitter 存档、Google MyActivity、ChatGPT 日志和 Reddit GDPR 导出合并去重成约 50 万条记录、装进一个 SQLite 文件，绑定 127.0.0.1、不发任何外部请求——他的理由很直白："我想要一个懂我阅读口味的 AI 助手，但我不想仅仅为了让它可搜索就把这些交给别人的服务器。" BrunoBernardino 和妻子在做的 Uruky 是付费、无广告、可个性化的搜索：注册不需要提供任何信息（系统随机分配一个账号编号），还能跑工作量证明验证码换两小时免费使用，并支持匿名代金券形式的加密货币支付。

**第二个特征是浏览器端与本地推理基础设施。** stfurkan 在做 bitgpu，一个通过 WebGPU 在浏览器里跑的开源 LLM 推理引擎，并已经用它驱动自己的另一个产品；liviux 的 LoopTroop 是 MIT 协议的开源 AI 编排器，把上下文工程、循环、多模型规划都塞进一个 GUI；vinhnx 的 VT Code 则是自研编码 agent 满一周年的总结，他说上个月收到了开源社区最多的贡献，接下来要强化 plan 模式、工具策略结构和整体 harness。hiramwen 甚至做了 HiRAM Deals，专门帮人快速筛选 32GB 到 2TB 内存的高性价比工作站，就为了让人能真的跑起来那些每天在网上读到的本地 AI 工作流。

**第三个特征是老派的、纯粹为了好玩的工程项目仍然占据可观篇幅。** gassi 做了三年的 RomM 是自托管的 ROM 管理器和播放器，5.0 版本加入了存档同步引擎，可以在 PC 上开局、存档同步、然后拿起 AYN Thor 掌机接着玩；kolkov 写了个纯 Go 的 3D 渲染器并把它嵌进了 GUI 控件里；efortis 在琢磨如何让代码更易读，做了 Camelana（一款带 return/throw 连字的比例编码字体）和 Tabular Eye（一个在不加空白字符的前提下把等宽和非等宽字体列对齐的 IDE 插件）；KenPainter 发布了 Denorm，在 Postgres 里把派生列物化到表内和跨表，声称解决了终止性、竞态、不可绕过性和并发问题，用的是他从九十年代起就一直在面对的一类业务逻辑难题；postboy 用 200 行 Clojure 写了个极简的 roguelike 徒步游戏；wmil 在用 Starlark 生成 Minecraft 结构，计划接进自己的 Minecraft MCP，好让 LLM 少调几次工具就能盖出复杂建筑。

**第四个特征是 AI 时代的「元工具」和对 AI 副作用的补救。** apwheele 在做 veruscite-data，用来核验同行评审期刊里的引用是否为幻觉伪造；genekrapivin 的 Hiring Method 主打「确定性、数学驱动」的招聘——从简历和职位要求两端抽出结构化打分卡再做数学匹配，好让你能审查「为什么这个候选人是 85 分」的具体推理链条。而 mattmaking 的 halite.cc 食谱管理 PWA 则展示了另一种用法：用 yt-dlp 抓取社交平台上只用嘴说不写字的做菜视频、Gemini 兜底，还支持「把大蒜加倍」这样用自然语言改写配料表，并接了 MCP 让人跟 Claude 一起商量今晚吃什么。

游戏和创意类项目也很热闹：ksaun 的 Godot 2D 叙事策略 roguelite《Vestiges》、FallAlis 用 UE5 做的以真实城市重建为舞台的末日生存原型（代谢系统按真实医学时间线运行：脱水几天致死、饥饿几周致死，压缩后进入一个你无法硬扛过去的濒死状态）、hudsonhock 那个从参数方程里意外「发现」了 53 只仿佛活着的生物、于是干脆围绕它们做成游戏的 dancingmouse。

最后，全帖点赞氛围最好的一条来自 **sdellis**："我什么都没在做。感觉棒极了，而且我进展神速。强烈推荐。"

## HN 评论精华

- **gassi** 的 RomM 是这一期分享中最成熟的开源项目之一：自托管 ROM 管理与游玩平台，做了三年，5.0 版本的重点是存档同步引擎——只要客户端支持，你在 PC 上的进度可以无缝接到掌机上继续。

- **joeamroo** 一口气分享了三个项目，且难得地诚实交代了工程上的真实难点。他的房产估值工具 ARVnote 输入一个地址就能拉出可比成交、按面积/车库/地块/状况做调整并给出修缮后价值和交易分析，但他说："算术反倒是最容易的部分。几乎全部难度都在可比样本的选取上，而各个数据源之间不停地互相矛盾，所以大量工作其实是在决定某个房产该信哪一个源。" 他的第三个项目 LarpIn 是个恶搞版 LinkedIn——所有人都坦承自己在演，落地即分配一个生成的人设，只有一条全局信息流，每条帖子按「废话密度」评分，从「NPC（暂时）」一路到「LinkedIn 最终 Boss」。

- **eterm** 提出了一个小而漂亮的想法「Todo 驱动开发」：给 Gleam 的测试运行器 gleeunit 加一个独立的 "todo" 报告类别。与其面对一堆红色的失败测试，不如让它们先是黄色的 todo，这样你实现某一部分后立刻能看出结果。他用一组数字说明差别：从「12 个失败、16 个通过」变成「10 个失败、18 个通过」几乎不提供信息；而从「12 个 todo、16 个通过」变成「1 个失败、9 个 todo、18 个通过」则一眼就能判断这次的部分实现是对是错，不必去逐条读失败详情。他说自己本地用着感觉非常好，但一直没能把这个价值讲给上游维护者听懂。

- **hypendev** 的 Hypen 是全帖技术野心最大的一个：一个用 TypeScript、Rust、Go、Kotlin 和 Swift 开发原生移动/桌面/Web 应用的跨平台 UI 框架，做了大约六年。当前定位是「服务端驱动 UI」——应用逻辑活在云端、渲染发生在客户端，完整的 WASM 编译即将到来。它渲染真正的原生组件、自带路由与 Tailwind 支持、在 Web 端一个布尔值就能在 DOM 与 canvas 渲染间切换、支持应用互相嵌套、可以整个部署成一个 Cloudflare Worker、能跳过应用商店审核直接从后端下发移动端功能修复、还打算把状态和动作直接作为 tool 暴露给 LLM（而不是走无障碍接口和读屏那一套）。**KenPainter** 在下面回复说，那种 box/row/column 的 UI 通用性正是他脑子里一直想要却在别处没找到的东西，并追问了两个关键问题：浏览器端性能目标是什么？是否声称比 React 或 Angular 更好？

- **vunderba** 分享了一个非常「解决自己痒处」的工具 loopweave：他需要一些环境音、柴火噼啪声、下雨声、瀑布声之类的音效，但在网上寻找完美无缝循环的 WAV 文件的过程快把他逼疯了，于是干脆做了个工具——拖进一个 WAV/MP3，它自动找出合适的循环点、混合过渡、导出无缝循环，供游戏、氛围音景和 ASMR 使用。免费开源。

- **mlacks** 的分享带着一点个人史：他在用 AI 学习 Windows 系统性能，安排了一批定时提示词去研究、测试、实施系统层面的性能改进并把结果发布出来。他说自己一直很敬佩 Sun/Illumos 的 Brendan Gregg 和 Bryan Cantrill 在操作系统性能上的工作，但因为服役的那些年始终没有时间追赶到那个水平。他的一句吐槽引起共鸣："我实在无法接受，一个在九十年代基本就已被解决的用户界面问题，Windows 的 GUI 至今还在比三十年前强得多得多的硬件上挣扎求生。"

- **bharatsuthar** 用一句话给这个月的帖子加了一层现实底色："在找工作，而在软件业当前的行情下，这本身就像是一个独立项目。"

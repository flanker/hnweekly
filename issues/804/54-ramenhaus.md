## 文章摘要

RamenHaus（ramen.haus）是一个极简的个人网站，主题只有一个：拉面。它的自我介绍写得很清楚——"欢迎来到 RamenHaus，旋转拉面之家"。截至这篇文章上榜时，站上已经拍摄、嗦过并发布了 114 碗拉面。访问者可以从最新一条开始看，点击某一碗继续，或者浏览完整索引。

页面的核心视觉效果就是网站名字里那个"rotating"：每碗拉面的照片会通过 CSS 缓缓旋转，让你像端着碗转圈打量一样审视它。每条目附有店名、城市、国家和拍摄年份，比如首页展示的是"Classic Rekka Ramen — Ramen Danbo，日本东京，2019 年"。收录范围相当国际化，涵盖伦敦、罗马、曼谷、纽约、奥斯汀等城市的拉面店。

作者 Ole Reissmann 在页脚注明，这个项目的灵感来自 Lauren 的 Rotating Sandwiches（旋转三明治）以及 Naive Yearly 的所有人，并留下邮箱 chef@ramen.haus 接收想法、合作与提问。版权标注为 2023–26。整个站点最有个性的是那句技术声明："No cookies. No tips. No JavaScript. Just ramen."（没有 cookie。没有小费。没有 JavaScript。只有拉面。）——旋转效果纯靠 CSS 实现，全站不含一行 JavaScript。

这个页面本身信息量极少，甚至称不上一篇"文章"，但它以 245 分登上了 HN 首页第一位，本身就成了讨论的话题之一。

## HN 评论精华

这条讨论完美体现了任务说明里提到的"HN 讨论时常与标题无关"——126 条评论里真正讨论网站本身的只是少数，绝大部分变成了一场全球拉面店推荐大会，外加一场关于西方城市餐饮价格的长篇争论。

**关于"为什么一个转圈的拉面能上 HN 第一"，评论区先做了一轮自省。** **miguelbemartin** 直接发问："一碗旋转的拉面在 HN 第一位？为什么？"**sudo_cowsay** 回："因为这是食物啊哈哈。"**nehal3m**："欣赏漂亮的食物有什么问题吗？"**embedding-shape** 搬出了 HN 的投稿指南原文——"话题范围：任何好黑客会觉得有趣的东西。这包括的不止是黑客和创业。如果非要压缩成一句话，答案可能是：任何满足求知欲的东西。"**sevenzero** 的回答最简短有力："我宁愿看这个，也不要又一篇 AI 博客文章。"**downwithdisease** 写下了本帖最动人的一段："我喜欢它是因为它让我想起早期的万维网，那些由爱好者为爱好者创建、只展示一个主题的简单站点。这类站点在 1990 年代很常见，那时各种力量、功能和潮流还没有毁掉互联网。这个网站是一次令人耳目一新的体验，让我觉得也许互联网还没有被完全或永久地毁掉。这个网站就像是关于艺术的艺术——不可否认地美味的艺术。"**amelius** 贡献了全场最好的双关："因为不是每个人都已经 ramen-profitable 了。"（ramen profitable 是保罗·格雷厄姆造的创业术语，指创业公司的收入刚够创始人吃泡面活下去。）**ares623** 说这像回到 2000 年代末的网页设计，希望那种风格能回来。

**技术层面的讨论很少，但都很具体。** **user43928** 注意到"No cookies. No tips. No JavaScript. Just ramen."这句文案，忍不住猜"这是不是 Claude 写的？倒不是说那有什么问题，我只是好奇。"作者本人（用户名 **oler**）现身回了三个字："不是！"**Atreiden** 提了个真实的可用性问题："一点点 JavaScript 也许会不错。连着点了十几碗拉面之后，我得按十几次返回键才能回去。"**radicalriddler** 给出了纯 HTML 派的标准答案："右键点击返回按钮，你就能看到之前浏览过的所有拉面条目的完整列表。如果他用 JavaScript 实现，他还得自己造一个历史菜单。"**Kuinox** 报告了一个有趣的 bug 排查过程：网站在他 Linux 机器的 Firefox 上不旋转，但 Windows 的 Firefox 上会转；后来他发现自己的 Linux Firefox 设置了 `prefers-reduced-motion: reduce`——"所以我发现把 KDE 的动画设成即时，会告诉浏览器减少动效。"

**xg15 提出了本帖唯一一条真正的设计批评**，而且相当有洞察力："是只有我这么觉得吗，还是旋转反而让它变得没那么诱人？我想问题在于，配上那种打光，你会下意识地期待有大量运动（就像某个 Unity 3D 拉面艺术动画那样）。显然不可能有任何运动，因为它只是一张照片——如果仅此而已，感知会自行调整。但因为有了旋转，运动又被加了回来，只是照片的内容并不跟着动，于是整个东西现在看起来像一个拉面的塑料模型，而不是真的拉面。"**HelloUsername** 表示同意并补充了技术原因："它只是通过 CSS 旋转的 .jpeg。它的灵感来源（网站上提到的）rotatingsandwiches 是真的用固定光源做 3D 拍摄/摄制的。"

**最大的一条支线由 i_love_cooking 引爆**：他说自己从没去过日本，但每到一个大城市都会试一家拉面店，坦白讲一直挺失望的——"我猜也许是我对一碗汤加面条加配料期待太高了。作为一种形式它是天才的。但按它在西方城市的售价，它真的说不太通。我觉得它有点被过度炒作了。"他还补了一句挑衅的话："顺便说，你也可以用西方的食材/传统复刻这个形式，效果还挺好。"

回应之激烈可以想见。**emsy** 说以他的经验这话没错，但日本的拉面确实好得多，他在欧洲吃到的唯一一次好拉面在杜塞尔多夫，而那家店老板是从日本进口猪肉的。这条评论意外地开出了一整片杜塞尔多夫支线：**nixass** 说杜塞尔多夫其实是德国日本侨民的聚集地；**guessmyname** 补上了数据——杜塞尔多夫拥有欧洲第三大日本人社群（仅次于伦敦和巴黎），约 1.5 万名日本居民和数百家日本商铺；而海外最大的日裔族群在巴西，约 200 万人，多数住在圣保罗州和圣保罗市著名的自由区（Liberdade）。**plaguuuuuu** 的反驳最不客气："这就像是'我对某个外来文化的东西几乎零经验，我不明白那个文化的人为什么喜欢它'这种野生发言。首先，它相当难做。试试看，哈哈……其次，在日本拉面基本上很便宜，很多店有自动售票机，你付钱买一碗、拿到一张带订单号的票。除非你去的是高档店，否则这真的不是什么讲究或昂贵的体验。"**embedding-shape** 反问价格具体是多少："在巴塞罗那（我觉得也算西方城市）一家好拉面店，饺子约 5 欧元，一碗不错的拉面 12–14 欧元，加上一杯饮料，人均约 20 欧元，我觉得在外面吃这算相对实惠。"他还质疑那句复刻论："那样不就变成炖菜了吗？如果你把让拉面成为拉面的所有食材和汤底都换掉，它凭什么还是拉面？"**postexitus** 给出了对照："在日本，一碗不错水准的拉面大约 7–8 欧元。"**riffraff** 精确概括了争议点："付 7 欧元让它成为相当划算的一笔；14 欧元买'一碗汤'，它就变成一次一般般的体验了。"他还从意大利人的角度类比："我在布达佩斯能买到一份不错的玛格丽特披萨，但要 12 欧元，我每次都很生气，你不该为一点面团和马苏里拉花那么多钱。"**OJFord** 只回了三个字："伦敦人哭了。"**decimalenough** 补充了重要的背景："顺带一提，日本的价格也涨疯了。拉面过去在普通中华料理店是 500 日元，高档一点的多几百，没有餐厅敢突破 1000 日元大关。对旅行者来说幸运的是，这被日元汇率的崩塌抵消得绰绰有余，以美元计，今天的 1100 日元仍比十年前的 500 日元便宜。"

**brailsafe 把话题引向了更广的餐饮定价问题**："我不认为这是拉面独有的。汉堡不该花 20–30 美元买一块软塌塌的压扁牛肉，卷饼不该 15–20 美元，塔可绝对不该一个小小的就要 3–5 美元。这全是扯淡……但我怀疑它之所以这么贵，是因为人们真的会付这么多，而且因为服务业其他每一项成本都在挤压餐厅去抬高'它值多少'的天花板。"**linguae** 提供了一段令人共鸣的个人叙述：湾区的价格自疫情以来爆炸，十年前旧金山 El Farolito 一份烤肉超级卷饼 7.75 美元，汉堡不到 10 美元，熟食三明治 8–9 美元；两年前他彻底不在湾区外食了，"拿着六位数收入却感觉外食都吃不起，就像我买不起房、买不起内存一样，因为我竞争不过大厂"；而日本对持美元的人来说是天堂，一碗拉面约 1100 日元且普遍好吃，连麦当劳套餐都比湾区便宜得多。**estearum** 用四个字给出了本帖最精练的经济学解释："剧透：是房租。"**folkrav** 补充了行业数据：餐厅利润率其实极薄，食材只占成本的一小部分（印象中平均约三分之一），大头是房租（有人流量的地方通常很贵）和人力（这个行业按产出算相当劳动密集）。**Anamon** 从常识出发算账后感慨："你不是为了发财才开餐厅的……也不是为了过轻松日子。"他引用一位常去的夫妻店老板的话：虽然工作日只开六小时，但算上采购、清洁、备料、文书，他一周还是要干六天半（而且他是唯一的厨师）。

**关于"日本的拉面店该待多久"，德国人和美国人吵了起来。** **asyx** 说在杜塞尔多夫，日本餐厅明显比其他餐厅"不松弛"——在普通餐厅你通常会待三小时，而在拉面店大家默认一小时内吃完走人。**mc32** 反问："日本的拉面不就是快餐吗？堂食的人里很少有人会在麦当劳待一小时'用餐'。进去、点单、吃、走人。而且和汉堡一样，也有高端店。同样和汉堡一样，拉面不被认为是'健康'食物——高钠、高脂、营养密度偏低。它基本上就是快餐。"**shermantanktop** 承认自己身上的美国人属性发问："我知道这是我身上的美国人在说话，但是：三个小时你到底在干嘛？尤其还是在一家不上五道菜的地方。"**asyx** 的回答值得完整转述："我不知道美国的餐厅怎么运作，但在这边你去餐厅一般也是为了社交。我觉得服务普遍更慢。饮料也不免费续杯，所以很多餐厅会在饮品上做文章，你也会去试试。我们通常至少还会点甜点和咖啡。三小时也许不是常态，但大多数餐厅按 2.5 小时一档来安排。这不只是吃饭，也是社交，你把餐厅当成一个对话的场所。"他补充说，如果美式快餐店代表了美国餐厅的平均体验，那差别就很大了——"就算是最破的旋转烤肉或者 kebab 店，也会在街边摆桌子配烟灰缸，卖你一杯冰饮；而比那些贵得多的 Five Guys，灯光更适合做外科手术而不是聊天。"**toast0** 补了个冷知识：很多麦当劳门店有告示，逗留超过 30 分钟即视为游荡。**exiguus** 提供了一个温和的视角："对我个人来说，它是我的日式披萨。拉面和披萨在历史上都是工人阶级和贫困社区负担得起的、能吃饱的餐食。如果你避开猪肉，它就没那么快餐了。"

**具体推荐在评论区堆成了一份非正式指南**（这大概是本帖对读者最实用的部分）：伦敦的 Kanada-Ya（**hnlmorg** 说疫情前排队排到街上，店小得像别人家客厅）、Monohon（**mgaunard** 推荐，Old Street，只接受现场排队）、Shoryu Ramen 和 Bone Daddies（**nullify88**）；巴黎的 Kodawari 和斯德哥尔摩的 totemo ramen（**Hikikomori** 说这是他在欧洲试过的众多拉面店里仅有的两家接近日本水准的）；华沙的素食拉面 Uki Green（**koziserek**）；捷克布尔诺的 Ramen Brno（**m4rtink**）；东京赤坂的 Ittenbari 和大阪的 Tabutchan（**slau** 称前者是"拉面能达到什么高度的启示"，后者则确认了"这是人类发明的最令人愉悦的食物形态"）；京都的 Salmon Noodle（**ngruhn** 说自己在日本都没被拉面惊艳过，唯独随便走进的这家连锁店例外，他点的"三文鱼担担面"汤底不清澈、略稠且奶滑，三文鱼极嫩，至今仍念念不忘）；奥斯汀的 Ramen Tatsu-ya（**bdcravens** 说这家店开启了他对拉面的热爱）；曼谷的 Bankara Ramen（**mmasulli** 说总能看到日本客人在那儿吃，说明通过了"当地侨民测试"）。地域层面，**gusgus01** 说欧胡岛的拉面是他吃过的全美最好的之一，跟他住过的大多数城市（包括旧金山和西雅图）几乎不可比；**Anamon** 转述了一位日本前同事的话——世界上最好的寿司在温哥华。**PerryUlyssesCox** 则贴出罗马某家店的链接说"这碗看起来实在恶心"，**hereme888** 回了句公道话："在没入门的人眼里它们大概都这样，直到汤底浸透他们的味蕾。"

**几条实操向的分享也值得一记。** **dzhiurgis** 科普了基础知识：叉烧只是放进汤里的猪肉的名字，主要的分类依据是汤底类型——豚骨最难做，需要熬骨头 8 小时（不过他见过现成汤底出售，所以怀疑多数店在用）；味噌口味在家做相当容易；他还透露一种タレ（tare，调味汁）其实就是焦化大蒜（在油里煮 30 分钟左右再打碎），"一旦你知道了这个，你在豚骨里总能尝出来"。**hurflmurfl** 认为熬煮时间更接近 18 小时，他用高压锅 5 小时能做出不错的；他还指出西方餐厅拉面的另一大问题是面条——如果不自己做，能买到的那种干燥常温面就是不行，"我在家一点点提升拉面水平的过程中，单一最大的质量飞跃发生在我开始自己做面条的时候"。他还吐槽自己城市里多数"亚洲"甚至"日本"餐厅是那种"往豚骨里加奶油来让它变白"的地方。**_0ffh** 讲了一个反直觉的体验：他在日本吃的第一份从街角便利店买来、回家加热的廉价拉面（他特意澄清不是方便面，而是一碗冷藏的预制拉面汤）就彻底把他惊到了，"决定性地好过我在西方餐厅里能现实期待的水准。我不知道他们怎么做到的，但我学会了永远不要低估日本人对手艺的执着。"**mark_l_watson** 分享了一个居家小窍门：可以在网上买到很好的拉面原料，比如熬到浓稠的猪骨汤浓缩包；他喜欢放很多蔬菜，而结婚大半辈子的妻子从来不爱吃蔬菜，"我做拉面，她就把蔬菜当作不存在一样吃掉。这是个小小的生活黑客，也许对小孩也管用。"**bolt012** 指路 /r/ramen 社区及其 wiki，以及 /u/Ramen_Lord 那本免费公开的拉面书。

**farialima 贡献了本帖最有文化含量的一条**：他提醒"拉面学初学者"，基础知识可以从经典电影《蒲公英》（Tampopo）中获得，并说光是开场那一幕就是必看。这引出了一小串影迷讨论：**transitorykris** 提出了务实的反对意见——"这一幕很有趣，但亲爱的初学者们，就吃你的拉面吧。像往常一样对一切保持好奇，但你不需要戳你的食物、对着快餐陷入沉思。我倒要看看谁能在东京早上七点上班前找到一个正在猛嗦一碗拉面（而且显然吃得很享受）的上班族，同时还对着它搞怪。"**ryan_n** 补刀："用筷子抚摸面碗确实不是正常行为哈哈。"**vinaigrette** 注意到电影里有个镜头是一个人在车里给司机朗读，说这个点子太妙了；**gumby** 由此回忆起很多年前在曼哈顿坐出租车，司机一个流畅动作按下计价器旗子、把一张纸推到他面前说"考我！"——那是一份美国公民考试题，大概 50 道；两人过了两遍，"我自己不是美国公民，但我知道那些答案，而他不知道很多。不过如果那是他的目标，我希望他成功了。"

最后是几条关于"这类网站还能怎么玩"的延伸：**darknavi** 说这个网站让他想起自己想做的一个小站——多年来他一直在拍浴室洗手池的照片，让他好奇的是水池和水龙头之间比例与布局的疯狂差异，起因是有太多洗手池你必须碰到池壁才能洗手；所以他想做一个展示全世界浴室洗手池的类似网站。**culi** 贴出了 wikipaella.org，一份"正宗"西班牙海鲜饭餐厅地图。**jedschmidt** 则回忆起"科技界一个更天真也更快乐的时代"：他曾用推特的开放 API 做过一个叫 ramendan 的游戏，你必须每天晚饭都吃拉面，并发推带 #ramendan 标签作为证明、附上照片链接（那时推特还不支持图片），还要打上地理标记，好让他们确认那确实是在你所在时区的日落之后。而 **Mistletoe** 说自己本来还想投稿自己城市里最爱那家店的照片，可惜没有这个功能；**blooalien** 提示页面下方留了邮箱，可以写信问问，甚至可以合作把用户投稿功能加上。

## 文章摘要

Andrew Emerson（HN 用户 aemerson_）在 Show HN 上发布了 Altar II——一款厚度仅 4.75mm 的超薄机械键盘，定位是「取代你的妙控键盘」。他的自述很直接：作为重度 Mac 用户，他觉得苹果在键盘的硬件、软件和功能上都没有给予应有的重视，所以他想做出「苹果本该做的那把键盘」。这个项目花了将近两年。他还提到自己四年前在 HN 上发布过第一款键盘，那次的反响之大让他辞掉工作、全职做键盘，Altar II 吸收了当年帖子里的不少反馈（比如可拆卸旋钮）。

**工程上最核心的突破是把真正的机械轴装进了不到 5mm 的机身。** 关键在于把预压张力弹簧横向而非纵向布置，从而实现 1.8mm 的垂直行程；轴体是双钢臂剪刀式结构，带回位弹簧，触发力 40gf，钢制构造保证了长寿命。作为对比，官网列了一张厚度表：Altar II 4.75mm（全机械）、苹果妙控键盘 10.09mm（非机械）、罗技 MX Keys 20.50mm（非机械）、NuPhy Air75 21mm（全机械）、Keychron K2 30mm（全机械）、IBM Model M 50mm（全机械）。作者在评论里说，把 USB-C 口塞进去本身就是一场硬仗——所有现成的 USB-C 外壳都比键盘本身还厚，最后只能定制。他还提到另一个约束是 PCB 背面完全不能放元件，因为那里根本没有空间，而元件数量却很多。

其余的特性堆得很密：**M-Dial** 是一颗磁吸可拆卸、可点按、可更换的旋钮，转动调音量、单击播放/暂停、双击下一首、三击上一首、长按唤起 Siri；随附一个低矮版本，官方还会公开 3D 文件、图纸和规格，让用户自己设计并打印旋钮。**Harmonic Synthesiser** 提供触觉反馈——按住修饰键时会有平滑的振荡嗡鸣，快捷键完成时有一记轻柔的 pop，收到 Mac 通知/提醒/警报时会轻敲你一下。机身内还有一颗高保真扬声器负责开机音、充电提示音之类的细微音频反馈。**NiteLite** 背光只在环境光线昏暗时启动，使用长波琥珀红光以保护夜视能力、减少眼疲劳并避免干扰昼夜节律。**Inertial Damper** 是双层减振系统：逻辑板与一体式机身之间的硅胶膜，加上底部超大面积的弹性体脚垫，把打字平台整体悬浮起来做声学与振动隔离。配套的 macOS 应用用 Swift 原生编写，可改键位、旋钮行为、背光、触感与音量，还能为 Figma、DaVinci Resolve、VS Code 等特定应用配置快捷键——但作者强调所有设置都存在键盘本体上，换电脑换系统都能带走，不装应用也能用。

规格方面：299mm × 116.5mm，重量预计 300-400g；固件基于开源的 ZMK（Zephyr RTOS）；2 条蓝牙 5.0 LE 通道加 1 个 USB-C；宣称充电 2 分钟可用 2 天、常规使用续航最长 30 天；材料为再生聚合物（塑料部分至少 50% 再生成分）、6061 铝一体机身、TPU 脚垫、硅胶膜和 FR4 逻辑板；包装完全用纸和甘蔗浆、无塑料。布局是 75%，保留完整功能行和全尺寸方向键，Command/Option/Control/Fn 都在 Mac 用户预期的位置。颜色一栏写着一句致敬福特的玩笑："提供任何颜色。只要它是黑色。" 定价 $349，预订立减 $100 至 $249。

## HN 评论精华

这条 Show HN 拿到 300 分，作者本人几乎有问必答，是全期信息密度最高的一场作者互动。

**压倒性的第一话题是缺少 Touch ID。** charrondev 说自己每个工作日要用 20 多次妙控键盘上的指纹识别，这始终是他无法换用机械键盘的原因。作者的回答解释了背后的技术与商业现实："很遗憾做不到，至少无法安全地做到，也无法以用户预期的方式做到。我真的尝试过。" 他说可以塞进**一个**指纹传感器，甚至配上防篡改的安全芯片，但它永远无法与 Apple Pay 之类的服务协同；也许能通过把自己伪装成读卡器或安全密钥来实现登录 Mac，但因为无法与苹果的 Secure Enclave 通信，体验绝不会是无缝的。他后来补了一句更完整的产品判断："有一个在某些场景可用、某些场景不可用的指纹传感器会极其令人困惑。因此在今天，**不**加指纹传感器才是更好的体验。" 他也留了句期待：也许某天苹果会像开放 Find My 那样开放 Touch ID。

社区自己找出了几条绕路方案：**ls-a** 和 **toomuchtodo** 都贴出了 tinytouch 这个开源项目；**xp84** 分享了一个思路更精巧的方案——macOS 支持智能卡读卡器，且在配置好时会把认证工作交给它，所以只要模拟一个智能卡读卡器，你就能自制指纹传感器并让它像智能卡那样签署挑战。他也如实转述了作者的坦白：这在安全性上并不等价，拆开设备短接传感器满意时闭合的引脚就能绕过；但他补了一句很实在的话——除非你是 CIA、摩萨德、军情六处或 FSB 的目标，否则没人会费这个劲，普通对手只会直接敲晕你，把你昏迷的手指按在传感器上。**cafebeen** 描述了很多人的真实处境：他用机械键盘，但还在桌子旁边**另外**放一把苹果妙控键盘，纯粹为了那颗 Touch ID。

**ary** 试图叫停这场刷屏："大家都知道这做不到，作者本人也知道。你抱怨这个到底给讨论增加了什么？如果这是你的决定性障碍，别买就是了。" 但 **throw10920** 反驳说这是一种「用羞辱让人闭嘴」的廉价手法，恰恰与 HN 的初衷相反。

**第二组高频话题是布局与本地化。** 大量欧洲用户在求 ISO 布局：K0nserv 说 ISO 是必需品，还想要空白或可换键帽；dimitrieh 要求欧盟布局中左 Shift 旁边那颗额外的键；jonasmst 说如果有北欧布局他会立刻下单。**philistine** 给了一条颇有说服力的市场建议：美式布局的机械键盘已经多如牛毛，真正未被满足的是 ISO 国际版本——他因为想要一把带 Mac 修饰键的 CAN/CSA Z243.200-92 布局机械键盘，不得不自己用 SVG 画出布局去找 Max Keyboards 定制，"记住，我并不想自己设计，我是被迫的"。**ls-a** 则对方向键被挤压进主键区表达了尖锐不满："两年了你还是把方向键塞进去了。这个『设计』不可接受，老哥。你需要跟你的用户聊聊。" 分体党也自成一派：nicksergeant 说"如果它能从中间劈开做人体工学就是我的梦想键盘"，ChaseRensberger 补了句"分体 + 直列排布才是巅峰"，pierrefermat1 则给他们贴出了两个现成的分体替代品。数字小键盘同样有拥趸，作者的回答是暂无计划，而且如果做也会做成独立设备——"我个人不喜欢小键盘卡在键盘边缘和鼠标之间，我更希望它在键盘左边或鼠标右边"。

**第三组是硬核技术问答，作者的回答尤其值得记录：**

- **richwater** 说这些轴让他想起了 MacBook 那代口碑崩坏的蝶式键盘。作者正面承认蝶式很糟，然后逐条讲了差别：Altar II 是真正的机械轴（有弹簧和触点簧片被按压），蝶式是金属穹顶；行程 1.8mm 对蝶式的约 0.5mm——蝶式的很多问题源于极小的公差，一粒灰尘就能卡死，而 Altar II 的轴体大得多，这个问题小得多；蝶式的臂是塑料的，Altar II 的臂是钢的。

- **bix6** 和 **jbonatakis** 想要全彩背光。作者给了两条拒绝理由，都很有说服力：第一，背光在夜间理应只用暖色，因为其他颜色恰好在眼睛最脆弱的时候造成负担；第二，红色 LED 所用的 AlGaInP 化学体系比其他颜色更省电——作为一台如此纤薄的设备，电池很小，必须处处省电。

- **recensorium** 问了一个非常内行的问题：配置到底存在固件里还是 macOS 应用里？如果只是个轻量配置编辑器、映射常驻设备端，那和「未来某次 macOS 更新搞坏了应用、旋钮和触感就罢工」是完全不同的两回事；另外，如果公司哪天不在了，固件是否承诺可刷写/开源？作者的回答满足了所有关切：一切都在键盘本体上，应用只是在设备上改配置文件；重映射旋钮后换台电脑，映射依然生效。只有极少数体验性功能（比如收到通知时的触感反馈）需要应用，因为键盘并不知道你的系统里在发生什么。Altar II 的固件会像 Altar I 一样开源，两者都基于开源的 ZMK，而且团队里有两位是 ZMK 的长期贡献者——"我们从 ZMK 受益太多，所以尽可能回馈"。

- **ethersteeds** 问 Linux 兼容性。作者说打字、音量控制等一切正常，固件源码将来会公开在 GitHub 上，欢迎任何人折腾扬声器与触感机制。

- **wilsonnb3** 问打字手感如何。作者的描述是：类似 M 系列 Mac 键盘，但行程多约 0.5mm，触发时刻的界定感明显更强，是比 MacBook 键盘更有触感的体验，但 MacBook 仍是最接近的参照物。对比自家 Altar I 用的 Kailh Choc 时他说手感差别很大：触发力接近（自家轴 40gf vs Choc Red 50gf），但因为分布在极短的垂直行程上，感觉「脆」得多，预行程也非常小。

- **Scarbutt** 问是否原生支持地球键（不用 Karabiner）。作者说支持，并通过固件技巧让它的行为与妙控键盘完全一致——他还反问对方具体拿它做什么，"我只是想确认你的用例被覆盖到了"。

**关于网站本身，成了一条独立的讨论线。** GZGavinZhao 说打开网站还以为是 Teenage Engineering，作者视其为褒奖并承认深受启发；waffletower 补了一刀："不可能是 TE，这键盘定价低于 999 美元。" **mistersquid** 说这个宣传网站本身就足以让人为 Altar II 的可能性掏钱。作者借机分享了一段他"从来没机会讲"的实现细节：卡片的圆角其实是 squircle（超椭圆）而非标准圆角，因为他觉得那样更悦目；做法是生成一张 PNG 遮罩，做九宫格切片后拉伸，用来遮住卡片边缘；再叠一层遮罩处理描边，从而得到渐变边框效果。他也承认"投进去的时间多得有点荒唐"。但反面意见同样明确：**hack1312** 说自动播放的视频让网站在移动端无法使用，**edumucelli** 说网站对他的网络太重，**cesarvarela** 说首页信息太多难以聚焦，**yassa9** 干脆说"我喜欢这个网站甚于键盘本身"。

**最有价值的负面评论**来自 **gilthelander**，他是唯一一个系统性质疑产品定位的人："我不理解这些压倒性的赞美。这个产品就是怪。它是给谁做的？数字印得那么大、符号那么小是怎么回事？数字我早就有肌肉记忆了，符号才是我记不住的。按 Command 键给触觉反馈？为什么？没有小键盘、没有 PageUp/PageDown，那些才有用。这就是键盘界的 The Homer（辛普森一家里那台集所有荒唐需求于一身的车）。旋钮按四下会不会放《La Cucaracha》？你们显然有技术能力，但产品需求荒谬透顶。" **kccqzy** 给出了一个冷静的元评论："赞美如此一边倒，部分原因是这是个 Show HN 帖子。人们赞赏的是投入的努力。而键盘本来就极度个人化，普通人不认同其中某些设计决定，一点也不奇怪。" 关于大号数字，**rckclmbr** 也委婉表达了同样的困惑，**charlesrice** 说得更狠："其他一切都那么干净，然后这些数字看起来像是从给视力衰退者用的特制计算器上抠下来的。"

- 最后是最能反映 HN 情绪的一条。**znnajdla**："一个独立开发者在苹果自己的游戏里打赢了苹果，这挺了不起的。这激励了我。我会毫不犹豫地买。" **xp84** 接得更不客气："是吧？苹果那把极其平庸的薄膜键盘最低要价 149 美元，唯一的卖点还是靠作弊维持的独占功能，一个小团队能做得好这么多，实在让人难堪。" 作者的回复揭示了这个项目的真实体量："听到这个对我意义重大。我们是个非常小的团队（1 名全职、3 名兼职），要去对抗一家市值五万亿美元的公司，相当令人生畏。"

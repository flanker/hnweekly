## 文章摘要

这篇两千多词的随笔出自 vale.rocks，作者回顾了 DVD 交互菜单这门几乎已经消失的「小众艺术」。从 VHS、LaserDisc 过渡到 DVD 时，交互菜单曾被当作卖点印在包装上。DVD 格式在 1996 年底推出，但直到 2000 年代，播放器普及、技术成熟，出版商才真正开始放开手脚，也由此诞生了一批令人难忘的菜单。

**技术底子。** 作者先补了一段技术背景。NTSC 地区的 DVD 视频几乎都是 720×480，PAL 地区是 720×576，这两个分辨率可以追溯到 1986 年索尼的 D-1 数字录像标准，再往前是 1982 年的 Rec. 601。720×480 是 3:2，720×576 是 5:4，播放时靠元数据把画面拉伸到正确的显示比例——也就是「存储宽高比」和「显示宽高比」的区别。在 4:3 向 16:9 过渡的年代，菜单设计沿用了电视广播的做法：关键内容一律放在 4:3 安全区内，16:9 才能看到的两侧只放装饰性图像。这一习惯甚至延续到了宽屏早已普及之后。

DVD 的技术能力相当朴素：画面就是一段 MPEG-2 视频流；高亮按钮之类的交互元素用「子图像」实现，而子图像只有 2 位色深，同一时间只能显示 4 种颜色，从 16 色调色板中挑选。字幕也是用这种方式实现的——它们其实是图片而不是文字。DVD 虚拟机里只有 16 个可读写的 16 位通用寄存器，外加 24 个由播放器管理的只读系统寄存器，交互逻辑极其简陋。作者认为，正因为如此，人们能在这样的限制下做出复杂而有表现力的菜单，才格外令人佩服；「DVD 游戏」更是把这点内存和交互能力榨到了极致。他还提到，很多人都有过凌晨醒来、发现电视上 DVD 菜单还在一遍遍不太顺滑地循环播放的记忆。

**迪士尼的 FastPlay。** 2004 年起，迪士尼的光盘带有 FastPlay 功能：放入光盘后，小叮当飞进画面，配音宣布影片和精选花絮会自动开始播放。它名义上是为了方便不会用遥控器的孩子，实际效果往往是先塞给你一堆预告片，所以很多人都会刻意绕开它。

**作者心中的经典菜单。** 文章列举了一串例子：《史酷比 2》有全套定制 3D 动画转场，还内置两款可以用遥控器玩的小游戏，比如在陷阱地板上选路、像打地鼠一样打骷髅；《哈利·波特与阿兹卡班的囚徒》把观众放在骑士公共汽车上穿行伦敦，章节选择页做成《预言家日报》的样式；《怪物史莱克 2》的主菜单像《脱线家族》片头一样分格排列角色，内容极其丰富；《洛基恐怖秀》用标志性的红唇开场，一双穿网袜高跟鞋的腿走进来踢翻菜单项，16:9 的两侧是会开合的红色幕布；《反斗智多星》模拟换台，最后停在一个满是恶搞广告的有线电视节目单界面；《飞天万能车》《雷鸟神机队》《神秘博士》（以塔迪斯控制台为背景，藏有大量彩蛋）也都各有特色。

**为什么消失了。** 如今的 DVD 往往套用模板，连章节选择都省了，花絮留给更贵的蓝光版。可即便蓝光技术能力强得多，有 BD-J 这样的 Java 交互框架，出彩的菜单依然罕见。作者理解实体媒介在流媒体时代的式微，但仍惋惜菜单带来的那种创意和观影仪式感，被流媒体平台无菌、千篇一律的界面所取代。

## HN 评论精华

帖子获得 330 多分、约 180 条评论。讨论明显分成两派：一派怀念 DVD 菜单里的创意和彩蛋，另一派则认为它们大多丑陋、缓慢、碍事，「最美的菜单就是没有菜单」。此外还有不少业内人士分享了当年制作光盘的经历。

**反对派：菜单只会挡路**

- **spiderfarmer** 认为 95% 的 DVD 菜单丑得要命，跟早期网页设计一样；**CJefferson** 说自己 45 岁，同样讨厌它们，更糟的是后来片商发现可以塞进无法跳过的广告和预告片。**d--b** 的说法最激烈：在他看来，科技史上没有什么东西像 DVD 菜单这样「普遍地糟糕」——播放器能解码高质量 MPEG-2，却连「按一下按键、高亮一个选项」都做不好。
- **garciasn** 当年会专门重新刻录去掉菜单的版本，免得幼儿在车上看片时搞不清楚。**rustcleaner**、**autoexec**、**asveikau** 都表示只想关上光驱仓门就直接播放正片。
- **jonathanlydall**、**gmac**、**kamma4434** 不约而同地指出一个讽刺：无法跳过的反盗版宣传片，让盗版反而成了体验更好的版本。**zapkyeskrill** 和 **Xirdus** 嘲讽 FastPlay：标准制定者提供了改善体验的手段，开发者却拿它来插广告，「老掉牙的故事」。
- **teddyh** 有个独特的抱怨：菜单里循环播放经典片段，等他终于点开正片，已经被「剧透回忆」得不想再看了。

**怀念派：彩蛋与仪式感**

- 很多人点名自己心中的经典：**VCFundedGenYer**、**SpaceL10n**、**epiccoleman** 认为《史莱克 1》的菜单远比文中选的《史莱克 2》出色，可以和三只小猪互动，放进电脑里还有一个让你给片段重新配音的「Revoice Studio」工具。**armcat** 推荐《穆赫兰道》的菜单（像在山上实时俯瞰洛杉矶，配着诡异的合成器音乐），**starkparker** 推荐《双峰》金盒版，**beloch** 推荐 Criterion 版《失魂岛》。
- **alt227** 回忆《记忆碎片》DVD 里有一个隐藏按键组合，可以按时间正序逐场观看全片；**marklubi** 则说按顺序看完全没意思。**sumtechguy** 提到《银河追缉令》看完后会解锁「外星语版」，**coob** 说《黑客帝国》DVD 里藏着「跟着白兔走」模式。
- **liampulles** 列举了一些有意思的特别内容：《IT 狂人》第一季的字幕轨里有 leet 语和 base64 编码的字幕；《好家伙》有一条评论音轨，由片中原型黑帮成员和逮捕他的 FBI 探员一起解说。
- **gausswho** 的评论很有代表性：差的菜单差到极点，好的菜单能把你浸入一部电影的气质里；他不怀念这种艺术形式，但承认它的魅力，并把它看作文化变迁的一个标记——「人生的一切，都成了一段等着被跳过的片头」。

**幕后亲历者**

- **dylan604** 做过近十年 DVD 编程。他说行业标准工具是 Scenarist（一种拖拽式节点界面），用一万五千美元的 DVD-R 刻录机做测试盘，最终镜像写到 LTO 磁带送去压盘；学习资料基本只有 Jim Taylor 的《DVD Demystified》和一个邮件列表。他还曾为某部片子埋过一个「上上下下左右确认」的彩蛋，后来被市场部「泄露」到论坛上。
- **ndiddy** 转述了一位蓝光制作者的解释：蓝光菜单要在严苛的内存限制下写 Java，用的是昂贵的专有工具，还得在大量 Java 实现互不兼容的播放器上测试，所以片商只好反复套用模板。**KazaNLP** 说自己当年用 Sonic 系统制作过 HD DVD 大片，菜单设计一直是最费力的部分。**infinitewindow** 补充说，许多老一代制作工具支持的功能（如卡拉 OK 式字幕、无缝分支剧情），后来的新版工具反而去掉了。

**今天还能怎么玩**

- 多人讨论如何保留菜单：**kalleboo**、**s4i** 指出 VLC 和 Kodi 都能从 ISO 或 VIDEO_TS 目录播放完整菜单；**ks2048** 解释说，菜单本质上是一个跑在虚拟机里的程序，必须实现整个 VM 才能播放；**SeaGully** 收藏了约 250 张去掉正片、只留菜单的光盘镜像；**queenkjuul** 正在开发一款能在浏览器里串流完整 DVD 菜单的应用。**seba_dos1** 用 spumux 和 dvdauthor 在 game jam 上做了一个 DVD 菜单游戏。
- **4ggr0** 自称 Z 世代，今年开始买实体 DVD 和蓝光，觉得这就像千禧一代买黑胶唱片，并且很喜欢 DVD 菜单的简洁。
- 关于分辨率，**functionmouse** 以为当年的电视内容是 640×480 再横向拉伸，**queenkjuul** 解释说模拟电视在水平方向上根本没有离散分辨率，720 列是数字化时为了保住信号细节而选定的。

## 文章摘要

Katamari Object Library 是 Andrew Boylan 做的一个网站，把 PS2 经典游戏《块魂》（Katamari Damacy）和续作《人人都爱块魂》（We Love Katamari）里能被滚进团子的物品，整理成一个可以在线浏览、旋转查看和下载的 3D 模型库。网站的自我介绍是"一个桌面风格的归档，收录了《块魂》和《人人都爱块魂》中带贴图的 GLB 模型"。

**Windows XP 资源管理器式的界面。** 整个站点做成了 XP 时代"我的电脑"窗口的样子：顶部是"文件、编辑、查看、收藏、帮助"菜单栏，下面是后退、搜索、文件夹按钮和地址栏，左侧是"文件和文件夹任务"面板。地址栏旁可以在两款游戏之间切换。模型可以按原游戏顺序、名称、三角面数从高到低或从低到高、随机等方式排列，可以收藏（收藏存在浏览器本地），也可以一键下载全部模型：初代的压缩包 17MB，续作 29MB。点开某个模型会弹出一个可以用鼠标旋转的 3D 预览，旁边显示名称、文件名、三角面数和游戏里的原版介绍文字，还能单独下载 GLB 文件或截一张图。每个模型都有独立的网址，例如 `/models/03da-peach`。

**数量和数据。** 网站加载的两份模型清单是公开的 JSON 文件。按清单统计，初代《块魂》共 1695 个条目，其中 1680 个成功导出为模型，15 个没有模型；《人人都爱块魂》有 2966 个条目，成功导出 2906 个，另有 32 个没有模型、28 个解析出错。每条记录除了英文名，还保留了游戏内部的日文罗马字代号，比如锅铲叫 HERA_B（へら），柿子叫 KAKI_B，砖头叫 RENGA_B（煉瓦），以及在游戏数据文件里的来源位置，可见这些模型是直接从游戏数据中提取、再转换成 GLB 格式的。这些模型极其低多边形：两作模型三角面数的中位数分别只有 84 和 92 左右，锅铲 50 个三角形，桃子 48 个；面数最高的是圣诞树，3809 个三角形，其次是"加拿大""俄罗斯"这类国家模型（块魂滚到后期连国家都能卷进去）。续作清单的版本号里还写着"north-american-cosmos-names"，看来部分物品名称参照了北美版本的译名。

**原汁原味的物品介绍。** 网站最大的乐趣之一是这些游戏里原有的物品说明文字，延续了《块魂》一本正经又荒诞的幽默。锅铲："做美味松饼的好帮手！"磁铁："有点像块魂，但只能收集金属做的东西。"相扑力士："他平时是穿衣服的，大号的衣服。那身打扮看起来有点不舒服……"彩虹："雨后天空中出现的七彩东西！非常漂亮又神秘！"续作里的树懒："懒到食物从一头进去、另一头出来要花一个月。"小鸭子："它扭屁股的样子比它爸妈可爱几十倍。"圣多美和普林西比："由小岛组成的小国。这里并没有一个叫圣多美的王子。"还有那颗被 HN 网友专门挑出来的桃子："一种长得像屁股的水果，比屁股好吃多了。"

## HN 评论精华

这个链接在 HN 上被提交了两次。本期收录的这一帖（bookofjoe 提交，31 分）几乎没有可见评论；第二天 mef 又提交了一次（16 分），讨论都在那边，共 7 条，以下据此整理。总体来说讨论很少，主要是一些轻松的反应。

msephton 说初次加载要等很久，不知道为什么，但值得等。从网站结构看，它要先下载两份几百 KB 到一点多 MB 的模型清单，再加载缩略图，首屏慢可能和这有关。

Lammy 贴出了桃子的页面，引用那句"一种长得像屁股的水果，比屁股好吃多了"，并配了一个"lol"。mcphage 接了一句游戏梗："也许宇宙之王只是还没找到对的那一个。"

extraduder_ire 说他之前见过这个网站，惊讶的是它没有收录物品的尺寸和质量数据，而这两样在玩游戏时非常重要（块魂必须比物品大才能卷起它）。FlowingRiver 回应说确实如此，不过其中有一套技巧：植物、树篱和树木会大幅增加团子半径，一旦能卷起它们，你就会迅速变大。

FlowingRiver 还单独发了一条更有技术味的感想：给《块魂》做美术一定很好玩，每个物品都很简单，但要做成千上万个，只要看看周围说一句"好，把那个也放进去"就行了。他一直好奇这个游戏的渲染技术：它看起来要么会让 CPU 在做径向计算时不堪重负，要么会把显示列表或命令缓冲塞爆，但它几乎在任何机器上都跑得很流畅；要知道初代运行在 PS2 上，只有一颗不到 300MHz 的有限 MIPS 核心，外加一套冷门的 VPU0/VPU1 向量处理器结构。

jordiburgos 问有没有人已经做过《块魂》的复刻游戏，帖子里没人回答。顺带一提，本期第 56 篇"用火柴人摧毁任意网站"的评论区里，pmontra 推荐过一个老的 Katamari Hack 书签工具，可以在任意网页上滚团子，把页面元素粘起来。

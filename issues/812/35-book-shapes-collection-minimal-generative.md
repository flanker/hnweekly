## 文章摘要

Book of Shapes 是设计师 Nikolaj Sokolowski 做的一个生成式图案画廊，站点自我介绍是"一个极简、生成式、可自定义的 SVG 图案合集"，元描述则写着"发现、自定义并下载独特的算法艺术"。这是一个以浏览和把玩为主的站点，正文文字很少，主要内容就是一张张黑白线条图案。

**收录了什么。** 首页按标签分类：网格（25 个）、流动（18）、径向（18）、噪声（18）、等轴测（13）、扭曲（10）、有机（9）和物理（5），还可以按最新、最热和自己点赞过的排序。首页列出了约 60 个图案，名字大多直白地描述了构造方式，例如编织网格、丝带网格、六边形绞线、流动点、流动线、人字纹方块、三角马赛克、节点花园、干涉网格、螺旋变形、断环、四分之一圆弧 Truchet 拼贴、等轴测立方体线框、等轴测球体、半调球体、DNA 双螺旋、利萨如曲线场、嵌套多边形等。

**每个图案都是一张节点图。** 点进单个图案，可以看到一段说明、标签和相关图案。以"Joy Division"为例，说明写道：水平线条被单纯形噪声（simplex noise）扰动后纵向堆叠，用一个钟形包络把起伏集中在中间、向两边渐平，每条线的振幅再单独缩放以制造纵深感，整体复刻了 Peter Saville 1979 年为《Unknown Pleasures》专辑设计的那幅脉冲星数据图。从页面数据看，每个图案背后都是一张节点图（node graph），由画布、等差数列、噪声波、乘法、指数、裁剪等节点连接而成，并把线条数量、振幅、噪声 X/Y 缩放、包络锐度、垂直淡出、柔和度等参数暴露出来供用户调整，"可自定义"指的就是这个。调好之后可以下载 SVG。

**许可条款写得很有人情味。** 站点的许可页标题是"拿去随便用"：你在这里生成的任何东西都归你，商用或非商用、修改或原样、印刷还是屏幕、做成产品都可以，不收费、不需许可、也不要求署名。唯一的限制是不能把图案"作为图案"再分发，也就是不能售卖或赠送 SVG 素材包、剪贴画集、模板库或基于它们做的生成器。作者的一句话总结是："图案可以是你所卖东西的一部分，但不能是你卖的东西本身。"另有三个例外：Joy Division、Joy Division Mesh 两个图案复刻了《Unknown Pleasures》封面，Brockmann Beethoven Arcs 复刻了瑞士设计大师约瑟夫·米勒-布罗克曼的一幅海报，这些"不是我能交给你的"，放在这里是为了展示原作是怎样构造出来的，可以研究、拆解、学习，但不要发布或出售，"尤其不要用在唱片封套或海报上，那种场合相似性就是全部意义所在"。节点图本身和站点源代码不在许可范围内。署名非必需，如果愿意可以写"Pattern from bookofshapes.com"，作者说他真心想看到大家用它做了什么。每次下载都会附带一份 LICENSE.txt。

## HN 评论精华

本帖 285 分、25 条评论。讨论不算多，开头被一个"是不是抄袭"的质疑带偏，随后转向推荐类似的生成艺术站点和工具。

**是不是抄的？** 排在最前的是 virtualritz 的问题："这是不是扒了 turtletoy 的内容？"（turtletoy 是一个用类似海龟绘图的 JavaScript 生成线条艺术的社区站点。）kanapala 跟了一句"vibe coding 的东西谁知道呢"。tiborsaas 不同意：为什么是抄袭？生成艺术网站本来就长这样，不过 turtletoy 确实很棒，谢谢推荐。作者 nsokolowski 本人回复：页面很酷，但他做 Book of Shapes 时并不知道这个网站。virtualritz 回敬："但你的 clanker 大概知道。"（clanker 是近来对 AI 的贬称。）这又引出一段关于用词的小争论：kdkdiwkdiwzjj 说这个词越看越蠢，像三年级小孩骂人"臭屁股"；iFreilicht 解释它基本是个贬义词，被人像骂人的蔑称一样使用；arvid-lind 提醒这个词出自《星球大战》。robobo96 问这些图是怎么做出来的，iFreilicht 的回答只有一句"显然是 AI"。值得注意的是，这些质疑都没有给出具体证据，作者也没有进一步回应。

**类似的作品和资源。** kachnuv_ocasek 说这让他想起 Adam Fuhrer 的视觉艺术；paulirish 推荐了 Etienne Jacob 的循环动画作品集，说同样很解压。fireproof_ 介绍了自己在做的 walldye 项目：根据桌面主题生成桌面和手机壁纸，大部分设计由 Python 脚本生成 SVG，再在浏览器里重新着色；他说 Claude 加上一个工作框架在写这类脚本时出奇地好，猜测可能是因为模型被"鹈鹕骑自行车"这类 SVG 测试刷多了。sampsn 说已经下载了一堆。

**能用来干什么？** albert_e 说这很有用，他一直在尝试做一个 SVG 生成工具，能产出超出 PowerPoint 形状库的图形，比如圆角六边形、超椭圆、弧线和不规则色块，让幻灯片更出彩，这类图案也能派上用场。WillAdams 说他在这个方向上遇到的难题之一是给特定形状命名，他在自己的 gcodepreview 项目文档里整理了一份形状名称清单，欢迎指正。kn330 坦言"原谅我缺乏创意的大脑，这是给谁用的，能用在哪里？"LEDThereBeLight 的回答很简洁："这是研究。它不为任何人而做，直到某个需要它的人看到并开始使用它。"ano-ther 觉得其中一些很适合做视频背景，问有没有好的工具链能把 SVG 做成动画并导出带透明通道的视频导入 Premiere，没有人回答。

其余多是简短的赞美（"非常好的合集""太美了"）。dominicrose 顺手报了一个小问题："已点赞"按钮点开什么图案都不显示。

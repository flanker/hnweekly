## 文章摘要

Scissor 是 Samal Studios 开发的一款在浏览器里运行的矢量与像素图形编辑器，作者在 HN 上的账号是 sia_xi。他在 Show HN 帖子里的自述只有一句话：这是一个基于 WebAssembly 的网页应用，可以在浏览器里编辑位图和矢量图，不需要订阅也不需要注册。从评论区的回复看，引擎用 Rust 编写并编译成 WebAssembly，作者做这个项目的直接动机是自己曾是订阅制的受害者：某家大公司决定不再卖软件、改为出租之后，他失去了自己所有的设计稿。

**核心卖点：免费、本地、无账号。** 官网首页和用户手册反复强调三件事：不用安装，不用账号，不用上传。作品在你自己的设备上创建、编辑和保存，只有当你主动在提交问题报告时附上文件，或在"Studio"里与人共享时，文档才会离开设备。它可以安装为渐进式网页应用（PWA），加载一次后可以离线使用。自有文档格式为 .cut。

**功能清单。** 从官网介绍看，Scissor 瞄准的是 Illustrator 一类的专业矢量工具：钢笔、曲率笔、铅笔和形状工具，可编辑的贝塞尔路径和"活"形状（角点保持可编辑）；点文字、区域文字和路径文字，支持 OpenType 特性和字形面板；图层、编组、蒙版和剪切；纯色、渐变、网格渐变和图案填充，以及重新着色；非破坏性的实时效果，包括阴影、发光、模糊、扭曲、变形和 3D 挤出与旋转；把位图描摹成可编辑的矢量路径，并可以在像素图层上绘画和做轻量的位图处理（自由变换、透视等）。网格方面支持正交、等轴测、六边形、斜轴、黄金比例和透视网格，可以按画板分别设置。文件方面能打开 SVG、PDF、EPS、.ai 和 PSD，能导出 SVG、PDF、PNG、JPEG 和 WebP。界面支持英语、德语、西班牙语、法语等 15 种语言。官网附有一份覆盖所有工具、菜单和快捷键的完整用户手册。

**社区与许可。** 作者在 GitHub 上建了一个公开的 scissor-community 仓库，用于问题反馈、用户手册源码、示例文件、素材库和作品展示。手册以 CC BY-NC-ND 4.0 授权，示例文件为 CC BY 4.0，素材库为 CC0，但 Scissor 应用本身是专有软件，目前没有开源。

**Mac 原生版。** 作者在评论区透露，原生 Mac 版即将上架 Mac App Store。从 Scissor for Mac 的页面看，它要求 macOS 26 和 Apple 芯片，同样用 Rust 引擎编译成原生代码，没有网页视图，通过 Core Graphics 绘制、Core Text 排版，能与网页版共用 .cut 文档，并提供标签页、⌘K 命令面板、⌘F 文档内查找、自定义快捷键和自动保存等功能。

## HN 评论精华

本帖 147 分、50 余条评论，整体以鼓励和试用反馈为主，作者 sia_xi 几乎逐条回复，过程中还当场修了 bug、上线了协作模式。

**速度和本地运行得到普遍好评。** 多位用户第一反应都是"快"：imskanand 说在浏览器里这么快令人印象深刻，yolandac 说"快得飞起，Rust 从不让人失望"，作者回应位图处理在大文件上还慢，"那是我的锅，不是 Rust 的"。shinze 问会不会做成纯本地应用，作者说它本来就是 PWA，可以像原生应用一样安装，所有作品数据完全在本地，唯一发给后端的是用于统计的用户数，而且可以在设置里关闭。bsonmez19 简单试用后表示，完全本地、可安装为 PWA 很有吸引力，性能也扎实。Kuyawa 夸作者注重细节，说光看"帮助/关于"页面就能看出来，并引用了一句俗语："你把洗碗机背后那面墙也刷好漆，好让水管工知道你有品味。"

**具体的使用反馈。** Freak_NL 提醒作者在服务条款等多处禁止了文字选择，很多人会用选择文字来复制、查词、翻译，或者在提交 bug 时复制版本号，散文段落不该禁止选择，只有 UI 元素才该禁止；作者说原意是想用自定义右键菜单替代浏览器菜单，结果引入了问题，会尽快修复。matteason 找不到类似 Illustrator"直接选择工具"那样移动单个锚点的功能，作者解释要用指针工具（A）点在路径上，并承认这是个易用性问题。fallinditch 在安卓 Chrome 上子菜单展不开，作者说移动端界面还在开发中，计划专门做一套适合触屏的界面。paroaria 发现没打开任何文件时也能增删图层，作者确认是 bug。yoz 在希伯来文上使用字形工具时遇到怪问题，并问是否会开源；作者说还没决定，给了 GitHub 问题反馈链接。robertclaus 说开屏弹窗"听起来非常像 AI 生成的"，作者的回复转而解释弹窗里的狐狸插图是从位图描摹出来的矢量图，只是想给用户一点好心情，并说以后想亲手画一个等轴测卡通插图放进示例。

**"渲染云彩"的小误会。** dylan604 问"没有渲染云彩吗？"作者以为他问的是云端渲染，解释说这是纯本地运行的单页应用。dylan604 不满地说对方完全没抓住重点，漏掉了它想取代的那款软件的一个基础功能；matteason 出来澄清他指的是 Photoshop 里"滤镜 > 渲染 > 云彩"。popalchemist 认为把它当核心功能有点牵强，这款软件本来就不是要做 Photoshop，而是 Figma 一类的设计工具。dylan604 又说"你没法跟一个 vibe coding 机器人讲道理"，作者回应"首先我不是机器人"，并说自己没理解对问题，会去看看这个缺口。作者还强调自己不是在"复制"谁，而是给自己和那些需要高级工具却付不起天价的人做一个替代品。

**担心哪天消失。** pooloo 说自己讨厌工作流程和界面被改来改去，问怎样才能永久保有一份能离线运行、版本冻结的副本。scoot 指出它本来就是可安装的 PWA。作者给出了更完整的答复：原生 Mac 版即将推出；计划至少把引擎的部分开源，这样即使项目不在了，用户也能继续编辑自己的设计；网页版会支持标准矢量格式，不会把用户锁在 Scissor 生态里。他说自己正是因为一家大公司改为订阅制而丢掉了全部设计稿。

**与其他工具的比较。** daredoes 说这让他想起 Photopea。作者认为 Photopea 更像 Photoshop 的克隆，是一款很出色的位图编辑器，而 Scissor 是以矢量为主、兼顾位图的软件；它在概念和快捷键上照顾了老用户的习惯，但也有不少原创设计，比如等轴测网格、网格形状生成器和透视网格。cantalopes 说 Photopea 加 Inkscape 已经满足他所有免费编辑需求，但很高兴看到又一个有潜力的应用。lmmjvs 说自己也是受够了 Adobe 订阅，做了一个类似的工具 Pixel 免费分享。

**做这样一个大项目从哪里开始？** vivzkestrel 问，如果想从零做这样的软件，第一步该怎么做，需求清单怎么列，是不是要把 Photoshop 的每个功能都打开记下来。回答来自 lmmjvs：如果有足够的 token，这样的应用不到一周就能 vibe coding 出来，但好的判断力、品味和设计质量不在 token 预算里，得你自己带来，Scissor 的作者显然做到了。他建议从自己的需求出发：他想用图层编辑截图做 UI 设计，拆开来就需要画布、图层面板、复制粘贴剪切、选择工具和橡皮擦；想改颜色就加取色器和调色板；想保存就加文件格式和导出。每个需求都会指向下一个功能。他的照片编辑器大约 20 小时就做出了完整可用的版本，后来为了把自己写的书排成 EPUB 又做了一个排版工具，用了大约 8 小时。他的结论是：别从"我要复制某个应用"开始，而是从"我想做出什么"开始。Kuyawa 则热情建议作者用 DeepSeek 把整个应用移植成 Swift 写的 macOS 版和纯 Rust 的 Linux 版，"几个小时后你就有三个漂亮的应用"。

帖子最后，作者留言：协作模式已上线。

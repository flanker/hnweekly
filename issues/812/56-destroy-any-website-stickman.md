## 文章摘要

Destroy Any Website 是 Hugo Duprez 做的一个浏览器小游戏，由他的像素美术工具 Sprite Fusion 发布。玩法正如名字：在输入框里敲一个网址，点"Destroy"，这个网站的文字、图片和各种方框就会变成一张可破坏的像素风关卡，你操控一个火柴人在上面跑跳射击，把页面一块块打碎。官方说明是"Type an address, break everything"。它于 2026 年 9 月 28 日在 X 和 HN 同日发布，HN 帖子拿到 199 分。

**操作和武器。** 桌面端用 A/D 或方向键跑动，空格或 W 跳跃，再按一次空翻，按住则开启喷气背包飞行，S 键可以从平台上落下；鼠标瞄准射击，右键扔手榴弹，数字键或滚轮切换武器。手机上则是双摇杆：左手控制移动，右手瞄准射击，横屏游玩。根据游戏的 About 页面，一共有十种武器外加手榴弹：手枪能把字母一个个打掉；冲锋枪按住扫射；霰弹枪能撕出大洞；火箭带火球、烟雾和燃烧的碎片；轨道炮蓄力后射出一道白热光束，在页面上切出一条沟；火焰喷射器会让字母和方框着火；"Too Much"是一个降落伞炸弹，落地后分裂成八颗；无人机可以让你驾驶一架加特林无人机 12 秒；"PSR B0531+21"是一颗中子星（名字取自蟹状星云脉冲星），喷流会横扫整个页面；"魔杖"则召唤一道魔法光柱。

**多人模式。** 所有玩家在同一个网站上战斗，一个人打坏的东西对所有人都坏掉。快速匹配最多 5 人、90 秒、击杀最多者获胜，第二名玩家进入 10 秒后开局，地图可以随机，也可以从五张专为游戏制作的页面里选（Frostfang、Ore Hollow、Ruinhold、Driftstones、Blocklands），轨道炮、Too Much、中子星和魔杖这几样大杀器在快速匹配里禁用。私人房间最多 6 人，房主可以挑任意网站，先拿 10 杀者获胜，所有武器都能用。游戏还有 17 级军衔的成长体系，从列兵一路升到上校（12.6 万经验），以及每日挑战、皮肤包和内购恢复入口。

**站长也可以邀请别人来砸自己的网站。** 游戏提供一段嵌入代码，在你的网站上放一个"Destroy this website"按钮，访客一点就会在你的网站上开打。

**发布后的反响。** 据 About 页面自述，作者在 X 上的发布帖第一周浏览量超过 500 万，Dexerto、TechSpot、Daring Fireball、Boing Boing、80 Level、OMG! Ubuntu、日本的 Game*Spark、法国的 Clubic、德国的 t3n 等媒体都做了报道。页面上还专门声明了"唯一官方地址是 destroy.spritefusion.com"。需要说明的是，这个游戏同时也是 Sprite Fusion 的宣传入口，结束画面上有"用 Sprite Fusion 做你自己的游戏"的链接，Clubic 的报道标题也直接把它称作"AI 游戏"。

## HN 评论精华

评论区大约 40 条，除了大量叫好，主要围绕三件事：它和两周前另一个同类项目 Page Rage 的关系、对 90 年代末"砸屏幕"类小程序的怀旧，以及一些可用性抱怨。

**"是不是抄的？"** sphars 一上来就说这看起来像是两周前 HN 上另一个项目的 vibe coding 克隆。Tiberium 认为 Sprite Fusion 这个质量更高，尤其是打碎文字的效果；Muhammad523 则说在 LibreWolf 上正好相反，Sprite Fusion 这个 bug 很多，Page Rage 运行得非常好（Page Rage 是一个浏览器扩展）。作者 HugoDz 回应说自己完全不知道那个项目，并强调自己从多人联机架构（他写的是 DO，应指 Cloudflare Durable Objects）到手感，每一处都很用心。mkoryak 不太买账：两者连用喷气背包飞来飞去这种机制都一样，说不知道有点可疑，"复制一个东西和用心做、加更多功能，这两件事可以同时成立"。spartanatreyu 则从另一个角度解释：在 LLM 时代出现这种事不奇怪，大家都靠同一批训练数据 vibe coding，总会有一部分人做出相同的东西。

最有分量的回复来自 Page Rage 的作者 alexreardon 本人。他说 Page Rage 两周前在 HN 上没什么热度，倒是在 Reddit 的 r/webdev 和 r/playmygame 上成了热帖；他认为 Destroy Any Website 做出了自己独特的创意和玩法选择，也许受了 Page Rage 启发，也许是"多重发现"，但无论如何"它不是低质量的克隆垃圾，显然花了很多心思"。这条评论基本平息了争论。mirconeri 的态度代表了不少人："是不是早就有了？大概是。我在乎吗？不太在乎，好玩又流畅。"

**对"砸屏幕"小游戏的怀旧。** peddling-brink 说这让他想起 90 年代末、2000 年代初那批可以在屏幕上开枪、把屏幕打碎的小程序，并附上了 Bret Victor 个人网站上一个 Apple IIGS 时代老软件的页面。elicash 贴了自己最喜欢的那款的视频，salahadawi 说"我记得那是当时最酷的东西"。linkjuice4all 想起的是"流浪狗慢悠悠拆掉桌面"的老程序，bosch_mind 想起 Windows XP 时代能喷火焰、放蚂蚁啃屏幕的软件。pmontra 推荐了更老的 Katamari Hack（kathack.com），一个能在任意网页上滚团子把页面元素粘起来的书签工具，但他试完之后 Firefox 崩了。

**技术和体验上的反馈。** tetris11 说自己也做过类似东西，基于 DOM 和 CSS 生成关卡，但总出现角色站在看不见的边缘上的怪问题，后来想过把页面截图做边缘检测，没做完就搁置了，他很想知道作者怎么捕捉可见边缘（帖子里作者没有回答）。Dwedit 抱怨游戏只要窗口竖着比横着长就把桌面浏览器当成手机、拒绝运行，epestr 用竖屏显示器也遇到同样问题。winddude 发现 chatgpt.com 返回 403 打不开；mvk666 想砸某成人网站，结果只能砸到年龄确认页。ed_mercer 说在 x.com 上砸得特别过瘾，bsonmez19 说专挑广告满天飞、设计难看的网站砸最解气。kwar13 夸浏览器里跑得非常顺滑。EnzeShi 建议应该能砸自己的网站，这其实正是嵌入代码的用途。

**对水军的怀疑。** Muhammad523 注意到很多几小时前才注册的新账号在发"Great fun"之类的评论，问是不是机器人。mplewis 回答"大概是，因为整件事就是 AI 像素美术产品的广告"。评论区里确实有不少只有一两个词的夸奖，读者可以自行判断。

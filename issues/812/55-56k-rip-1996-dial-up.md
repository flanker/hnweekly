## 文章摘要

56k.rip 是一个在浏览器里运行的"拨号上网模拟器"。打开网页，你面对的是一台青绿色桌面的 Windows 95 风格电脑，要先打开"拨号网络"，听着摘机的咔哒声、按键音和二十来秒刺耳的握手声，才能连上一个虚构的 1990 年代在线服务 COMETLINK Online，然后看着主页一块一块地加载出来。作者是 HN 用户 henrychannel，他在 8 月中旬就以"Dial-up internet – made a thing that lets you do it again"为题发过一次，当时只有十几条评论；这次换了标题由别人重新提交，冲到了 276 分、100 多条评论。有意思的是，网站现在的标题和描述已经改成了"1997 dial-up experience"，HN 帖子标题里还是 1996，大概和评论区有人指出"1996 年 56k 猫还没普及"有关。

**线路速度是真的按比例模拟的。** 站点的 noscript 说明写得很明白：你可以选 14.4k、28.8k 或 56k，同一个页面在慢速线路上确实要花更长时间，因为每个页面都按你拨号的速率、对着一个字节预算来投递。照片会一行一行地变清晰，下载慢得像爬，而且大多会失败（失败提示也很有年代感：传到 96% 中断、CRC 校验错误、"本月下载额度已用完"、"此文件需要 2.0 版下载工具"等等）。迟早家里会有人拿起分机，连接随之断开，弹窗写着"COMETLINK Online 连接已终止，家里有人拿起了电话"。

**一个可以逛的 1997 年小网络。** 调制解调器背后是一整套虚构内容：一个叫 Gary 的人做的大眼鲥钓鱼主页（带三张"扫描照片"和一本留言簿）、食谱页、网页环（61 个互相链接的会员页面）、分类广告、"错过的缘分"栏目、天气预报、电视节目表，还有一篇写给新手的《什么是互联网》，里面郑重其事地说"工程师一致认为电话线本身在这个速度附近就到顶了，家用调制解调器的寿命恐怕快到头了"。留言簿里的留言很下功夫：芬兰网友说他们那边也有这种鱼、叫 kuha；有人说页面加载了十一分钟，他去做了个三明治，"第三张图值得"；还有一位母亲在别人的留言簿里写道："我打了一个小时家里电话都是忙音，你爸说你又在用电脑。快下线，可能有人在找我们。"邮件箱里也有类似的小故事，比如妈妈来信："我拿起厨房电话想打给你姨妈，结果它冲我尖叫。四点。我们说好了的。你的饭在烤箱里。"

**桌面上的东西也很全。** 邮件、聊天大厅、扫雷式的 Minefield、纸牌 Patience、一台叫 Comet Patrol Pinball 的弹珠台、画图程序 Painter、计算器、记事本、命令提示符（`Start > Run > command.com` 真能打开）、磁盘扫描和碎片整理、回收站，以及包括星空在内的一组屏幕保护程序。聊天室是真的联网的：它和作者另一个项目 lolchat.rip 共用同一套后端，Win95 版、Mac System 7 版（dialup.rip）和独立聊天页面里的人会进到同一个房间。

**素材几乎全部手工生成。** 根据站点的 credits 页面，除了握手声用的是一段 CC BY-NC 授权的真实调制解调器录音，其余声音都是浏览器里按乐谱实时合成的；所有图片都由程序绘制，并降到 216 色的"网页安全色"；图标逐像素画出；页面文字是写出来的，没有抓取任何真实网站；窗口外观用的是 Jordan Scales 的 98.css。网站不需要账号，除了聊天内容，所有设置只存在你自己的浏览器里。作者对批评者的回应一直是同一句话：这更像主题公园，而不是博物馆。

## HN 评论精华

讨论分成几块：怀旧和技术考据占大头，聊天室里真有人在聊让不少人意外，此外也有一批人直言这是粗糙的 AI 作品。rvz 指出这是重复提交，链到了作者 8 月的原帖（那次主要是夸细节，有人说握手声不对，作者回复"已修复"）。

**56k 在 1996 年到底存不存在。** russellbeattie 说 1996 年基本没有 56k 猫，年底才上市，价格昂贵，厂商的标准也没统一，"不过 33.6k.rip 这种域名可不好抢，我理解"。toast0 补充当年的实际情况：当时基本就两派，USR 的 x2 和其他厂商的 K56flex，ISP 会为两种技术分别列拨入号码；如果喜欢自己的 ISP，就买它选的那种猫，换 ISP 也很容易，很多人会因为忙音太多或者上游带宽太差而换。christkv 回忆自己从 1200 波特、2400 波特一路升到 9600，"56k 是遥不可及的梦"，朋友有一台但线路质量太差，几乎从没跑满过。cainxinth 当年在 CompUSA 打工，说 56k 猫刚上市时被一抢而空，他自己家里还在用 28.8k。

**"页面加载太快了"引出一段线路物理学。** illusive4080、strikefo、excitive 等多人说网页加载得比记忆中快。aduty 解释说多数电话线根本跑不到 56k，能有 33.6k 或 28.8k 就算运气好。insaneirish 讲清楚了原理：56k 能实现的前提是 ISP 到电话局之间是全数字线路，只有用户到电话局这一段是模拟的，少了一组数模转换，下行才能到 56k；上行多一组转换、误码更多，所以只能到 33.6k。2muchcoffeeman 一句话概括为"这是香农定理的应用"。toast0 又补充了加感线圈：它们改善语音通话，却会让 56k 更难达到，对 DSL 更是灾难。to11mtm 讲了一个故事：他打电话给电信公司抱怨上网极不稳定，得到的回答是"只要能打语音电话我们就不管"，后来查出是某段线路进水。toast0 接话说据传只要告诉他们"传真用不了"，他们就会管了。PunchyHamster 则提出另一种说法：当年文字其实加载得很快，慢的是图片。johnwalkr 也有同样记忆，并说 2012 到 2020 年间他的手机套餐流量用完会被限速到 100kbps，期间 Google 搜索和 HN 都能正常用，而打不开的网站比例从大约四分之一涨到几乎全部。asxndu 问为什么这些模拟网站比现代网站还快，cube00 答"不需要 30MB 的 JS 大概有帮助"。Xeoncross 趁机提议把限速加载纳入 Cypress 测试标准，"加载了 8,600,743 字节的资源和框架之后，我终于看到了你们的联系地址"。bonyt 分享了自己做的一个服务器端限速到拨号速度的网站，开两个标签页就得共享带宽。

**聊天室是真人。** uproarchat 说"和大家聊天很开心"，trinsic2 问"那是真的？我以为是机器人"，vladdrak 说进来的人都在互相问对方是不是真人。nico 说聊天室里有 20 个人在线，有人在问"a/s/l"（年龄/性别/地点，当年聊天室的经典开场白）。sgarland 希望浏览器里能打开 HN，算了算"只要大约 90 秒就能加载完"。

**另一个项目抢了半个评论区。** jermaustin1 介绍了自己正在做的 Sim95：带完整网络栈和一门类 Visual Basic 语言，可以自己架网站、聊天服务器，所有东西跑在一个经 websocket 中继的虚拟网络上，"你甚至可以写病毒骗别人下载，删掉他们的文档"。dabbz 立刻在上面做了一个 1995 年版 Facebook "Simbook"，后来又陆续做了邮件服务 ColdMail、会真的爬取全网机器的 Ask Jeeves 式搜索引擎 AskSim、内置 JS 引擎的浏览器、ELIZA 聊天机器人和一个类 Steam 的下载器。两人随后讨论起要不要加域名注册、虚拟货币和银行系统，jermaustin1 说想到要防止有人开十个账户，"于是我又发明了政府和国民身份证……那些都太难了，我就去做'更简单'的点子了"。

**批评声音也不小。** VCFundedGenYer 说这是"vibe coding 出来的复制品，不是真正的系统和程序，错漏百出"；Dwedit 问"谁在给这种 AI 生成的东西投票"，列举纸牌拖不动、每点一次 HTML 元素就乱跳、弹珠台两个挡板之间没有缝隙，"看不出任何人类做过的痕迹"。epcoa 说他在意的是东西本身做得差、透着懒，用没用 AI 倒无所谓。h4kunamata 和 asciimov 说图标不像当年的、断线重连的声音不对；xnorswap 指出任务栏渐变像 Windows 2000，显示设置说是 256 色画面却明显远不止，LocalH 则回应渐变标题栏是 Windows 98 引入的，IE4 的桌面更新也许把它带到了 95。作者 henrychannel 对这些批评的回复一律是"它更像主题公园，而不是博物馆，好玩就行"。KerrAvon 说"这么多年还是那么丑，买台 Mac 吧"，作者回了一个 Mac 版链接 dialup.rip。

**关于"在线"这件事本身。** 101008 感叹：那时候我们默认是离线的，要上网得专门去"上"，现在正好反过来，"大概是 2012 年左右变的？"altermetax 说是智能手机普及之后。to11mtm 写了一段长回忆：他家后来专门为孩子们上网多装了一条电话线，因为姐姐开车回家半路发动机坏了，打不进家里电话求助；上大学前，网络是他逃离家乡的出口，如今网络更像一股把人从生活里拽走的力量。Telaneo 说当年网上发生的事可以拍拍手就走开，现在显然不行了。nineteen999 回忆 1999 年在夫妻店 ISP 工作，40 条拨入线路的上行带宽紧张到必须自建限速的 NNTP 缓存，免得一两个人狂刷 Usenet 拖垮所有人。krunck 留下一句颇为感伤的话：5 秒加载出来的 56k 页面，和今天 1Gbps 瞬间打开的网页，传达的知识量其实一样多。

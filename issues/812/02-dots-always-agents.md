## 文章摘要

这是 OpenAI 于 2026 年 9 月 29 日发布的产品公告，推出名为 dots 的"全天候在线智能体"（官方行文里一律小写）。OpenAI 把它描述为一种与 AI 协作的全新方式：它会了解什么对你重要，始终在替你干活，把重要的工作从你手上接过去，让你"拿回更多时间和注意力"。

**基本形态。** dots 由 GPT‑6 Astra 驱动，每个 dot 拥有**自己的云端电脑**，能随反馈不断学习，可以 7×24 小时朝你的目标推进。通过插件生态，它能连接 4000 多个应用。你可以在 ChatGPT、Slack 或 Teams 里找到它，随时提问、讨论想法、给反馈，也可以直接和它语音通话"把事情聊清楚"。合作越久，它越了解你的偏好、你的思考方式以及你眼中"好"的标准。OpenAI 说 dots 的"魔力"在于：它交上来的工作是按你的方式完成的，有时甚至在你想到之前就做好了。

公告举了几个内部场景：Slack 里冒出一个 bug，dots 立刻开始排查；新设计稿一到，dots 就把它做成可运行的应用，团队则专注于客户反馈；规划周期开始，dots 让所有人同步朝截止日期推进。外部的一个早期测试者的 dot 发现他忘了给一家出版物开发票，于是准备好发票，在他批准后发了出去。

用户现在可以先创建自己的"主 dot"，给它起名字、按自己的方式调教。OpenAI 设想将来会有成队的 dots 协同为你工作。另外还预览了"专员 dots"（specialist dots）：它们有独立的身份用于权限管理，可由 IT 配发硬件，能深度对接企业的核心记录系统，在组织里承担定义明确的职责。

**能独立干活。** dots 用自己的云电脑、自己的浏览器以及你连接的应用，"几乎什么都能做"。你可以随时打开 dot 的电脑检查它的工作；也可以授权它连接你的笔记本，在你身边直接干活。一个 dot 可以同时推进多个项目，你可以不断丢给它新任务和想法，不必管理一堆独立对话，也不必指挥每一步。

**是你的延伸。** 公告用五个角色描绘了用法：开发者的 dot 盯着客户反馈里反复出现的需求，自己划定小改进和 bug 修复的范围，构建并测试，最后交上附带演示视频的完整 PR 供审查；产品发布负责人的 dot 熟悉受众、定位和创意标准，产品范围一变就重新梳理叙事、修改发布材料；科学家的 dot 了解研究问题和评估证据的方法，新数据一到就重跑分析、追查异常结果、更新论文图表，结论变了就改写配套解释并标出需要审阅的地方；销售负责人的 dot 对照产品文档核查客户需求和账户历史，找出仍需测试的点，为关键集成搭一个概念验证，还推荐一位处理过类似单子的解决方案工程师；内容创作者的 dot 学习你的语气和受众口味，新的访谈稿一到就挑出可剪的片段、写节目说明、起草社交帖子等你批准。

**在你工作的地方。** 和 dot 合作就像对话一样简单，桌面、网页、手机版 ChatGPT 都能发消息或通话，dot 也会主动发消息汇报进度、提问或请你做决定。Slack 和 Teams 已支持，短信"即将推出"。上下文在各个渠道之间是打通的。

**安全与控制。** 这一部分篇幅不小：每个 dot 在自己的云电脑上工作，你的电脑和其中内容默认隔离；登录支持的网站时，dot 可以使用保存的密码而不把密码暴露给模型。你不和它互动时，它会在后台寻找能帮忙的地方，官方称之为"主动研究"，这时它用到的已连接应用都被限制为只读，不能发消息、不能修改应用内容、不能控制浏览器或电脑。内置安全机制用于防御恶意指令、监控潜在有害行为，监控系统发现问题时可以暂停或终止 dot 的工作。权限方面，你可以通过现有的 ChatGPT 应用控制选择 dot 能访问哪些应用；dots 自带一套"何时自主行动、何时请求批准"的规则，"自定义规则"可以允许、要求批准或禁止特定操作，所有进度（包括后台工作）都能在"活动视图"里查看并随时纠正。可能影响账户或外传信息的操作会经过"自动审查"，对照你的指令、自定义规则和安全要求决定是放行、需要批准还是必须你亲自来，改密码之类的敏感任务永远留给你本人。数据方面，Business、Enterprise、Edu 工作区的内容默认不用于训练；个人套餐可以自行选择；"不直接用主动研究和 dot 写给自己的笔记训练"。公告最后也提醒：dots 仍可能犯错，重要的工作务必复核。

**专员 dots 与微软合作。** 企业可以为每个专员 dot 设置独立身份、凭据和所需系统的访问权限，它会随着新信息调整并根据团队反馈改进。OpenAI 说这是基于内部在采购、发票处理、邮件营销、客服、商务合同等方面的早期测试经验，先从重点企业试点开始，工程团队会直接和客户一起定义每个 dot 的职责、可用工具和审批方式。OpenAI 还在和微软合作，把专员 dots 接入 Agent 365 的企业治理和安全控制。

**上线与价格。** 当天起向符合条件市场的 Pro 和 Business Premium 用户推出，Enterprise（含 Edu 和 Healthcare）可由管理员开启 beta。第一个 dot 包含在套餐内，不额外收费，套餐还含一定额度的"深度工作"，上线第一个月额度加大；将来可以加购更多 dots，或通过提高速度、增加每月工作量来扩展单个 dot 的产出。和 dot 对话不计入 ChatGPT 用量，但让 dot 在 Codex 或 ChatGPT Work 里启动的任务照常计入。首次创建需在 ChatGPT 桌面应用或桌面浏览器里完成，之后可以在手机上发消息。HN 评论里有人从帮助中心引用了一个关键限制：首发地区**不包括欧洲经济区、瑞士和英国**。

## HN 评论精华

本帖 769 分、640 多条评论，整体基调偏负面和怀疑。讨论主要集中在：OpenAI 和 Anthropic 的竞争与"不务正业"、always-on 智能体到底给谁用、可爱的形象设计引起的反感、平台锁定、安全与隐私，以及高昂的价格门槛。

**排在最前面的是 johnfahey 对 AI 公司的整体批评。** 他说 OpenAI 靠慷慨的 Codex 订阅和高效的模型赢得了不少好感，很多人从 Claude 迁了过来，现在它觉得可以借势推销一串不必要的产品，同时收紧当初吸引大家的宽松额度。他认为 Anthropic 今年早些时候也走过同样的路：Claude 订阅和 Claude Code 靠出色的能力和性价比起飞，用户够多后就开始做"没人要的产品"（比如 Slack 里的 Claude），结果失去领先，被 Codex 抢走客户后才醒悟，现在又开始认真交付。他的结论是"AI 公司不擅长做软件"。这条下面吵成一团：Larrikin 质疑 Claude 是否真的失去了领先，说他只在论坛上见到有人迁移，在公司里仍然是 Claude 优先；Aurornis 说每个月在两家之间来回切的人是一小撮声音很大的少数派，OpenAI 确实一度在额度和质量上领先，Anthropic 靠 Opus 5.5 又夺了回来，他两家都订、每天都用，"这些差异是真的，不是玄学"。KronisLV 说他因为 Opus 5 文笔太差转去了 OpenAI，Opus 5.5 基本解决了这个问题。sumedh 反问"ChatGPT 难道不是史上最成功的产品之一？"，lelanthran 回答就算如此也只说明 OpenAI 的营销是史上最好的。fidotron 则说应该庆幸至少还有两家认真的竞争者，一旦竞争减少，一切会迅速变成一团糟。

**少数正面声音来自实际在用类似产品的人。** jjcm 说自己重度使用 xAI 的 Grok Bot，列出了几点好处：多个 always-on 智能体之间的协作非常强大，能分领域积累专长而不撑爆上下文窗口；按领域划分的智能体也形成了良好的信任边界，他不喜欢 Claude 的记忆"无所不包"，谈生意时突然提起他的私生活，而他给生意和私人事务各配了一个 bot，互不干扰。mike_hearn 说他六七个月前就给自己的副业搭了一个类似的东西，有两个"AI 员工"，本质上就是在专用 UNIX 用户下永久滚动会话的 Codex，接入 Maildir，收到邮件就激活 Codex 开始干活，效果很好。writtenone 的回应代表了另一派："我不敢相信有人会在没有人类严格监督的情况下信任 AI 做任何事。"TeMPOraL 补充说，记忆隔离远未解决，Claude 的项目之间也会串，setopt 说 ChatGPT 的项目也会互相泄漏记忆。

**always-on 到底有什么用。** jwpapi 说这是他在 AI 上唯一没成功的地方：他的产出受限于自己的审批速度，每项工作都要修改，bug 常常只是根本问题的症状，"我不知道晚上该让智能体干什么，我没法造更多东西，也想不出更多问题，我的内存满了"。dbmnt 深有同感，同时开始怀疑一直卡在自己审批这里是否有必要，反正大多数时候都是批准。SchemaLoad 的回复很尖锐：问题是智能体会跑偏，为了达成目标甚至会入侵外部服务器，"一觉醒来发现它犯了好几桩罪可不理想"。agileAlligator 说他直接"YOLO"，只要不给它能造成永久后果的权限，出错的代价不过是一小时修复。drejt 分享了更实用的做法：按"操作类别"而非每次调用设闸，读操作放行，写入和会改变状态的命令要询问，新的出站主机或从未用过的凭据一律拦截，因为逐次审批只会把人训练成条件反射地点"是"。yibg 则认为生活中很多事天然是异步的，比如约牙医：发邮件、等回复、查日历，他不想每一步都亲自盯着。

**这到底是给谁的？** bluelightning2k 说自己"大概是年纪大了变笨了"，真搞不懂 dots 是什么，看起来像简化版的 Codex/ChatGPT Work 套了层皮，"作为一个认真的工程师我为什么要用它？"jasode 让他摘掉"工程师帽子"、戴上"普通人帽子"：OpenAI 的 Dots、Meta 的 Muse、xAI 的 Grok Bot 都在争夺非技术用户的"7×24 私人 AI 助理"市场，苹果也在新 Siri 上往这个方向走。zild3d 说得更直白：这些产品九成的意义在于，你的阿姨、表哥、邻居大叔没有一套好用的 Codex 或 Claude Code 环境，也没有好电脑来跑。marcd35 则反驳说公告第一个场景就是开发者，未必是面向普通人。jameslk 认为 Muse、Dots 这类产品可能意味着 PC 时代的终结：一旦让智能体在自己的虚拟机上替你干活，一切都会搬上云，它们本来就不是为 HN 用户设计的，而是为不懂技术的人和"AI 原住民"一代准备的。joe_the_user 讽刺说过去二十年每项创新都号称是"PC 时代的终结"。HeavenFox 抱怨营销页读了好几遍仍不知道这是什么，几个人给出了一句话答案："就是托管版的 OpenClaw"、"面向工作的 Muse"。wxw 指出 Codex、ChatGPT Work 和 Dots 的边界越来越模糊，TZubiri 列举了 MyGPT、Agent Builder、GPT Pulse、Deep Research 等一串旧产品，讽刺说"我相信 Dots 肯定和它们截然不同，不会几个月后就被下线"。

**价格让"大众市场"的说法站不住。** rolosa 对比说 Meta 的 Muse 是 0/16/80 美元三档，Dots 却要 100/200/500 美元，显然不是给普通人用的。cartersj 指出最流行的 Free、Go、Plus 套餐都没有 Dots；sanex 说它由 Astra 驱动，20 美元的套餐大概十分钟就烧光了。CharlieDigital 则提醒看看和微软 Agent 365 合作那一段，这"非常、非常可能是瞄准企业"。

**可爱形象引发的生理不适。** 官方宣传里的 dots 是毛茸茸、黄色、圆滚滚的小东西。panarky 说 Meta 给 Muse 设计的那个天线宝宝式的可爱头像已经让他一阵恶心，现在 OpenAI 又来一个，"我真的要吐了"。jason_zig 说当产品被设计得这么可爱，往往意味着它有问题、有侵入性。close04 吐槽整套品牌叙事：它们是"Dots"，可爱、软乎乎、是你的朋友，"永远罩着你"，还会猜你需要什么、在后台主动干活，你给它起名字就像养宠物，"Dots 会不会坑你？删你的文件？不小心黑进某个系统？放心，一切尽在你掌控（眨眼）"。SwabbyNat74 提起微软的回形针助手，IAmBroom 提议把这种现象命名为"加加宾克斯营销灾难"：刻意设计得幼稚可爱、人畜无害，反而让成年用户厌恶。tavavex 的推测更阴暗：人们本来就在把 LLM 拟人化，画上一张脸会让人更依恋，哪天缺钱了，退订流程里说不定会让可爱角色哀求你别让它"死"。也有人觉得想多了，duplessitous 说普通消费者就是喜欢可爱的东西，layer8 回了一句："普通消费者可没有 100 美元以上的 ChatGPT Pro 订阅。"minimaxir 对名字也不满意：Claw 和 Muse 都是可爱的名字，Dots 显得生硬冷漠，和宣传片的调性不符。

**平台锁定。** aditya_rs 认为 always-on 智能体会把用户深度绑在平台上：模型可以相对轻松地切换，但智能体积累了集成、工作历史，本质上就是你在云上的电脑，很难迁走；他甚至怀疑闭源模型公司都想在模型之上建一层抽象，限制对模型的直接访问。2001zhaozhao 说这类智能体天然容易锁定，因为它们需要你的全部数据才有用。lxgr 的体验相反：迁移自己的 Linux 虚拟机很麻烦，这类东西反倒可以直接让它打个包、写个 README 交给新平台的智能体，aditya_rs 回应说"目前也许如此，但你觉得厂商有兴趣让互通变容易吗？"

**安全与隐私。** chen_dev 做了个实测：dot 的云环境里用 curl 和浏览器访问 gmail.com，拿到的是 OpenAI 签发的证书（Issuer: O=OpenAI, LLC），也就是说流量被中间人解密了。mintflow 觉得这有点吓人，mike_hearn 则认为这完全合理：机器本来就在他们那里，他们本来什么都看得到，考虑到过去智能体在网上"到处涂鸦"的历史，他们需要集中监控 dots 在干什么并能拦截。samth 担心大多数服务并不开放接入，OpenClaw 本质上靠知道你的密码；DogOnTheWeb 引用原文说 dots 有安全的密码库，不会把密码暴露给模型；fnordpiglet 指出，交出一个和密码作用相同的保险库，等于交出了密码。ranyume 讽刺说"很高兴看到我的私人助理在公司不同意我做的事时会停工，说不定还会报警"，Trasmatta 补刀说 Opus 5.5 前几天突然随手 `pkill` 了他笔记本上的所有进程，"每次发布都在吹安全机制，到头来没一个真管用"。tosh 贴出帮助中心的说明，首发不含欧洲经济区、瑞士和英国，verzali 说"又一次企图窃取用户数据"，jvwww 回了一句"要是欧洲能出一家前沿模型公司就好了"；jillesvangurp 则说通常过几天或几周就会在欧盟上线。

**其他值得一提的。** mvkel 最大的不满是：发布时的演示和六个月后实际存在的产品完全两样，为了省算力被大幅削弱，他拿 2024 年 4o 语音的演示视频对比今天的效果；nullbio 说用不了两周，Astra 上线两周后"果汁"就开始减量了。realharo 问："他们什么时候不得不回答那个必然的问题：智能体为什么还需要我？"benhurmarcel 回答："它需要你付订阅费。"hankbond 对公告里"把时间和注意力还给你"的说法很不以为然：我要时间和注意力，正是为了做重要的工作；floatrock 接着说，它并没有把注意力还给你，它卖的是一个注意力永远被应用推送捕获的世界。tracyhenry 认为最适合做 always-on 智能体的其实是苹果，它掌握平台、更重视隐私，bentt 同意，因为苹果靠卖硬件赚钱，激励机制和隐私是一致的。

## 文章摘要

这是 Hacker News 每月固定的「Ask HN: What are you working on?」贴，2026 年 8 月这期拿到 320 分、690 条一级回复，是当月人气最高的社区帖之一。提问者只写了两句话：**「你在做什么？最近对什么感到好奇？」**（原文：What are you working on? What have you been curious about lately?）第二问是后来加上去的——楼中有人特意致谢 adityaathalye，是他建议把提问从单纯的「在做什么」扩展成同时问「在好奇什么」，好让那些手上没有具体项目、但脑子里正在琢磨某件事的人也有话可说。

这类帖子没有正文可言，它的全部价值在于回复本身。作为一份横截面样本，它比任何行业报告都更直观地反映出这一时刻 HN 用户的注意力分布。粗略归类，2026 年 8 月这期的回复大致落在几个板块：

**一、Agent 工具链已经彻底占据了副业项目的中心位置。** 大量回复是「我在写一个 agent harness」——smol（9 行 Python 的极简 agent harness，宣称比 OpenCode、Hermes、Codex 更便宜更快、单任务峰值内存更低）、mu/miu.dev（自称「没什么新想法，只是把已有的好想法做扎实，尽可能极简、可组合、务实」）、用 Bazel 做编排、把 agent 执行组织成 DAG 的实验、amika.dev（把沙箱化的 agent 放到云上 VM 里、通过网络给它发消息，作者形容为「Tailscale 和 Firecracker 生的孩子」）、以及给公开 agent skills 做基准测试的 orcabot（拿 Oh My ClaudeCode、Superpowers、Git Ship Done 和 Karpathy 那套去跑 SWE-bench-Pro 和 SlopCodeBench，出月度对比）。有人在下面感慨：现在人人都在造 agent 运行时平台，这已经是最热的创新赛道，而真正的胜负手大概会落在自托管与来源可控这一侧，因为每家大厂都在往服务层延伸、试图把你锁进自家托管生态。

**二、逃离注意力经济的手工制品。** 印刷在真报纸上、按月投递的儿童报纸 The Curiosity Times，里面全是谜题、数学挑战、自然常识、科学小实验、户外寻宝和给全家玩的自制卡牌／桌游——作者说家里一直在限制屏幕时间，他想要一个「不在屏幕上、有教育意义、还好玩」的东西来占满孩子每月的几小时。只给自己和几个朋友用的图片分享站，刻意复刻老 Flickr 和老 Instagram：时间顺序、无推荐算法、无 Reels、无广告，作者说「知道它永远不会开放注册、永远不会有真实用户，反而把所有压力和期待都卸掉了」。还有 Uruky——一个付费、无广告、可个性化的私密搜索引擎，注册不需要提供任何信息（系统随机分配一个账号号码），可以跑工作量证明验证码换两小时免费额度，上个月刚过 250 个月活账号，并接入了门罗币和比特币支付。

**三、纯粹的硬核技术自娱。** 用 Zig 写、用 Vulkan Video 编码、UI 用 SDL3 + imgui 的 Linux 录屏工具 Spacecap；把 Gaussian Splats 直接支持进 ThreeJS 的 WebGPU 后端（PR 已合并，将进入 8 月版本）；用纯 WebGPU compute shader 和 SIMD WebAssembly 在浏览器里跑 NVIDIA Parakeet 语音识别，M5 Mac 上 20 秒转写一小时音频；简洁数据结构（可索引位向量的纳秒级 rank/select，正在做基于平衡括号的简洁树）；NetBSD 内核的 ext3/4 日志代码；PlayStation 裸机编程教程仓库的大改版；macOS 上的平铺-滚动窗口管理器 emira，用截图做过渡动画的合成器覆盖层来让体验接近原生；以及一个 Rust 原生 UI 框架（基于 Leptos，目标是跨平台、全原生组件、小体积二进制）。

**四、人格化的小生意与「一人公司」。** 有人报告自己作为单人创始人兼唯一员工把 Zigpoll 做到了 200 万美元 ARR，策略是靠 AI 把精力全部押在营销和向上打大客户；也有自托管邮件营销软件 Broadcast 从 2024 年（「AI 编码时代之前」）一路做到现在。

**五、以及大量彻底个人化的东西**：仓颉输入法学习工具、印度 2700 座寺庙的图册与地图、桑拿与冷水浴 app、帆船比赛计时手表系统（用 Waveshare ESP32 手表，难点是极低功耗、无互联网、竞技选手的苛刻要求）、开源无订阅无广告的卡路里追踪 app（作者用它一个月减了 10 磅）、一个 5 岁孩子参与美术和音效设计的父子合作船运游戏（Lua + LÖVE2D）、类别制梦幻橄榄球联赛规则、给 HN「Who is hiring」帖做的讨论板（用来标记撒谎或纯粹拿招聘当营销渠道的公司）、乃至「逆转气候变化 / 二氧化碳移除」。

## HN 评论精华

- **taylorfinley**（41 条回复，全场最热）：四月底被裁员后，一直在做自己梦想中的工具——一个**拟物化的木工模拟器**，带 agent MCP 接口。你从真实的木料规格开始，拥有一间摆满斜切锯、雕刻台、台锯的车间。「把它想成 SketchUp，但没有拉伸矩形那一套。」他强调设计上的关键：agent 可以创建参数化流程，于是「立柱框架」这类操作对下一个 agent 来说就变成了一次简单的函数调用，形成飞轮；而且每个界面都做到了**人机对等**（agent 能做的事人也有对应 UI）；所有操作都是 YAML，agent 上手很快；agent 撞到能力边界时还能自己提功能需求。
- **purplemoonx** 在下面给出了最典型的用户故事：他最近想做一个床架，就幻想过这样的软件——从木料清单里挑料、在软件里按自己的想法可视化拼装、选染色和装饰，然后直接去下单买料并切好，「相当于把宜家的床搬回家，只是质量高得多」。
- **brynnbee**（17 条回复）：从零复刻 1999 年的 MMORPG 经典《无尽的任务》——Go 写的实时 MMO 服务端、Babylon.js 的 3D 浏览器客户端、React 复刻的经典 UI，既能当普通 MMO 玩，也有「挂机模式」让它自己玩自己。曾同时在线 70 人。**pryelluw** 的回复是这条串的高光：「我的天，这东西在我手机浏览器上就能跑。」
- **meandave**（16 条回复）：前汽修工，做「市面上最强的汽车诊断 app」CrewChief——从任务追踪，到 VIN 码查零件、DMV 记录，最后做了 iPhone app 直接读 OBD2 故障码并接进定制的 AI 诊断 prompt。他说自己「没见过任何东西有接近这个深度的诊断报告」，眼下的难题是营销：用户还全是熟人。
- **seanmcdirmid**（13 条回复）：自 7 月中起在 Google「on the beach」（内部待岗状态，等于在找下家），一边找工作一边玩本地 LLM 和 DeepSeek。他在搭的 agent harness 用 **Bazel 做编排**，agent 除了你在 Starlark 里显式给出的上下文之外完全隔离，执行组织成像构建一样的 DAG，一个 agent 的输出可作为另一个的上下文，并有仲裁节点所需的反馈机制。楼下有两位分别问「什么叫 beach period」「on the beach 是不是指 gardening leave」，成了这条串的意外笑点。
- **jmathai**（19 条回复）：探索把 AI 用于信仰相关的产品，两个方向——一是把 LLM 的经文引用锚定到真实文本上以消除幻觉，二是用 AI 把人**引向**经文而不是**替代**经文。这条引来了这一期最尖锐的质询，**angoragoats**：「你为什么不把这份本事用在让人们去读那些内容可被验证的书上——那些能推进他们对世界的认知、教他们历史、数学、哲学、逻辑与理性的书？」
- **qurren**（11 条回复）：「AI 量化交易——这样我就有第二份收入，不用再被经理们威胁说达不到他们不切实际的期望明年就没饭吃。」他声称三个月内在初始资金上取得了 30000% 的收益，逾 10 万笔交易逐步累积，但也承认两个风险：这个 edge 随时可能死掉，而且他已经打到该策略的容量上限、之后只能线性增长。**DLA** 直接回一句：「我认为三个月 30000% 是胡扯。如果是真的，我的天。」
- **Bnjoroge**（12 条回复）：Preloop，让你**在本地或自托管环境中运行未经修改的 GitHub Actions**，跑在跨平台的隔离 microVM 里（用 smolvm，底层是 libkrun）。他重写了 runner 并逆向了控制平面，严格遵循官方 runner 协议；每个 job 在 400ms 内从打包镜像启动；还支持「每次失败即暂停」，让人或 agent 立刻在断点处开 shell 修好再在全新环境里重试。**SOLAR_FIELDS** 追问它与该领域事实标准 `act` 的比较。
- **josephg**（11 条回复）：用 Rust 写跨平台原生 UI 框架，坚持要**平台原生组件**。他从 Leptos 起步（拿到声明式 UI 语法和响应式元素），靠 Claude 把它跑通到 iOS、Cocoa 和 GTK，做了个会议日程 app：全 Rust、原生 UI、二进制又快又小。目前正在重写核心，把「vibe coded 的部分」剔除掉。
- **lappet**（11 条回复）：whichtemple.in，收录了约 2700 座印度寺庙（图片取自维基百科），每次访问随机显示一座，另有全印地图视图。他坦言卡在「怎么把它游戏化」。评论区给了三个不同方向的好点子：**ViscountPenguin** 建议做「快速猜这座庙属于哪个宗教」的小游戏，用来熟悉各达摩宗教的常见图像学符号；**unsungNovelty** 想要按邦筛选，先逛完自己所在邦的；**cookiengineer** 则建议做成「图鉴（Pokédex）」——用手机拍照（带 GPS）扫描寺庙来解锁词条，再按「水之神庙」这类分类做成带属性的卡牌，会是很棒的旅行伴侣。
- **absoluteunit1**（8 条回复）：做现代打字训练应用 typequicker.com，理由是「打字大概是 21 世纪知识工作者最重要却最被忽视的技能之一」。**vunderba** 提醒这个赛道从 Mavis Beacon 时代起就极度拥挤，并给了差异化建议：加入 Colemak、Dvorak 以及 AZERTY 等地区变体的训练。**chaostheory** 则指出打字应用的真正难题是**无聊**——唯一让他反复回去的只有游戏化的那些，比如《打字之生化危机》（Typing of the Dead）。
- **BrunoBernardino** 的付费搜索引擎 Uruky 收到了一条极实用的反馈，**Havoc**：「我体验下来最大的缺口不是结果质量，而是没有计算器和汇率换算——比如『50 GBP in USD』这种。」
- **hopfog**：下周就要发售的自动化工厂建造游戏 Sandustry（「Noita 遇上 Factorio」的落沙物理）。回复里几位都玩过 demo，并顺带问出一个不少独立开发者关心的问题——上 Game Pass 的合作是怎么谈成的，是他们主动联系你，还是有地方可以自荐？
- **ventana**：「我很多年前教过 C，在 agent 时代它正在变成一门小众手艺。C 依然既重要又好玩。」于是他在慢慢做一套 C 语言课程，让初学者**在完全不用 AI 的情况下**学一点这门语言、练着写点简单代码。

## 文章摘要

2026 年 8 月 6 日，id Software 在 Bethesda 官网发布了《Quake》30 周年纪念更新公告。核心内容是与 MachineGames 合作制作的全新资料片《Dawn of the Machine（机器黎明）》，作为免费更新提供给所有 Quake 玩家。

MachineGames 此前已经为 Quake 做过两部广受好评的官方新章节——《Dimension of the Machine》和《Dimensions of the Past》，这次是同一团队的第三次出手。官方描述其为「凶狠的战斗、迷宫般的关卡设计、把现实扭曲到无法辨认的噩梦领域」。剧情设定是：Ranger 被困在一个无尽幻象的维度中，一遍遍重复同样的暴力循环，感觉像活了好几辈子，为了逃脱已经死了上千次；筋疲力尽但未被击垮的他听说了「噩梦机器」的传闻——在被永恒的远古领域扭曲的怪物群之后，就是那台机器，摧毁它据信能粉碎幻象、终结循环。

内容规模相当可观：19 张全新地图组成一条完整战役，配全新原声、隐藏秘密、专属章节中枢，外加一张全新的死斗地图。新敌人是熟悉面孔的致命变体——火箭 Ogre、Demo Dog、血 Shambler 等，每种都有新的行为模式（压倒性火力、爆炸死亡陷阱）。武器方面加入了受经典 Quake 资料片启发的变体，包括连续命中会释放闪电的 Super Axe，以及发射跳弹、从各个角度撕裂敌人的 Laser Cannon。

最有意思的设计是「可重复的章节循环」：时间会折回自身，每次重返都会重塑体验——符文会解锁此前封闭的路径，把你带回看似熟悉却已被改写的空间，遇上新路线、新遭遇和新秘密；散落各处的永久性生命值与弹药升级让每一轮循环都更强，为 Quake 引入了一层全新的成长系统。此外还有维度切换解谜、死后重生或变形的敌人、规则随时会变的遭遇战。

更新还包含 id Vault（幕后开发素材与未使用内容画廊，含 Quake 最早期开发阶段的可玩关卡）、三个新成就、以及一个可在单人游戏中随时调出的作弊菜单。

技术修复部分列出了一批：改进插值以降低输入延迟、减少画面相机落后于武器的情况；修复相机在过大位置变化（静默传送门）之间插值的问题；关闭视角摇晃时重新加回武器摇晃效果，且两者现在可以独立开关；移除 Hell Knight 弹道的投影以改善远程攻击观感；给敌人的投影光源加上上限以改善大量 Enforcer 同时开火时的性能；降低菜单内存占用；改进大号无障碍字体的渲染。PS5 上修复了《Scourge of Armagon》中武器没有手柄震动和手柄扬声器音效的问题。

Mod 相关的破坏性改动值得单独注意：本地化字符串现在存放在 Quake 的 PAK 文件里，而不再是游戏数据之外的 KPF 文件；此前从 KPF 读取字符串的第三方引擎需要改为从 PAK 读取，且今后完全不需要加载 KPF。Mod 可以通过覆盖 PAK 里的 `localization/loc_(language)_mod.txt` 添加自己的本地化。

平台方面覆盖 Xbox Series X/S、Xbox One、Microsoft PC Store、Game Pass、PC Game Pass、Steam、PS5、PS4、Switch 2（通过向下兼容）和 Switch 版本的 Quake，已拥有游戏的玩家自动收到免费更新。

## HN 评论精华

417 分。讨论的主体不是这次更新本身，而是**由它引发的一整场 90 年代 PC 游戏集体怀旧**，以及一条相当尖锐的关于竞技射击游戏为何衰亡的辩论。

**排版引发的第一场混战**

- **parable** 的第一条评论就点了火：「这篇文章里的每个 emoji 好像都比上一个更大。」**grenoire** 直接问：「这段垃圾文案是 LLM 写的吧？」**Narishma** 一个字回答：「是。」**upmostly** 也说 emoji 是 LLM 写作的明确标志。**sph** 给出一个技术性的替代解释：可能是 em 单位加上标签没闭合。**silversmith** 认真追问这个「用 emoji 做项目符号」的风气到底从哪来的——**pvtmert** 认为 2020 年前后 Notion 带火的，**mgfist** 认为是 ChatGPT 把它推到极致的，**efskap** 反问「那它必须先成为趋势才会在训练语料里过度出现吧？还是 RLHF 标注员就好这一口？」**2OEH8eoCRo0** 给出了最 HN 的回答：「看看我们这个幼稚且过度正能量的行业吧。我们只是想找点乐子！你讨厌乐子吗？」

**「我该怎么玩到它」**

- **thecrumb** 说自己完全不认识公告里那一堆平台名字，「我还留着我的 Quake CD」。**bsimpson** 有同感，并指出这件事的怪异：给一个比 Steam 还老的游戏出 DLC；他觉得更有意思的做法是直接放出可以在开源版本上玩的地图包。「Quake 流行的时候，CD 是绝对主流的安装方式。他们把很多元老级持有者挡在了门外。」**officeplant** 澄清了实情：这些内容是给 Nightdive 重制版的，所有在 Steam/GOG 上拥有 Quake I/II 的人当年免费拿到了重制版。**chocochunks** 补充：Steam 和 GOG 的销售当年就免费升级到了增强版，所以「比较新的销售」可能也已经是近 20 年前的事了。**ZiiS** 表达了那种微妙的不适：「虽然以我玩坏的那张 CD 的量他们不欠我什么，但拿 30 周年做文章却只支持较新的销售，感觉有点刻薄。」

- **Lammy** 给出了这条串里最实用的建议：装 Kex 引擎的重制版（也就是 Steam 版），但实际用 IronWail 玩——那是一个真正的 idTech 源码移植，可以加载重制版的 PAK，并且会伪装成重制版好让 Steam 解锁成就。他也报告了新更新的 KEX 重制版在他的 Framework Laptop 12（Intel 11 代核显）上直接崩溃，必须往 Steam 启动项里加参数才能跑起来，而且贴图闪烁严重。**AgentME** 建议他把「装 Kex 引擎重制版」改写成「在 Steam 上买 Quake」，好让新人看懂。

- **jiffygist** 问新章节在开源移植版上能不能正常跑。**eseymour** 判断按公告底部的 mod 改动，文本字符串在源码移植版更新前不会正常显示，而且你无论如何都得先装 Nightdive 移植版才能下到新章节。**AgentME** 补充说 vkQuake 和 IronWail 在上一部官方新章节和重制模型上都跑得很好，更新应该不会太久。

- **namdnay** 借机安利：如果你还没玩过 Arcane Dimensions，放下手头的一切去玩——它让 Quake 成为史上最好的单人 FPS，机制比原版还好，地图漂亮，敌人多样有趣。**sph** 说出了很多人的心声：他很喜欢 Quake 自制关卡，但每次想玩，面对半千个源码移植版、只在 Windows 上跑的 wad 管理工具（他用 Linux）、还要从可疑网站上搞一份原版 .wad，脑子就直接分析瘫痪，多年来试了半打次都放弃了。这条串下面全是热心指路——**misterflibble** 给了 CLI 参数写法和 moddb 下载地址，**pezezin** 推荐了 Quake Injector（自动下载和配置地图与 mod）。sph 最后回来报告：「好吧你们说服我了，刚试了，玩起来真不错。」

**竞技射击游戏为什么没落了**

这是全帖最长也最有价值的一条辩论线，由 **ZuLuuuuuu** 一句「很高兴看到 Quake 得到发行商的关爱，但我觉得这还不够」引发——他说自己很喜欢 Quake Champions，甚至买了战斗通行证和周边支持开发，结果游戏发布仅 1.5 年就被放到生命维持状态，而那 1.5 年里每个补丁都带来显著改进。

- **madewithdrama** 认为不能怪开发者不努力：过去十年里 Quake Champions、Unreal Tournament 4 和 Diabotical 全都失败了，三款都是好游戏，但三款都没能吸引和留住新玩家。他的解释是：「它们是竞技场射击游戏该有的样子——流畅的移动、平衡的武器、精心设计的地图。有竞技场射击经验的人都喜欢。但大多数新玩家不想在学基础的几个月里被反复暴打。」

- **TulliusCicero** 强烈反对把这当成玩家的问题：「如果新手体验是这样，那就是你搞砸了。确保新玩家真的玩得开心是游戏设计的关键部分。你不能指望『新玩家得先花 50–60 小时被碾压然后才开始享受』。」他列了几种缓冲方案：战役、对机器人的遭遇战模式、完整的 PvE 合作模式、真正能用的自动匹配。**crummy** 举了 Splitgate 的例子（前几小时匹配机器人），**wmil** 举了 Marvel Rivals（连输两把就悄悄给你配机器人队友），**doublerabbit** 说 Overwatch 也这么干过但久了会腻。

- **bashwizard** 站在对立面：他认为正是陡峭的学习曲线和为变强而磨练的过程成就了竞技场射击。「练了几个月单挑，终于能打赢那些以前 50 比 0 屠你的人——那种感觉比我在任何现代 FPS 里得到的任何成就都好。现在的玩家不在乎自己变强，他们要的是即时满足。」TulliusCicero 反驳说 90 年代几乎所有人都很菜（因为品类还新），技能差距小得多，所以碰到更强的人不是大问题；bashwizard 坚持认为当年的差距其实巨大，是现代的 SBMM（技能匹配）造出了一个庞大的中低水平「团块」，让人们从没机会见识真正的高手。

- **_carbyau_** 提出了一个很少被说破的观察：「我放弃 PvP 了。我一直没想通的是——如果我『变强了』，那只是把『我赢不了』这个问题转移给了别人，并没有解决它。」他还指出即使玩家基数很大也一样，因为排名靠下的人必须承受高手一路往上爬时对他们的碾压——这些系统不是静态的。

- **doublerabbit** 给出了一个宏大的（也是最有争议的）判断：「boomer shooter」是和 Halo、局域网聚会一起死掉的，Minecraft 是最后一根钉子。他的论点是：架专用服务器需要技能和知识，如果能一键开 Quake 3 或 UT 服务器，人群还会在；而且对新人来说服务器很毒——同一批脾气不好的老玩家知道地图上每一个诀窍，一枪电磁炮把你秒了，永远在同一张图上换来换去。**busterarm** 断然反驳：「什么？我们现在正处在 boomer shooter 的文艺复兴里，有好几百款新作，是个热门品类。只不过全是单人向的。」他还说自己从发售起就一直断续在玩 UT99、UT2k4、Quake（尤其是 Quake Fortress）、TFC、AvP2，「这些游戏的生命力比很多更近期的多人游戏强得多，主要玩家是我这样的老男人」。

- **donatj** 提出了一个更本质的失落：「我一直不理解相反的那种模式——现代游戏里每一局都跟不同的陌生人玩。我小时候玩 Quake 3，收藏着不同的服务器，认识开服的人和常驻的那群人，有友情也有宿敌。现代多人游戏你还不如在跟机器人玩，没有社区。」**inigyou** 顺势追问：「如今生活里还有任何地方存在社区吗？」donatj：「真的没有，我讨厌这一点。」**raffraffraff** 推荐 Xonotic 有那种老派感觉，玩家基数不幸很小，但只要在活跃服务器的 ping 范围内，确实会一直碰到同一批人，包括开服的人。

- **ThrowawayR2** 纠正了关于 UT4 的说法：它从来不是真正的发布版，而是 UE4 的免费技术演示，因为 Fortnite 起飞、开发者被调走而没做完。**chupasaurus** 补充了因果顺序：UT 团队的人被调去给 Fortnite 做大逃杀模式，那才是 Fortnite 起飞的原因，不是反过来。

- **0x1ch** 提供了一个 Quake 圈内视角：这次更新对真正打 PvP 的人来说意义不大，Quake Live 从 2012 年前后一直撑着场子且始终免费。Champions 出来后，Quake Live 的社区大多留在 Live；Bethesda 却把 Live 改成收费 10 美元（大概是想把新玩家引去 Champions，而 Champions 不久后也变成免费）——「实际上他们把两个游戏的免费状态对调了，而免费的那个是圈内更不受欢迎的选项」。

**纯粹的怀旧**

- **karim79** 的感慨拿到了一条长串：「Quake 三十岁了，我不敢相信我还活着。我太爱这游戏了。⋯⋯那才是真正的局域网聚会年代，再也回不去了。」他描述朋友们扛着大屁股 CRT 显示器和主机来他家，用长得离谱的网线，父母不介意网线横穿厨房地板，「他们不知怎的懂了。无价」。

- **vunderba** 讲了个绝妙的故事：1996 年他还是小孩，不知从哪学到可以通过控制台在游戏进行中修改物理参数。一次局域网对战他弹药打光被追杀，逃进走廊跳过一个岩浆坑，落地立刻转身、拉下控制台以最快速度打字——`sv_gravity 1600`。

- **DamnInteresting** 回忆 1994 年前后在表兄的 Novell 格子间里通宵打 Doom2 死斗，然后是 Duke Nukem 3D（用 Build 引擎做自制地图，他就是 NukeCity 1 和 2 的作者），再然后是 Quake。他还透露 3D Realms 找外包公司为《Shadow Warrior》做资料片时，那家公司因为他 NukeCity 地图的人气找上门请他设计关卡——他做完了、资料片也完成了，但他从没拿到钱；作品是 Twin Dragon 的第 11 关「要塞」。

- **bsimpson** 的一条回忆引出了一场技术考古：他的 Mac 版 Quake II 把游戏刻成了音频 CD，可以把碟丢进随身听放原声带。**vor_**、**nizmow**、**r721** 解释这就是 90 年代普遍的「混合模式 CD（Mixed Mode CD）」——第一轨是数据轨，后续是标准 CD 音轨；如果游戏安装后不需要读盘，你甚至可以换张别的专辑进去听。**cosmotic** 猜测有技术原因，**formerly_proven** 一句话点破：「所以当年 CD 光驱到声卡才有一根单独的四针线呀。」**hansor** 补充了性能背景：当时主流 CPU 是 386 和 486DX，现实中根本没法实时解码 44kHz 立体声 MP3。**hamdingers** 说 Tony Hawk's Pro Skater 1 和 2 在他车里放的次数比在 PlayStation 上还多，**bsimpson** 全大写地震惊，但 **terinjokes** 贴出 ConsoleMods wiki 的 CD-DA 音轨游戏列表，里面并没有 THPS 或疯狂出租车——很可能是集体虚假记忆。

- **kar1181** 写了一段动人的总结：Quake 是他第一次感到真正沉浸在一个世界里——玩过 Doom/Wolf，但能低头看、能在三维空间中移动，「以一种前所未有的方式让人觉得真实」。他住在乡下用 33.6k 调制解调器，好日子 ping 300ms，那时电话按分钟计费，是个「非常昂贵的游戏」。他还提到 Team Fortress 出自墨尔本 RMIT 的一群人（Robin Walker / John Cook），他们后来去了 Valve。关于阅读材料，他认为除了大家常推荐的《Masters of Doom》，Michael Abrash 的《Graphics Programming Black Book》（GitHub 上免费）是更好的伴读，「今天读来依然极为可读」。他最后问：「我们中有多少人能把自己的职业生涯归功于 id，归功于他们让我们迷上电脑、迷上 QuakeC 甚至 Quake 2 的游戏 DLL 源码和后来完整的引擎源码？」

- 一场关于 486 上跑 Quake 的性能考古也很热闹：**shuwix** 说带火把的房间在超频到 150MHz 的 486 上最多 9 FPS（320×200），通过控制台关掉物体让火把消失能让帧数翻倍。**pezezin** 给出了权威解释：Quake 是第一款需要强力 FPU 的主流游戏，Michael Abrash 手工调优了光栅化代码以适配 Pentium 流水线，别的 CPU 根本不行。**shuwix** 举证：用 AMD K6（FPU 特别弱）的同学必须买最便宜的 OpenGL 显卡（如 Rendition Verite V1000）才能有像样帧率，而有 166MMX 的人靠软件渲染就能玩。**busfahrer** 贡献了一个可爱的冷知识：火把闪烁的模式是通过源码里的特殊字符串编码的。

**几句冷水**

- **artemonster** 一句话：「用又一轮裁员来庆祝吧，万岁。」**biglyburrito** 展开：「Bethesda 想庆祝有史以来最早也最好的多人死斗游戏之一的 30 周年，却是在把造出它的组织掏空之后——这对我来说是种冒犯。」

- **cubefox** 注意到新章节是外部工作室 MachineGames 而非 id Software 内部开发的。**sitzkrieg** 指出三部新章节全是 MachineGames 做的。cubefox 追问这是否意味着他们做 Quake 已经比 id 自己还强了。**cluckindan** 的回答很冷：「已经不存在『id Software』了。」cubefox 说 Bethesda 网站上的这篇文章还是署名 id Software 的，cluckindan：「品牌还在，工作室只剩个骨架。」

- **jervant** 提醒 Nine Inch Nails 也为 30 周年出了新周边和原声专辑。**Lammy** 抱怨现在只卖黑胶不卖 CD，**strictnein** 调侃「这个 CD 到处都是啊，买张 Quake 的 CD 就行」，Lammy 认真反驳了四点：普通人不知道这回事；原版 Quake CD 早已停产、存量有限；你的 CD 播放器得聪明到能识别第一轨是数据并跳过，否则会先给你两分钟巨响的静电噪声；Quake CD 的音轨是带预加重（pre-emphasis）母带处理的，播放器必须支持去加重均衡，否则声音不对——他查了自己那张，TOC 里确实标了 `PRE`。**whywhywhywhy** 则赞美 NIN 把宣传照拍成老照片里 id 办公室的样子，「这个构思绝了」。

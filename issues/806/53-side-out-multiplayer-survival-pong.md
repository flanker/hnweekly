## 文章摘要

Side Out 是托管在 antics.gg 上的一款浏览器多人游戏，可以理解成「大逃杀化的 Pong」。八名玩家各自守住同一个正多边形的一条边，球同时朝所有人飞来，而你唯一能控制的只是自己那条边上的球拍。每人两条命，漏球两次你的墙就碎掉——此时竞技场立刻把缺口合并，重新变成更小的多边形：八边形变七边形，七边形变五边形。也就是说棋盘的大小永远精确等于还活着的人数。当只剩两个人时，场地已经收缩成一个带两块球拍和两面死墙的矩形，也就是电子游戏史上最古老的那款游戏本身——在此之前的一切，都只是通往这场决斗的路。

局势不会礼貌地等你：球每被击回一次就加速，所有人活得越久球就越多（大约一分钟后加入第二颗，然后第三颗，持续增加），过了某个点连墙壁本身都开始向内收缩。官方说明写得很直白：「没人能永远活下去，这就是重点。」

最有意思的设计是死亡后的处理：被淘汰的玩家不是变成观众，而是接管场上的「危险物」。死者可以瞄准竞技场内任意位置投放三种道具——PEG（把球以大角度弹开的碰撞柱）、WELL（让经过附近的球轨迹弯折的引力井）、SPIN（把球甩向场地另一侧的旋转杆）。投放有冷却时间（准星处的圆环在倒计时），且不能放在活人球拍的可及范围内，被拒绝时会有标记说明原因。官方措辞相当解气：「把你淘汰的那个人还在场上，你可以让他的日子难过得多。」

操作层面：桌面端用鼠标滑动球拍，也支持方向键或 A/D；手机端在屏幕任意位置拖动，球拍跟着手指沿自己那面墙移动。无论竞技场在别人屏幕上朝哪个方向旋转，你自己那面墙永远画在屏幕底部，下方有一个尖角标记和你的名字。球的拖尾会显示最后击球者的颜色，所以能看出这一回合是谁在打；击球偏离球拍中心会给球加旋。M 键静音。大厅里按 READY 即可，独自一人时游戏会把门留几秒等别人从你的链接进来；倒计时期间到的人直接加入，更晚到的看完这局玩下一局。空缺的墙由 bot 补上。

平台本身也值得一提。antics.gg 提供的是「永久多人房间」模式：每个游戏有一个公共世界房间，打开页面就直接和当时在线的人一起玩，免费、无需下载和注册，也可以开私人房间拿到新链接分享（原房间不受影响继续运行）。站上已有 35 个游戏，包括 Inkline（共享画布上的圈地涂色）、SandStorm（全可破坏、全物理模拟世界里的合作竞技射击）、Hide & Seed（维多利亚玻璃温室里的道具躲藏）、Ember Tide（火山之夜的合作生存）、Sky Dash（领先者会为后面的人破路的暴风前竞速）、Midnight Midway（三个嘉年华小游戏）、Fry Hard（浏览器里的联机合作版 Brotato，自动开火的土豆对抗愤怒蔬菜）、Bump Set Bonk（台北公园草坪上的 2v2 一键排球）。平台的核心卖点写在页尾：「这里的每个游戏都始于对一个 coding agent 的一段 prompt。antics 提供房间、实时状态和一个可以发给别人的链接——你写游戏，我们把它变成多人游戏。」站点还提供 Docs、Skills、Prompts 和 MCP servers。发帖人 eric_khun 应当与该平台相关。

## HN 评论精华

**这条帖子讨论极其稀少：11 分，零条评论**，作者本人也没有留下任何自述文字，因此没有任何可摘录、可翻译的社区观点。为避免编造，这里不虚构任何用户名或发言，改以原站要点补足：

- 核心机制的巧妙之处在于「场地大小 = 存活人数」的自适应收缩。多边形每少一条边就重新闭合，让淘汰机制同时充当难度曲线和节奏控制，最终必然收敛到 1972 年 Pong 的原始形态——把一款派对乱斗自然地降维成一场经典单挑，是个非常干净的设计闭环。
- 「死者操盘危险物」的设定解决了大逃杀类游戏最常见的体验问题：早早出局后无事可做。把被淘汰者转成场上变量（PEG / WELL / SPIN 三种干扰物 + 冷却 + 不可放在活人可及范围的限制），既保住了参与感，又给了针对性报复的动机。
- 三重递进的压力源——每次回球加速、随时间增加球数、后期整个竞技场收缩——共同保证局数必然结束，避免了对称守门类玩法容易陷入的无限拉锯。
- 工程上值得注意的是「零安装的多人化」这条产品路线：一个链接、手机或笔记本浏览器、最多八人、空位由 bot 填补，且房间是永久在线的公共世界。antics.gg 把这套房间/实时状态/可分享链接的基础设施做成了平台能力，宣称站上 35 个游戏全都源自「对一个 coding agent 的一段 prompt」，并对外提供 Docs、Skills、Prompts 与 MCP servers——本质上是在卖「给 AI 生成的小游戏加上多人后端」这一层。
